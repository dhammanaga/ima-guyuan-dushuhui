## 📅 使用方法（每周流程）

1. **开会前**：主持人读当周主持人版（⭐速览＋📌特别提醒＋⏱时间弹性指南，再扫一眼总指南的"逐周要点一句话"），**学员无需预习**；两版文档打印或电子分发——**学员拿学员版、主持人拿主持人版**。
2. **双版本关系**：两版的**共读原文逐字一致**（主持人版只多出⭐速览／⏱时间弹性指南／📌特别提醒等主持辅助块）；共读环节大家读到的文字完全相同，主持人的辅助内容不打扰共读。
3. **进行中**：按120分钟六环节推进（静心开场10′→共读原文30′→第一轮分享25′→主题讨论35′→禅修练习15′→收尾回向20′）；共读环节轮流朗读★核心段，◈扩展段视时间选读。**共读只读不解释。**
4. **收尾**：一句话收获（成员回馈三问，不作点评）→下周预告→作业→回向文；作业不检查、不评比。
5. **缺席**：不补分享，缺席者拿当周学员版自学即可。
6. **新人中途加入**：随时欢迎；每讲开头的速览不依赖前几周，主持人用一分钟讲清"**只读原文、只谈自己、不舒服随时可以停**"即可。
7. **核对出处**：想核对某段原文来自哪份材料时，翻《原文全集》按周查找——每块共读文本都标有材料标题、类型与完整 media_id；延伸阅读的打开方式与此相同。
8. **材料准备**：学员版人手一份（打印或电子），主持人版主持人自留一份；建议另备**当周图表／对照表的打印或投影**（六组三十二身分总表、五种分辨法对照表、七种学习善巧／十种作意善巧表、顺逆序全表、八类利益清单、四界十二特相表、观智次第图等）；**备定时器、松肩用的小铃与安静场地**；涉内脏／粪便／体液的周次（W3／W4／W6／W8），主持人**会前先自过一遍当周段落**、心里有数。

## 🗓 给组织者的开课建议

- **固定节奏**：建议同一时段、同一场地，8周连续；每周1次×2小时，按第1—8周的次序走，主线最清楚（总论一周 → 逐组观照三周 → 方法善巧一周 → 可厌作意与顺逆序一周 → 修习利益一周 → 转向四界与观智一周）。
- **人数**：6-12人为宜；**本系列涉身体与心理，宜精不宜多**，建议 10 人左右、便于随时照护；8人以上时第一轮分享改为"每人一句话"，让每个人都说得上话。
- **主持人**：可由1—2位轮值；轮值者提前通读《00_主持人总指南》，开讲前读当周"主持人版"的速览与"逐周要点一句话"一段即可上场，**不需要修学或教学资历，也不需要任何"证量"**（本系列不比较、不判定任何人的进度与境界）。
- **首课约定**：第一讲开场花三五分钟说明三条规则——**只读原文、只谈自己、作业不检查**；并说清三个许可——**"可跳读、可只听、可只取一处、可随时暂停、可睁眼、可暂离"**；再立一句定调词"**「可厌」＝不可喜（asubha），不是厌恶；不自我嫌弃、不嫌恶他人、不追求境界**"，让"不考试、不评比、安稳为先"的氛围从第一课就立起来。
- **课前准备**：当周图表／对照表打印或投影稿一份；计时器；安静场地即可，无需投影以外的多媒体设备。
- **课后小结**：每讲可由主持人记一句"本周最触动我的话／我今晚的一个发现"，八周下来就是一份属于这个班的"共学小记"。
- **收官安排**：第8周为收束与收官周，建议把"收尾与回向"留足15分钟，做八周回顾与"下一程"分享，并落到"**方向清楚就是进度**"，让这一路走得完整、走得踏实。
