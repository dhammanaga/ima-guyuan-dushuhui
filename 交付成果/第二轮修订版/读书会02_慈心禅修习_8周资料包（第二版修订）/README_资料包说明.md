## 🧭 使用顺序

1. **主持人**先读 `00_主持人总指南.md`（10分钟）
2. 每周活动前，主持人打开**当周主持人版**，学员打开**当周学员版**——**"共读原文"部分已嵌入完整原文文字，直接照读即可**
3. 想查阅更多原文 → 打开 `原文全集.md`（9份资料完整文字，已标注出处）
4. 按周文档中的流程推进：静心开场 → 共读 → 分享 → 讨论 → 练习 → 扩展内容包 → 收尾回向
5. **时间管理**：时间不够→按"⏱ 时间弹性指南"浓缩（只读★核心段）；时间富余→用"📚 扩展内容包"延伸
