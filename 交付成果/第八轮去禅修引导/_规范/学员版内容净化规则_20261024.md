# 学员版内容净化规则 v1.0（去主持人备课与说明性内容）

> 一句话口径：**学员版只留「给学员看的东西」——问题本身、共读原文、静心引导正文、作业与回向；一切给带领者看的备课、计时、流程、引导路径、应答库、备用方案，一律不留。**

## 一、五条铁律（本次确立）

| # | 对象 | 规则 |
|:--|:--|:--|
| R1 | 计时与流程建议 | 分享节内的 `> **计时与流程建议**` 引用块**整块删**（含「N 分钟的常见切法」「人数超过 N 人时…」「若有人明显超时…」「全员分享完毕仍有富余时…」「复述关键词／白板记录」等条目）。同类 `**时间分配参考**`、`**第二轮分享时间分配建议**` 亦删；同行若接 `**起手问题**`，只保留「**起手问题**：」及其后问题。 |
| R2 | 主题讨论 · 只留问题本身 | 讨论节内**白名单**：问题行、`### 第N问…` 子问题标题、空行、`---`。其余一律删——`>` 引用块（本问目的／引导路径／原文提示／引导方向／追问方向／⚠️ 收束提示／跑偏带回／讨论方式／预设回答与应对／引导）、`**讨论总则**`／`**讨论规则**`／`**讨论提示**`／`**讨论开场白**`／`**记录建议**`／`**时间不够时…**`／`**请跟随引导练习**`／`**读者不提供答案**`／`**主题讨论主持工具箱**`／`**组织形式**`／`**小结框**`／`**示例**`／`**参考收口语**`／`**引导问法**`、`- 提示／深化／再深化／落点／指向／关键点／钉住结论／生活化／落地／展开方向／目标／提醒／对照／收束／延伸思考／追问`、`N. **"问"** → "答"` 问答对、表格、纯括注说明段。 |
| R3 | 备用追问 | `**备用追问（讨论冷场或过热时使用）**` 及其后 `- 冷场时…`／`- 过热时…` 列表**整块删**；`**备用深水问题（时间富余时）**`、`**（若时间富余）延伸一问**`、`**（时间富余时的第N题）**` 同删。 |
| R4 | 收尾环节 | 删 `**便签环节（约N分钟，时间富余时用）**` 及其正文段、`**最低收尾方案（当晚严重超支时启用…）**` 及其内容、`**[⑤⑥⑦] 收尾主持要点**` 及其列表（三句回顾法／作业认领／离场照护／场地与秩序／回向前的一句等）。保留：总结引导、今天请带走这三样、本周作业、下周预告、四周回顾、系列结语。 |
| R5 | 回向环节 | 删回向词之后的带领者括注 `（回向毕，带领者致谢：…）`、`（回向毕，轻声道一句…）`；同类 `（领读前留三息的静默…）`、`（「三个带走」说完即可收束总结…）`、`（宣布散会，感谢大家。）` 一并删。**回向词四句一字不动。** |

## 二、顺带清理（同类、同源，随本批执行）

1. 分享节 `> （带领者先分享自己的，然后按顺序轮流。这一轮只说不评论。）`、`> 时间紧时每人一句话即可；冷场时带领者先分享自己的真实感受。` 等**带领者操作引用行**删除；同一引用块内的分享问题保留。
2. 静心节 `**带领者引导语**（念出即可）：` → `**引导语**：`（引导正文一字不动）。
3. 讨论节问题行内的备课括注删除：`（★必答…）`、`（◈选答…）`、`（备用…）`、`（约N分钟／N min）`、`（时间富余…）`、`（冷场…）`。
4. 原稿残缺的备课残句（如 8周版15 第5/6 周「意义上，生命是一条无间断的相续之流…** 记住这两句」半句）、`****` 起首的畸形行，删除。

## 四、问题行识别正则（宽口径，防误删）

```
^\s*(?:- )?\*\*(?:（可选）)?(?:问题|引导问题|讨论问题|小题|问[一二三四五六七八九十\d]|[一二三四五六七八九十]问|第\s*[0-9一二三四五六七八九十]+\s*[问題题]|[一二三四五六七八九十]+题)
```

> 实测必须覆盖的形态：`**问题一：…**`、`- **问题①（★必答）**：…`、`**引导问题一（由浅入深·第1层）：…**`、`**问一（认识受）**：…`、`**第 1 题：…**`、`**小题 2（必谈）：…**`、`**（可选）引导问题四（进阶）：…**`、`### 第一问：…`。
> **纯分组标签**（`**引导问题（由浅入深，指向实修）**`、`**讨论问题（按优先级）**`）虽匹配上式，仍须删——判定：加粗内无问句、形如标签。
