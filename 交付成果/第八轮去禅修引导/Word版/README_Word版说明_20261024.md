## 一、目录结构

```
交付成果/第八轮去禅修引导/Word版/
  4周版/   读书会NN_第N周_{周标题}_主持人版.docx
           读书会NN_第N周_{周标题}_学员版.docx     （N = 1–4）
  8周版/   读书会NN_第N周_{周标题}_主持人版.docx
           读书会NN_第N周_{周标题}_学员版.docx     （N = 1–8）
```

- 文件统一带系列前缀 `读书会NN_`，便于与其他系列混放时辨认。
- 配色：主持人版藏青 `#1F3864`，学员版墨绿 `#1E4620`；同一系列两版内容一一对应。

## 二、样式规则依据（v1.1）

- 规范文档：`文档/规范与手册/读书会Word文档生成规则_20261024_2245_v1.1.md`
- 生成器：`脚本/_mk_word_latest.py`（v1.1）
- 校验脚本：`脚本/verify_word.py`

**字体（关键）**：正文＝中文**宋体** ＋ 西文 **Times New Roman**；标题＝**微软雅黑**。
v1.0 用的「等线（DengXian）」已全部移除，并清理了 `theme1.xml` 里的其他语言字体，WPS 打开不再提示字体缺失。成品内字体名只有：宋体、Times New Roman、微软雅黑、Symbol、Courier。

**版式**：A4 21×29.7cm、上下 2.0cm／左右 2.2cm；首行标题 20pt 居中＋下横线；`#` 16 / `##` 13.5 / `###` 11.5；正文 10.5pt、行距 1.4、段后 5pt、两端对齐；引用块 10pt／左竖线 3.75pt／底纹 `#EEF3F9`；表格按内容定列宽、表头 10pt 跨页重复、隔行 `#EEF2F8`；页眉 8.5pt＋下细线；页脚「— 页码 —」；知识地图代码块转层级缩进文本。

## 三、生成方式（批量重出用）

```bash
python3 脚本/_mk_word_latest.py "<资料包目录>" \
        --series NN --edition "第八轮（第8版）" --weeks 4     # 或 8
# 输出到 <资料包目录>/Word版/；如集中到本目录，加 --out 本目录/4周版
```

取源纪律：一律取 `精修4周版/`、`精修8周版/` 下对应资料包（第8版）的 md，不得用第5/6/7版旧稿。
