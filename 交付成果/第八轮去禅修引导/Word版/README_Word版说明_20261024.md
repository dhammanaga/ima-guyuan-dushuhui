### 字体（v1.2 收口，彻底消除缺字提示）

| 用途 | 字体 |
|---|---|
| 正文中文 | 宋体 |
| 正文西文/数字 | Times New Roman |
| 标题 | 微软雅黑 |
| **巴利语转写**（ā ī ū ṅ ñ ṭ ḍ ṇ ḷ ṃ ḥ） | **Times New Roman（强制）** |
| 列表符号 | 文本字符「•」「1.」 |

- v1.1 之前 WPS 提示缺 **Courier**：来源是 Word 内置列表样式（List Bullet/Number）的符号字体。v1.2 改为手写符号，并在包内所有 XML 中清除 `Courier／Symbol／Wingdings／Calibri／Cambria／Arial／等线`。
- 成品字体名只剩：**宋体、Times New Roman、微软雅黑**（已实测计数）。
- 巴利语：实测 Noto/思源 CJK 缺 14 个变音字母（ṅ ṭ ḍ ṇ ḷ ṃ ḥ 及大写），故巴利片段一律走 Times New Roman，中文仍走宋体/雅黑。

### 版式

A4 21×29.7cm、上下 2.0／左右 2.2cm；首行标题 20pt 居中＋横线；`#`16／`##`13.5／`###`11.5；正文 10.5pt、行距 1.4、段后 5pt、两端对齐；引用块 10pt／左竖线 3.75pt／底纹 `#EEF3F9`；表格按内容定列宽、表头 10pt 跨页重复、隔行 `#EEF2F8`；页眉 8.5pt＋下细线；页脚「— 页码 —」；知识地图代码块转层级缩进文本。
