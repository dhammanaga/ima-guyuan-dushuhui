## 🗺 本周知识地图

**本周是四周的收束课（＝8W7＋8W8）：把十二支合起来，看它在自己身上怎么转。**
一句话说清：**十二支按「过去二支、现在八支、未来二支」分成三世，串成两重因果；
两重因果上有三个连接点，其中只有「受→爱」这一处是当下能碰的；
而整条链之所以转个不停，是因为无明与爱这两个根本没有被断。**
看清这三个连接，就知道今生唯一的下手处在哪里。

```
三世两重因果 · 三连接 · 三轮转 · 从缘起看解脱（全链收束）
│
├─ 一、三世两重因果（＝两条链子首尾相接）
│   ├─ 第一重「过去因 → 现在果」：过去（无明·行）→ 现在（识·名色·六入·触·受），
│   │   以**无明**为根本、以**受**为终结——这一生的果报，是从过去因缘而来的
│   ├─ 第二重「现在因 → 未来果」：现在（爱·取·有）→ 未来（生·老死），
│   │   以**爱**为根本、以**老死**为终结——此刻的执取，正在结出未来的生死
│   └─ 两重并说的用意是**同时根除二边**：由「果」的生起显明诸因不断，故根除断见；
│       由已生的识、名色、六入、触、受终归坏灭，故根除灵魂说、梵我说等常见
│
├─ 二、二八二支与三时
│   ├─ 过去二支：无明 · 行（已过去，看不见、也下不了手）
│   ├─ 现在八支：识 · 名色 · 六入 · 触 · 受 · 爱 · 取 · 有（生命期间一直在转的八支）
│   ├─ 未来二支：生 · 老死（尚未到来）
│   └─ 所谓「二八二」＝过去二、现在八、未来二，共十二支配属三世
│
├─ 三、两种有轮的安立（同一个轮回，两种说法）
│   ├─ **践行者**以无明为根本：见解很坚固、凡事「通过控制来完成」的人，
│   │   其执取只要会导致愁、悲、苦、忧、恼升起，它都是无明
│   ├─ **爱行者**以爱为根本：贪图色声香味触的享受、或「躺平算了」的人，
│   │   其轮回的根本是贪爱，故属爱为根
│   ├─ 说第一种有轮（无明为根本）→ 为**根除断见**：果报有因而生，显明诸因不断，
│   │   不是偶然、不是父母精卵结合就无因出现
│   └─ 说第二种有轮（爱为根本）→ 为**根除常见**：这一生的识名色六入触受终归坏灭，
│       没有灵魂、梵我式的永生
│
├─ 四、胎生者与化身者（两种结生方式）
│   ├─ **胎生者**配第一种有轮：如人类十月怀胎、渐次发育——无明爱取之业与父母相合，
│   │   在受精卵上结生「羯罗兰」（入胎的结生名色，仅头发丝尾尖大小），
│   │   最初只有三十种色（心所十法聚 · 性根十法聚 · 身净色十法聚），
│   │   再心脏先发育、肢体发育、六根出现，走「名色→六处→触→受」的次第
│   └─ **化身者**配第二种有轮：如天人死而生天，结生那一刹那**五蕴同时具足**，
│       不经渐次发育——「有」直接产生「生」，生即是五根五蕴一时生起
│
├─ 五、三连接（两重因果的三个咬合点）
│   ├─ 第一处「行 → 识」＝**因果连接**（业 → 果）：过去的业行，导致这一生的结生识生起
│   ├─ 第二处「受 → 爱取有」＝**果因连接**（果 → 烦恼）：受是果报，遇到果报就采取行动，
│   │   果报一出来，人就开始造业——这个行动不是善的就是不善的，没有中间状态
│   ├─ 第三处「有 → 生」＝**因果连接**（业 → 果）：所造之业在临死时成熟，
│   │   导致未来结生；从死亡到结生，也是业成熟
│   └─ 三处连起来是「因果 · 果因 · 因果」，故说「**因果因而有三连接**」
│
├─ 六、二十行相有轮（把两重因果铺成一张完整的循环图）
│   ├─ 过去五因（无明 · 爱 · 取 · 行 · 业；无明含爱取，行含业有）→ 现在五果（识 · 名色 · 六入 · 触 · 受）
│   ├─ 现在五因（无明 · 爱 · 取 · 行 · 业；同前相摄）→ 未来五果（识 · 名色 · 六入 · 触 · 受；生、老死、愁、悲、苦、忧、恼即摄于此）
│   ├─ 二十行相的构成：过去五因 · 现在五果 · 现在五因 · 未来五果，合共二十行相
│   └─ 「现在五因」里也含无明：爱、取与其相应的无明同在，「有」则涵盖其前分的行——
│       所以根除无明不是回到过去，而是在当下每一个「受缘爱」处下手
│
├─ 七、缘起图与四象限（轮回图怎么看）
│   ├─ 图共**八个圈**（依本讲所用图式；从无明起转到最外），分作**四个大区域**
│   ├─ **内圈：无明与爱**＝轮回的两个根本——无明以过去的无明缘行代表，
│   │   爱以这一生的受缘爱的爱、取代表（受缘爱此处亦有无明，只是简说）
│   ├─ 第一象限（过去因：无明 · 行）＝**集谛所摄**：属过去因的阶层，是烦恼轮转
│   ├─ 第二象限（现在果：识 · 名色 · 六入 · 触 · 受）＝**苦谛所摄**：
│   │   果报只要出生就不圆满、低劣、会坏掉，这就是苦
│   ├─ 第三象限（现在因：爱 · 取 · 有）＝**集谛所摄**：每个当下正在发生的造作
│   └─ 第四象限（未来果：生 · 老死）＝**苦谛所摄**：未来果的实内容仍是识名色六处触受
│
├─ 八、三轮转（有轮为什么转个不停）
│   ├─ **烦恼轮转**＝无明 · 爱 · 取（过去的无明 ＋ 今生的爱取）
│   ├─ **业轮转**＝行 · 业有（过去的行 ＋ 今生的业有）
│   ├─ **果报轮转**＝识 · 名色 · 六处 · 触 · 受 · 生 · 老死（今生果报 ＋ 来生生老死）
│   └─ 三种轮转相续成「有轮」：**只要尚未断除烦恼轮转，就会持续不断地滚动不息**
│
├─ 九、唯一下手处——受缘爱
│   ├─ 过去世的无明与行**已经过去**：未修到观智之前，不可控，也无从了知——
│   │   过去的业跟这一生到底什么关系，是佛教最深奥、也最下不了手的地方
│   ├─ 三处连接里，只有「受 → 爱」是**当下可碰**的：第一处在过去，第三处在临终来生
│   └─ 所以面对果报时，应当**如理作意**——这是课程里反复强调的一句话；
│       「受是果报」，随后那个「要」才是当下可作意的
│
├─ 十、过去爱 · 现行爱与果报受（受凭什么引生爱）
│   ├─ **过去爱**是轮转的根：过去爱导致现在的爱生起；对过去未来而言，现在爱也是过去爱
│   ├─ **果报受**以「**亲依止缘**」为爱之源：受是果报，它不能「生」爱，
│   │   只作强有力的助缘
│   ├─ **非果报受**（速行上的受）以「俱生 · 无间 · 亲依止」等为爱的缘：
│   │   速行上的受若与贪相应则俱生，速行之间是无间
│   └─ 现行爱分两种：**觅求爱**（为追求受用而奔走，如行于羊肠小道）·
│       **觅得爱**（已求得受用、正享用时生起的爱）——都是为了某一种感受而追求
│
├─ 十一、从爱到一切恶不善法（九种次第与四种胜解）
│   ├─ **九种次第**＝寻求 → 得 → 抉择 → 欲贪 → 耽着 → 固执 → 悭吝 → 守护 → 执持刀杖：
│   │   一条从最微细到最粗重的放大线，全都从爱出发；看清次第，就知在哪一步刹车
│   ├─ 爱与寻求：因爱存在故寻求存在——如寻求四种食物（段食 · 触食 · 意思食 · 识食）
│   ├─ **四种胜解**（抉择的四种性质）：**智胜解**（知乐及其因、照做以致未来有乐，即自觉者）·
│   │   **贪胜解**（基于一百零八种爱而抉择）· **见胜解**（依六十二种邪见而抉择）·
│   │   **寻思胜解**（以寻思斟酌可欲非可欲、我将享用储藏等）
│   └─ 现行爱生起时「有如被揪发、令人嚎叫而偏离一向之路径」：极难控制，往往会倒在里面
│
└─ 十二、从缘起看解脱（本周落点）
    ├─ 过去的无明与行已不可及，未来果尚未到来——**今生唯一的下手处就是受缘爱**
    ├─ 帕奥西亚多：以**观智（毗婆舍那智）**断除「见」与「爱」两种根本，如以**智剑斩有轮**，方能出离
    ├─ **还灭不是把什么打碎**：看清「我所爱的，究竟是哪一种受、那样的受可否依止」，
    │   爱自然松了一分；一分一分地松，还灭就从这里开始
    ├─ 解脱不是逃到哪里去：就在当下这一念「受缘爱」里，**不再被自动带走**
    └─ 能停一停，就是希望在的地方：看清机制是修行的起点，不是给自己定罪
```

**本周要点**

1. **三世两重因果**＝两条链子首尾相接：过去（无明·行）→ 现在（识·名色·六入·触·受）；现在（爱·取·有）→ 未来（生·老死）。第一重以无明为根本、受为终结，第二重以爱为根本、老死为终结。
2. **两重并说的用意**是同时根除二边：破断见（果报有因而生，非偶然）＋破常见（此生识名色终归坏灭，无灵魂永生）。
3. **二八二支与三时**：过去二支（无明·行）／现在八支（识·名色·六入·触·受·爱·取·有）／未来二支（生·老死）。
4. **两种有轮**：践行者（见解坚固、靠控制完成）以无明为根本；爱行者（贪图享受）以爱为根本。其余生方式亦两分：胎生者渐次发育（羯罗兰→三十种色→六根出现），化身者结生一刹那五蕴同时具足。
5. **三连接**：行→识（因果连接 · 业→果）· 受→爱取有（果因连接 · 果→烦恼）· 有→生（因果连接 · 业→果）——「因果因而有三连接」。
6. **二十行相有轮**：过去五因 · 现在五果 · 现在五因 · 未来五果，合共二十行相；所谓轮回，就是「遇到果报 → 作出反应」被重复了无数次。
7. **缘起图八圈四象限**：内圈无明与爱为轮回根本；第一象限过去因与第三象限现在因属集谛所摄，第二象限现在果与第四象限未来果属苦谛所摄。
8. **三轮转**：烦恼轮转（无明·爱·取）· 业轮转（行·业有）· 果报轮转（识·名色·六处·触·受·生·老死）；只要烦恼轮转未断，有轮就持续滚动。
9. **唯一下手处——受缘爱**：过去已不可及、未来尚未到来，三处连接里只有「受→爱」是当下可碰的；面对果报应如理作意。
10. **受凭什么引生爱**：过去爱是轮转的根；果报受以亲依止缘为爱之源（是助缘不是「生」）；非果报受以俱生·无间·亲依止为缘。现行爱分觅求爱与觅得爱。
11. **九种次第**＝寻求→得→抉择→欲贪→耽着→固执→悭吝→守护→执持刀杖，全从爱出发；**四种胜解**＝智·贪·见·寻思。
12. **从缘起看解脱**：以观智断见与爱、以智剑斩有轮；还灭不是把什么打碎，而是看清后自然不取——解脱就在当下这一念「受缘爱」里，不再被自动带走。

## 🧘 静心开场（10 min）

> 💬 **破冰｜3–5分钟**：此刻你身上的温度、心情和念头，都是过去留下的果；而你接下来做什么，又会成为新的因。说说现在的你正处在什么样的「果」里？

> 🛡️ **心理安全三约定**（每次开场在心里过一遍）：① **保密**——这里说的话不出这间屋子；② **不评判**——不评价任何人的分享，也不急着评价自己；③ **可随时暂停**——任何时候觉得不舒服，都可以停下来休息、喝水或离开，不需要解释。

**主持人引导语**（照读即可）：

请大家轻轻坐好，背脊自然挺直，双手安放在腿上，眼睛微闭，或轻轻下垂。先做三次深长的呼吸，慢慢把一天的忙碌放下。

现在，把注意力带回到呼吸。吸气，知道自己在吸气；呼气，知道自己在呼气。不去控制它，不去调整它，只是陪着它。

静下来之后，我们轻轻做一件事：回顾今天。今天，一定有某一件「果报」来到你面前——可能是一句话、一个眼神、一个消息、一次身体的感觉。它来的时候，你心里先有了一点感受：舒服、不舒服，或者不苦不乐。请挑一件今天就发生的，慢慢回想。

想起来了，就停在那里。看清楚：先有的，是那个「受」——舒服还是不舒服；接着，几乎是同时，心里有了一股力量，想要什么、想推开什么、想说什么、想做什么。那一股想要动起来的力量，就是今天我们要温柔地认识的——「爱」和「取」。

不用急着评价自己。只是看见：一个果报来了，一个受起来了，一个爱、取跟着来了，于是我又造了一个新的「行」。一条链子，就在我身上转了一圈。这一圈，就是「三世两重因果」里的第二重——现在因，正在为未来种下果。

如果你愿意，可以再往前追一步：这一串反应里，有没有一个「我」在？还是说，只是「受」生了，「爱」就跟着生？不必急着回答，只是轻轻地看。

好，现在把注意力放回呼吸，安安静静地坐一会儿……（静默约 3 分钟）……

**★核心段落**（必读）

各位贤友，这一周我们把十二支合起来看。前面几周，我们一支一支地认过：无明、行、识、名色、六入、触、受、爱、取、有、生、老死。今天我们要看的，是整张图——十二支怎样按「过去、现在、未来」排成三时，怎样串成两条因果链，又怎样在三个地方咬合起来。请先记住一句话：轮回，不是因为有一个「我」在走；而是这十二支「此有故彼生」地，一连接一连接地滚下去。这一段材料偏论典，名相多、结构多，听不懂的地方允许它先过去，只要抓住「两条链子怎么接、三个地方怎么咬合」这一件事就好。

### 一、三时与两重：十二支怎样排成过去、现在、未来

十二支并不是挤在一处，按《清净道论》的说法，要按「三时」来安立。所谓三时，就是过去、现在、未来。过去的两支，是无明与行；现在有八支，是识、名色、六入、触、受、爱、取、有；未来的两支，是生与老死。两者与八者合起来，正是十二支。

为什么要分成三时？因为这条链子其实是两条因果链首尾相接。第一条，是过去因结出现在果：过去生的无明与行，感得这一生的识、名色、六入、触、受。第二条，是现在因结出未来果：这一生的爱、取、有，又感得未来的生与老死。请特别留意：这不是一条直线，更不是「一个我」从过去走到未来；而是两重因果，一环扣一环地接续下去。

所以三时的分法，是理解整张图的第一步。它把「因」和「果」按时间分开，我们才看得出：哪一段是过去已经种下、现在只能承受的果；哪一段是此刻还在手上、还能作主的因。分不清这三时，就很容易把「果」当成自己的过错，也容易把「因」当成命中注定。分清了，心就有了着力的地方。

### 二、第一重因果：以无明为根本，以受为终结

先说第一重。过去生的无明与行，是这一期生命果报的根；由它一段一段地相续：无明缘行、行缘识、识缘名色、名色缘六处、六处缘触、触缘受。所以这一重，是以无明为根本、以受为终结。

《清净道论》有一句偈颂：「彼之无明、爱为根，过去等而有三时，以诸支中之同类，而有二支与八支。」它说的就是这件事：整条有轮，是拿无明与爱这两个根本来安立的。第一重，从前际带来果报，所以以无明为根本；一路推下去，到了「受」为止。换句话说，我们这一生从出生到此刻所领受的一切，都含在「识、名色、六入、触、受」这五个果报支里。

### 三、第二重因果：以爱为根本，以老死为终结

再说第二重。这一生的爱、取、有，是未来的因；由它推向后继：受缘爱、爱缘取、取缘有、有缘生、生缘老死。所以第二重，是以爱为根本、以老死为终结——它说的是「与后继相连」。

把两重并排看，就明白了：第一重从「过去」看向「现在」，第二重从「现在」看向「未来」。过去已不可及，未来尚未到来；而两重都把中间这一点——现在——圈在里头。所以这张图真正的重心，并不在遥远的过去或未来，而在我们此刻的受、爱、取、有。修行要使劲的地方，也正在这一点上。

### 四、二八二支：过去二、现在八、未来二

把三时的分法数一数，就是「二八二支」：过去二支，是无明、行；现在八支，是从识开始的识、名色、六入、触、受、爱、取、有；未来二支，是生、老死。二加八加二，正好十二支。

为什么要记住「二八二」？因为它把「现在」的范围一次点清了：属于现在时的，竟然有八支之多——这就提醒我们，十二支里大半的戏，都发生在此生；无明与生老死只各占两头。换句话说，缘起并不是一部只讲前世来世的玄谈，它的主舞台就在当下这一生，就在我们每天的识、名色、六入、触、受、爱、取、有里面。

### 五、两种有轮：践行者以无明为根，爱行者以爱为根

同样是这条有轮，《清净道论》却依两种人，各说一遍。第一种，依「践行者」说：以无明为根本、以受为终结。第二种，依「爱行者」说：以爱为根本、以老死为终结。

什么叫践行者？就是见解很坚固、往往也比较「聪明」的人。他会坚固地执持某一种看法；而这种执持只要会导致愁、悲、苦、忧、恼生起，它都是无明。禅修里有一种「高智商综合征」：紧张、抓取、控制。这样的人在世间往往有过许多成功，被人高度评价、被多人关注，于是对那份愉悦执取而生爱，爱又变成执取——这执取就是邪见：「凡到我面前来的事，我都能通过控制来完成。」可禅修是自然如实的，一旦不如实，就想「我要控制」，这就以他的「见」为根。所以他以无明为根本。

什么叫爱行者？就是比较贪图享受的人。他要么去贪着色、声、香、味、触，要么就贪图「我躺平了算」。他的见解不多，你说怎样都行，反正得让他乐呵——所以他的轮回以「爱」为根本。经典里，践行者与爱行者、瞋行者与贪行者本是分开讲的，这里为了方便，大致对应地说。

### 六、两轮并说，为同时破除断见与常见

《清净道论》进一步说明：为什么同一个轮回，要分两种方式说？因为要说给两种毛病听。

第一种有轮——以无明为根本——是为了根除断见。它的道理是：这一生的识、名色、六入、触、受，这个「果」是有原因才生起的；因是什么？是无明、爱、取、行、业这些「因」。由果的生起，反过来显明诸因的不断。于是那些认为「生命是偶然出现、是父母精卵结合的偶然现象、是无因开始」的断见，就被根除了。

第二种有轮——以爱为根本——是为了根除常见。它的道理是：已生的识、名色、六入、触、受，终究会老、会死；这一生的爱、取所导致的下一生结生，也一样会坏灭。于是那些「灵魂说、梵我说、有生等」以为有个恒常之我的常见，就被根除了。

所以两轮并说，用意是同时破二边：由「果从因来」破断见，由「终归坏灭」破常见。这也就回答了最初的疑问——轮回里，既不是「有一个我越世延续」，也不是「死后什么都没有」；而是「没有一个我，却仍然相续」。

### 七、胎生者与化身者：结生的两种次第

还有第三种分法：依「胎生者」说第一种有轮，依「化身者」说第二种。

先说胎生者。像我们人类，是十月怀胎、渐次发育。父母准备好一个受精卵，而你的无明、爱、取、行业刚好与这个家庭相契合，你的业就在那个受精卵上生起一个结生名色——这个入胎的结生名色，过去叫「羯罗兰」，小得只有头发丝尾尖那么大。最初结生的色法，有心所（心色）十法聚、性根十法聚和身净色十法聚，合起来只有三十种色法。然后慢慢发育：心脏先发育，接着肢体发育，六根出现——走的是「名色→六处→触→受」这样的次第。这就是胎生者的情形，能显明诸法的次第转起。

再说化身者。像天人化生：这一生死了，以善业在天界生起，不论色界天还是欲界天，在结生的那一刹那，若是五蕴的生命，五根就同时具足，五蕴同时生起，不经渐次发育。这能显明「所生诸蕴的一同生起」。「有」直接产生「生」，而这个「生」，就是五蕴同时具足。

### 八、三连接：轮回的三个咬合点

三时之外，《清净道论》又说：「此有轮以过去因果，因而有三连接。」三连接，就是这一圈轮子上的三个咬合处。

第一处，行与识之间，是「因果连接」：过去的业行，导致这一生的结生识生起——业（行）是因，果（识）是果。

第二处，受与爱之间，是「果因连接」：这一生由「受缘爱、爱缘取、取缘有」。受是果报；每天我们遇到一个果报，就对它采取行动——遇到果报、采取行动，再遇到、再采取。这个行动不是善的，就一定是不善的，没有中间状态。所以它是「果」（受）生起「因」（爱、取、有）的连接。

第三处，有与生之间，是「因果连接」：所造之业在临死时成熟，导致未来结生；从死亡到结生，也是业成熟——业（有）是因，果（生）是果。

三处连起来，就是「因果、果因、因果」，所以《清净道论》说「因果因而有三连接」。请记住一处特别重要的：三连接里，唯有第二处「受→爱」，是此刻就在眼前的。

### 九、二十行相有轮：过去五因 · 现在五果 · 现在五因 · 未来五果

除了三连接，《清净道论》还把这一圈铺成一张更完整的图，叫「二十行相有轮」，也就是把十二支在三世两重因果上完全展开。

具体说：过去有五因——无明、爱、取、行、业（「无明」里含着爱、取，「行」里含着业有）；由这五因成熟，感得现在的五果——识、名色、六入、触、受，也就是我们这一生全部的果报。而现在这一生，又在造现在的五因——同样是无明、爱、取、行、业；这五因成熟，就结出未来的五果——下一生的识、名色、六入、触、受；而生、老死、愁、悲、苦、忧、恼，也就摄在这五果之中。过去五因、现在五果、现在五因、未来五果，四类各五，合起来正好二十行相。

这里有一个容易误解的地方：既然「无明」被列在过去五因里，是不是说无明只属于过去、跟现在没关系？不是的。现在五因里的「爱」与「取」，本身就与其相应的无明同在；而「有」也涵盖着它前分的「行」。所以无明、爱、取并不是三个各自独立的东西，而是同一股「不明真相而伸手」的力量的三种作用。明白了这一点就知道：根除无明，不是要回到过去把它挖出来，而是在当下每一个「受缘爱」的地方下手。

所以把二十行相认下来，不是为了背，而是为了认出：所谓轮回，不过就是「遇到果报→作出反应」这一件事，被重复了无数次。二十个行相里，真正「此刻正在发生」的，是现在五因——无明、爱、取、行、业；真正「只能承受、不能挑选」的，是现在五果——识、名色、六入、触、受。看清这个区分，我们也就知道该把力气放在哪里了。

### 十、收束：这一圈，就在我们身上

各位贤友，上篇我们就读到这里。

请记住几句最朴素的话：第一，十二支按三时分成过去二支、现在八支、未来二支，串成「过去因→现在果、现在因→未来果」两重因果。第二，这两重因果上有三个咬合点——行→识、受→爱取有、有→生，合称三连接。第三，把它们完全展开，就是「过去五因、现在五果、现在五因、未来五果」的二十行相有轮。第四，轮回不是有一个「我」在走，而是「遇到果报、作出反应」这件事，被重复了无数次。

还有两句，是这张图的「骨头」：一是「两种有轮」——践行者以无明为根、爱行者以爱为根，两种说法合起来，同时破掉断见与常见；二是「胎生者与化身者」——同一件事，从渐次发育与一时具足两个角度看，都能成立。这些都不是要你记住多细，而是要你看见：这张图既不落空，也不落一个「我」。

把「轮回」这个词，落成一句大白话，就是：遇到果报，作出反应；这个反应又成为新的因，再结出新的果——如此重复了无数次。我们过一天，其实就是这张图转过了一圈。

1. **「三世两重因果」到底在说什么——为什么它不是「一个我」从过去走到未来？**
   - 追问路径：先请一位学员用自己的话说出「二八二支」（过去两支＝无明、行；现在八支＝识到有；未来两支＝生、老死）→ 再追问：若说「过去的我」就是「现在的我」，会落入哪一种见？（常见／灵魂说）若说「过去的业跟我毫无关系」，又落入哪一种见？（断见）→ 落到：佛陀用「两重因果」正是为了同时根除断见与常见。
   - 操作提示：可补一句——第一种有轮「为根除断见」而说，第二种「为根除常见」而说。所以「三世两重因果」不是「有一个人在轮回」，恰恰是「没有一个人，却仍然相续」。

2. **三个连接点，今生我们能下手的究竟在哪一个？为什么？**（本周重点）
   - 追问路径：先请学员分别说出三个连接——（一）过去行→现在识（因果连接）、（二）现在受→爱取有（果因连接）、（三）现在有→未来生老死（因果连接）→ 追问：第一个连接，过去的业我们看得见、控得住吗？（看不见，也控不住）第三个连接，是一期生命结束时才成熟，当下能改吗？（只能等果）→ 只剩第二个——「果报受引生爱取」，是每天都在发生、就在眼前的。
   - 操作提示：落到《清净道论》那句「我们真正今生能下手的，关键其实是受缘爱」；不必现场展开二十四缘。

3. **「每天遇到果报，就动手」——请各人举一个今天真实发生的例子，找出背后的「欲取」还是「见取」。**
   - 追问路径：请学员描述一次「遇到一件事→立刻反应」的片段 → 追问：这个反应，是「我想要那个感觉」（欲取），还是「我认为应该这样」（见取）？→ 再追问：那个「爱」后面，你真正想要的是哪一种「受」？如果那个受得不到，会怎样？
   - 操作提示：可给一个小口诀——**「只是想做」＝欲取；「必须这样才对」＝见取**，请学员各举一例对号入座。

**备用深水问题（时间富余时）**：既然「现在五因」里也隐含了无明，那「根除无明」是不是就不必回到过去？请回到资料第九节，说说你的理解。

> **分层追问**（可视时间取用，由浅入深）：
> - 【现象】今天你享用到的一件事，其实是更早时候的付出换来的——是哪一个？
> - 【影响】如果今天的行动正在为将来写下因，你对「此刻」的分量感受如何？
> - 【应对】这周挑一件每天都做的小事，有意识地做一次，把它当成给未来的播种。

### 讨论常见误区与应答（主持人备用）

- **误区一：「三世两重因果＝宿命论」**。应答：五果（识、名色、六入、触、受）确实是过去业所感的果报，这一部分不能改；但「现在五因」（爱、取、有）正是你现在正在造作的——**果报不能改，对果报的反应可以改**。所以「相续」不等于「注定」，关键就在第二个连接点上。
- **误区二：「既然无我，那是谁在轮回？」**。应答：不是「有一个我在轮回」，也不是「没有相续」；而是「因缘的相续」——像灯焰，前一念灭、后一念生，不是同一团火，也不是凭空而来。这正是「两重因果」要**同时**破掉的断、常二见。
- **误区三：「过去世的业我又看不见，讲它有什么用？」**。应答：资料自己就说了——过去的无明和行，你根本无从了知。立「三世两重因果」，不是为了让你去查前世，而是为了让你看清「现在因→未来果」这一条当下可控的链子。看得懂过去，是为了知道现在该在哪里松手。
- **误区四：「那是不是要压住感受、不许有爱？」**。应答：不是。方法不是把感受压下去、也不是骂自己「怎么又贪了」，而是看清你爱的是哪一种受、那个受有什么过患，于是自然地削弱——「看到所受，比急着消灭爱更有效」。

**★核心段落**（必读）

各位贤友，下篇我们来看一件最切身的事——从缘起看解脱。上篇我们把整张图摊开了：两重因果、三连接、二十行相。下篇要接着回答两个问题：第一，这一圈轮子，究竟靠什么力量闭合、转个不停？第二，在这张图里，我们此生真正能下手的，是哪一个地方？请带着这两个问题往下听。这一段会讲到「老死、衰变、轮回」，听起来也许有些沉；请记得，我们今天不是来看自己有多么走不出来，而是来找到那个可以踩刹车的地方。

### 一、缘起图：八个圈与四个象限

先看一张大家可能见过的图——「缘起图」。它在世界各地被翻译成各种语言，画的是同一个轮回。这张图最外围有八个圈（依本讲所用缘起图；不同版本图式略有差异），从最里的无明一直转到最外，整体又分成四个大区域。

四个区域，对应三时两重因果的四个部分：第一象限，是过去因——过去生的无明与行；第二象限，是现在果——这一生的识、名色、六入、触、受；第三象限，是现在因——当下的爱、取、有；第四象限，是未来果——未来生的生、老死。我们上篇讲的「二八二支」「两重因果」，到了这张图上，就变成四个清楚的分区。看清分区，是为了明白：哪些是我们只能承受的果，哪些是此刻正在造的因。

再对一对「谛」的归属，就更有味道了：第一象限（过去因）与第三象限（现在因），都是「集谛所摄」——它们是苦的原因；第二象限（现在果）与第四象限（未来果），都是「苦谛所摄」——果报只要出生，就不圆满、低劣、会坏掉，这就是苦。所以这张图其实在说：凡是「因」，都落在集里；凡是「果」，都落在苦里。看懂了这一点，也就看懂了这个轮子为什么一直在苦与集之间打转。

### 二、内圈的两个根本：无明与爱

这张图最内层，画的是无明与爱——它们代表轮回的两个根本。

图上用「过去世的无明与行」「现在世的爱、取、有」来体现这两个根本：无明，用过去「无明缘行」的那个无明代表；爱，用这一生「受缘爱」的爱与取代表。这里要补一句：受缘爱这一处，其实也是有无明的；而无明缘行，也要有爱、取，才有行——只是图上简说而已。所以无明与爱并不是两个互不相干的东西，它们是同一股力量在「过去」与「现在」两个端上的名字。看清这一点，就能理解《清净道论》为什么把整条有轮，都建立在「无明与爱为根」这一句话上。

### 三、三轮转：烦恼轮转 · 业轮转 · 果报轮转

十二支还可以收成三个圈。过去世的无明，加上今生的爱与取，这三个合起来，叫「烦恼轮转」；过去世的行，加上今生的业有，这两个合起来，叫「业轮转」；今生的识、名色、六入、触、受，加上来生的生、老死，这些叫「果报轮转」。

《清净道论》有一段话说得很清楚：「当知于此三轮转滚动不息中，行有时是业轮转；无明、爱、取是烦恼轮转；识、名色、六处、触、受是果报轮转。」这三个轮转互相咬合，就构成了「有轮」。请把它记成三个圈：烦恼圈、业圈、果报圈。我们每天其实就在这三个圈里打转：先有烦恼，烦恼推动造业，业的果报又成熟为身心，果报里又生出新的烦恼——如此循环。

这三个圈，各归其位，重要的一点是：果报圈与业圈里的东西，多半已不由我们分说；而烦恼圈里的无明、爱、取，恰恰是此刻还在造作的地方。所以要看清一件事——把这三圈分清，不是让我们去怨果报、去恨过去的业，而是让我们知道：真正能动的那一处，就在烦恼圈里。看清三圈，是为了把力气用对地方。

### 四、只要烦恼轮转未断，有轮就滚动不息

三个圈里，哪一个最要紧？是烦恼轮转。

《清净道论》说：「以此三者轮转而有三轮转的有轮，只要尚未断除烦恼轮转，就应持续不断，支援而不息，又因一再转动而滚动。」意思是：业轮转与果报轮转，都还算是「转动」的环节；真正让这个轮子停不下来的力量，是烦恼轮转——无明、爱、取。它一转，就去推业轮转；业轮转一转，就成熟果报轮转；果报轮转里又长出新的烦恼，再推下一轮。所以只要无明与爱还没断，这个有轮就一直转、一直转，不会自己熄灭。这就给了我们一个重要的提示：修行要用力气的地方，不在「果报」那一圈，也不在「已经造下的业」那一圈，而在「烦恼」这一圈——尤其在那个当下还能作意的烦恼里。

### 五、唯一下手处：第二重连接上的「受缘爱」

那么，具体到这张图上，哪一处是我们今生能下手的？《清净道论》又讲「三连接」。

第一重连接，是过去生的行，和这一生的识——过去的业（业轮转）导致这一生的果报轮转生起。第三重连接，是今生的业有，和来生的生、老死——这一生的业，导致未来的果报轮转生起。这两处，一个在过去、一个在临终与来生，此刻我们都碰不到。

第二重连接，是今生当下的受，引发爱、取、有——每天坐在这里，眼睛看到的、耳朵听到的而产生的感受，就是果报受；由此引发爱、取、有。这是「果报轮转」导致「烦恼轮转」生起。每一个当下，我们就是这样：接受一个果报，然后根据这个感受，做出无明、爱、取、行、业这样的行为。三个连接里，只有这一处，是此刻就在我们眼前的。

所以《清净道论》反复强调：无明与爱、取是轮回的根本；而过去的无明与行已经过去了——对我们现在来说，如果还没修到观智，它不但不可控，而且根本无从了知。这正是佛法里最深奥、也最让人下不了手的地方：过去的业，跟我们这一生到底是什么关系？看不见、无从了知，于是许多疑惑就卡在这里。可是，好在还有「受缘爱」这一处，就在第二重连接上。所以我们真正今生能下手的，关键就是它。也正因为如此，面对果报的时候，应当如理作意。

### 六、过去爱与现行爱：受凭什么引生爱

「受缘爱」这三个字，还要再拆细一点看。根据《中部·大因缘经》的译注，这个「爱」有过去爱与现行爱两种。佛陀说，过去爱是轮转的根——过去的爱，导致我们现在的爱生起；而现在这个爱，对于未来而言，它又成了过去爱。所以爱也是相续的。

那爱从哪里来？爱之源是受。这里要分清两种受：一种是果报受，它以「亲依止缘」为爱之源——受是果报，它不能直接「生」爱，只能作为强有力的助缘；另一种是非果报受，也就是速行上的受，它以「俱生、无间、亲依止」等为爱的缘——速行上的受若与贪相应，就与贪俱生；速行与速行之间，是「无间」。当然，过去的爱也依然以亲依止缘为爱之源。

这里的关键是：受是果报，多分不由我们挑选；而爱发生在速行里，是心在造作的地方。所以「果报如此，速行可变」——我们能作意的，正是那个快要被爱牵走的一念。

### 七、从爱到一切恶不善法：九种次第

那现行爱生起时，是什么样子？佛陀用一句话形容：它「有如被揪发，令人嚎叫而偏离一向之路径」——也就是说，现行爱生起时极难控制，人往往会一头扎进去。

佛陀还用九个词，把现行爱一路展开，叫「九种次第」：寻求、得、抉择、欲贪、耽着、固执、悭吝、守护、执持刀杖。翻译成白话：因为有所爱，就去找寻；找到了，就得到；得到之后心里开始掂量取舍；取舍定了，倾向越来越强，成了欲贪；得到了就耽着不放；耽着久了变成固执；固执进而悭吝，不愿分享；悭吝便要守护，严防失去；守护不住，最后竟至于执持刀杖而相争斗。

这条线不是夸张，也不是宣判，只是把一件天天经历的小事从头摊开——从「想要」到「争执」，都在重演同一条线，而它的起点小得几乎看不见，就是一次「寻求」。所以不必等到闹到「执持刀杖」才后悔，而可以在最早的「寻求」那一端就松手。你可以问问自己：这条线上，你最容易在哪一步被带走？看清那一步，那就是你的下手处。

顺带认一认「抉择」这一环里的「四种胜解」：胜解就是抉择。有智胜解——知道乐以及乐之因，照它去做而得将来的乐，这是自觉者；有贪胜解——基于一百零八种贪而作的抉择；有见胜解——依六十二种邪见而作的抉择；还有寻思胜解——以寻思斟酌可欲不可欲、「我将享用、我将储藏」之类。

### 八、觅求爱与觅得爱：以受为突破口

现行爱还可以再分两种。一种叫「觅求爱」：为了追求某种受用而四处奔走，像走在羊肠小道上。另一种叫「觅得爱」：已经求得受用、正在享用之时生起的爱。两种爱，都是为了某一种感受而追求。

那么具体从哪里下手？关键在「受」。一切五蕴之法，都要通过受来体验——看到的、听到的、想到的，最后都落成一个「受」。所以爱与执取追到底，都是因为我们倾向某一种受：想要舒服的受多一点，想要不安的受快走开。这就是「受」是门口的原因——看得住受，就看得住后面那一大串，从寻求一直到执持刀杖。

这里要特别说明：方法不是把感受压下去，也不是爱一起就骂自己「怎么又贪了」。有用的做法，是去看「我所爱的，究竟是哪一种受？那样的受，能不能依止？」看清了，爱自然松了一分；一分一分地松，还灭就从这里开始。

为说明这种颠倒有多深，经典用了几个譬喻：盲人失足——看不见路的人一脚踏空，不知险在何处；饮用盐水增渴——越喝越渴，以为在解渴，其实在加渴；鱼因贪饵咬钩——为着一点饵食，咬上的却是钩。它们说的是颠倒，不是宣判：把那么一点「受」当成可依靠的，是多么不可靠。

### 九、从缘起看解脱：以智剑斩有轮

看清了轮回怎么转、在哪里下手，最后要回答：解脱的路在哪里？

帕奥西亚多在《观察缘起》里讲得直接：以「观智（毗婆舍那智）」断除「见」与「爱」这两种根本，如以「智剑斩有轮」，方能出离。请留意这里的工具是「智」，而不是「意志」——不是下决心「我不要再爱了」，而是看得足够清楚，让执取自然失去力量。见与爱，正是上面两种有轮、两个根本所对应的东西；断除它们，轮子才真正停下来。

这也正是「还灭」的意思：不是把什么东西打碎，而是看清之后自然不取——看清那只是一个果报、那只是一个受，后面那个「要」，就没有那么非伸不可了。解脱不是逃到哪里去，而是在当下这一念「受缘爱」里，不再被自动带走。

经典里还有一句分量很重的话：不悟缘起，则不得解脱。换句话说，我们这一路学的这张图，不是知识，而是出路。落到每天的生活，这条出路就是八正道落于日常——对自己、对他人、对事情、对饮食，都能如实去看，而不是自动反应。

### 十、收束：能停一停，就是希望在的地方

各位贤友，下篇就读到这里。把今晚收成三句话：第一，轮回是靠烦恼轮转（无明、爱、取）闭合的——只要它不断，有轮就一直滚。第二，三处连接里，只有「受→爱」是此刻能碰的，这就是今生的下手处；面对果报，应当如理作意。第三，还灭不是把什么打碎，而是看清之后自然不取——以智剑斩有轮，不悟缘起则不得解脱。

请带一句话回家：受来了，不必赶它走；爱升起了，不必骂自己；只要在它们之间，留一个呼吸的空间。真正要带走的，是下一次一个「受」起来、手要伸出去的那一瞬，你能停一停、看一眼。能停一停，就是希望在的地方。

也请记得：这一周讲的，不是一套让人更灰心的道理。看清机制，是为了让希望有落脚之处——不是等到把整条链子拆完才叫修行，而是下一次一个受起来时，你能多看一眼。能看见那只手，就已经和从前不一样了。愿你把这一眼，带进下一杯茶、下一句话里。

（下篇完）

## 💬 第二轮分享（10 min）

**分享规则**：本轮只谈「感受与体会」，不谈义理对错；每人 1–2 分钟，主持人计时；可以只说一句「我今天的发现是……」；不愿分享的可以举手跳过，静静听着也是参与，**尤其是本周涉及老死、衰变，任何人都有权保持沉默，沉默不等于不参与**。分享时请尽量用第一人称描述「我身体的感觉」「我当时的反应」，避免对他人或事情的评判；若涉及他人隐私，请只讲自己的那一半。

请就以下问题，任选一个分享：

1. 读或听「三轮转」这一张图，你心里第一反应是什么？是觉得复杂，还是觉得它说中了什么？请只描述你当下的感受，不必讲义理。
2. 听到「受缘爱是今生唯一能下手的地方」这一句，你心里是松了一口气，还是有点沉重？请说说那一刻你真实的反应。
3. 今天静心时，当你回想到那个「很舒服」或「很不舒服」的时刻，有没有一丝「想要它多一点／想让它走开」的微细倾向？它出现得快还是慢？你能在身体哪里感觉到它？

> 本周是收束课，也是「有情绪的一课」。请主持人把节奏放慢一点：每人分享前先说一句「不急着有答案」，分享后不点评、不总结，只回应一句「谢谢你让我们听见」。若全场都很安静，也不必硬找话题——安静本身，就是这一课的一部分。

> ⚠️ 主持人操作：先请平时少发言的人，再请活跃的人；**明确宣布「今天讨论老死、衰变，可以沉默、可以只听」**。若有人开始讲很长的故事、或滑向「我怎么这么放不下」的自我责备，温和打断并转向：「我们先把镜头拉近到身体的那一处感受，好吗？看清它就是收获。」

## 🎯 第二轮主题讨论（10 min）

本周讨论请「慢而深」，宁可只把第 1 问谈透，也不要把三问都走马观花。开始前先说一句：今晚我们谈的是「机制」，不是「对错」。

讨论问题（按优先级）：

1. **轮回的回路，是在哪一环闭合的？** 资料说：无明、爱、取是烦恼轮转，行、业有是业轮转，识、名色、六处、触、受与生、老死是果报轮转；只要烦恼轮转未断，有轮就持续滚动。
   - 追问路径：请一位学员用「刚才的一次不愉快」举例，一起在图里标出：哪一段是果报（不由己）、哪一段是烦恼、哪一段是业？——引导到「轮回不是外面有个轮子，是我此刻的受→爱→取→业在转」。
   - 可再补一问：三轮转里，哪一轮是你此刻最能认出来的？看清这一点，会让你更沮丧，还是更有希望？引导到「看清机制＝修行起点」。

2. **过去世的因看不见、下不了手，那今生到底能在哪一环下手？** 资料说：无明、行已经过去，若未修到观智，不可控也无从了知；真正今生能下手的关键，是「受缘爱」——在第二重连接上。
   - 追问路径：请一位学员举「被一句话惹恼／被一句赞美说动」的例子，一起标出：哪一个是受（不由己），哪一个是爱（可作意）？——引导到「受不是『我』，爱也不是『我』，但爱正是我们能看清、能作意的地方」。
   - 可追问九种次第：从寻求、得到、抉择，到欲贪、耽着、固执、悭吝、守护、执持刀杖——你最容易在哪一步被带走？看清那一步，就是你的下手处。

3. **看清轮回的颠倒，与「解脱」是什么关系？** 资料用盲人失足、饮用盐水增渴、鱼因贪饵咬钩等譬喻说生死，又说「爱和执取，都是因为我们倾向某一种受」，所以要去看到「你所爱的是什么样的受、那样的受可否依止」。反过来，帕奥西亚多说：以观智断见与爱、以智剑斩有轮，方能出离。
   - 追问路径：请大家比较「沉溺」与「看清」两种状态的区别，问：不急着消灭爱，先看清「我爱的其实是那种受」，会不会已经松了一分？——引导到「还灭不是把什么打碎，而是看清后自然不取」。
   - 可再补一问：把「解脱」想成一个遥远的大目标，和想成「今天在受与爱之间停一次」，哪一种更让你愿意当下就试？收束时把话带回「当下可操作的受缘爱下手处」。

> **分层追问**（可视时间取用，由浅入深）：
> - 【现象】回想这周，什么时候你感到「受」一起来，就自动被牵走了？
> - 【影响】如果过去已经改不了，把力气放在「感受生起」这一环，你怎么看？
> - 【应对】这周在感受最强烈的一刻，只做一件事：认出「这是一个感受」，别的先不做。

> ⚠️ 主持人操作：第 1 问是本周的「眼」，务必留足时间；第 2 问是本讲的落点，不能只停在「我下不了手」的无力感，要落到「受一生、爱未成时，我能看它一眼」；第 3 问涉及解脱，容易滑向恐惧或空谈，要随时把「这是观察，不是定罪」带回现场。若第 3 问触及生死话题、全场忽然安静，不必强行填满——可以说「我们先安静一分钟，再请愿意的人说一句」，把沉默也当作参与。

## 🔚 收尾与回向（15 min）

**总结引导**（主持人用自己的话串讲，不必照读）：

今天我们只做了一件事——把十二支合起来，看它在自己身上怎么转。我们用《清净道论》的「三世两重因果」看见：过去五因结出现在五果，现在五因又结出未来五果；用「三连接」看见三个轮子怎样咬合：过去行→现在识、现在受→爱取有、现在有→未来生老死；用「二十行相有轮」看见「过去五因、现在五果、现在五因、未来五果」这一张完整的循环图。而在这三个连接里，唯一当下就在我们眼前、每天都在发生的，是中间那一个——果报受引生爱取。所以资料才反复强调：今生能下手的，是「受缘爱」；面对果报时，应当如理作意。

请带一句话回家：**轮回，不在遥远的过去或未来，它就在「一个受起来、我立刻伸手」的这一瞬间**。看见这一瞬间，就是松动的开始。看清楚那个「爱」后面你要的是哪一种「受」，比急着压下那个念头更有力。

也许今天你还不能立刻做到「不伸手」——没关系。能看见那只手，就已经和从前不一样了。修行不是一次到位，而是一次一次又一次地，把那个「自动」慢慢变成「知道」。

我们今晚没有要求你「不要爱」、也不要求你「马上断轮回」。资料说得很实在：爱和执取，都是因为我们倾向某一种受，所以真正有用的，是去看「我所爱的，是什么样的受？那样的受，能不能依止？」看清了，爱自然就松了一分；一分一分地松，「还灭」就从这里开始。这就是「从缘起看解脱」——解脱不是逃到哪里去，而是在当下这一念「受缘爱」里，不再被自动带走。

**本周核心回顾（可板书，收尾前 1 分钟带大家念一遍）**：

1. **两重**：过去（无明·行）→ 现在（识·名色·六入·触·受）；现在（爱·取·有）→ 未来（生·老死）。
2. **三连接**：行→识（业→果）、受→爱取有（果→烦恼）、有→生（业→果）。
3. **一个下手处**：三处连接里，只有「受→爱」这一处是当下可碰的——这就是「受缘爱」。
4. **一句话**：果报来了，不必改果报；改的是它来了之后，你伸不伸手、伸手时清不清楚。

**四周回顾与结语**：四周里，我们认了十二支、看了三世两重因果、把轮回收成三轮转——无明、爱、取是烦恼轮转；行、业有是业轮转；识、名色、六处、触、受、生、老死是果报轮转。只要烦恼轮转没断，这个有轮就一直转、一直转。今天我们把它们收成一个环，又在环上找到了一个可以停一停的地方。请记得，这不是结束，而是一种新的开始。愿这四周的学习，成为大家日后如实观察缘起的一点灯；这个系列的共读到这里告一段落，后续若有「缘起深入与二十四缘」的课程，欢迎愿意继续的朋友一起来（本周只讲三世两重因果与二十行相，二十四缘各缘的展开属于下一阶段）。

**给主持人的一句话**：本周讲到老死、衰变，气氛容易沉。请你在收尾时一定把话拉回来：我们今天做的，不是给自己宣判，而是找到了一个可以停一停的地方。**能停一停，就是希望在的地方。**

**散场前的三句轻声**（可照读，语速放慢）：
