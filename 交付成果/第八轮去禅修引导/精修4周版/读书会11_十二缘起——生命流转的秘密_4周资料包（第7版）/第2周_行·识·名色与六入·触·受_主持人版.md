## 🗺 本周知识地图

**本周走十二缘起的第二至第七支：行 · 识 · 名色 · 六入 · 触 · 受。**

一句话说清这六支的关系：**「行」是造作，「识」是果报，「名色」是身心成形，「六入」是六扇门，「触」是三者和合，「受」是三种领纳**——一路下来都在相续，却没有一个固定的「我」在搬来搬去。

```
行 · 识 · 名色 · 六入 · 触 · 受（第二至七支）
│
├─ 一、行支（第二支 · 造作）
│   ├─ 行＝「造作」，不是「行动」——是**思心所**驱使身、语、意去造业；
│   │   造作之后会留下「业的力量」，这个力量就是下一支「识」的缘。
│   ├─ 行分三种（合称 29 种思，亦称 29 种业行）：
│   │   · **福行**＝善的造作，共 13 种思——依布施、持戒等生起的 8 种欲界善思，
│   │     加上依修禅定生起的 5 种色界善思
│   │   · **非福行**＝不善的造作，共 12 种思——依杀生等不善业生起的 12 种不善思
│   │   · **不动行**＝禅定中的造作，共 4 种思——依修禅定生起的 4 种无色界善思
│   │   ⚠️ 三类共 29 种思：8＋5＋12＋4＝29。所以「以业解释行」——行造作后留下业的力量。
│   └─ 三论点证「无业则无果报」（《清净道论》设问「如何得知识以行为缘而生起？」后的三答）：
│       · 论点1【没有业则没有果报】：没有累积的业，就没有果报（业报）
│       · 论点2【有业才有果报】：此识本身就是果报，若无累积的业，果报不会生起
│       · 论点3【没有业而有果报，不成立】：若无业也能生起，则一切有情都会自动生起果报识，
│         事实绝非如此
│       ⚠️ 三答分别从「业」「果报」「作者」三个角度各推一遍，共同证明「无业则无果报」。
│
├─ 二、识支（第三支 · 果报）
│   ├─ 识＝「果报识」。这里说的不是泛泛的「心」，而是**果报心**——由过去业所感得的结果；
│   │   十二缘起支中，识·名色·六入·触·受同为「果报轮转」，故以「果报／业报」解释「识」。
│   ├─ 共 32 种世间果报识（＝89 种心中的 32 种果报心），分六识与二十二种意识：
│   │   · 眼、耳、鼻、舌、身五识各有善、不善果报两类，称**双五识**（共 10 种）
│   │   · 意识 22 种＝意界果报心 2（2 领受心）＋ 无因意识界 3（3 推度心）
│   │     ＋ 有因欲界果报心 8 ＋ 色界果报心 5 ＋ 无色界果报心 4
│   │   ⚠️ 10＋22＝32。**出世间心不属于轮回论，不计入**。
│   └─ 行缘识＝业 → 果的因果连接：业（行）是因，识（果报）是果；
│       即**过去的造作如何感得这一期生命的第一个果**。
│
├─ 三、名色支（第四支 · 身心成形）
│   ├─ 名色＝「身心」。**名**＝受、想、行三种非色法（心所；识另立一支）；
│   │   **色**＝四大种及所造色（业生色，是果报的色法）。
│   ├─ 「相续连结故，不一亦不异」：
│   │   · 「**不一**」＝上一期生命与这一期生命不是同一个生命
│   │   · 「**不异**」＝这一期生命的结生与上一期生命有关系——
│   │     你死后不会进入另一个生命相续流，一定是在**同一个生命相续流**里
│   ├─ 四喻（写清「A 喻 B」）：
│   │   · **回声**——敲钟后产生的钟声与回声不同，但并非无关，因敲钟而有回声
│   │   · **灯明**——后灯由前灯而燃，不是同一盏灯，也不是毫无关系
│   │   · **印章**——纸上的印纹不是你手中那枚印章，却因你盖印而有了印纹
│   │   · **镜像**——镜中的人不是你，却是你的影像
│   │   ⚠️ 四喻共同说明：「因声等而有回声、灯明、印章、镜像时，它们并未去到别处」，
│   │   结生心也同样如此——**不从他处来，也不无因生**。
│   │   原文又补：若完全同一，则不会因牛乳而产生凝乳；若完全相异，则凝乳就与牛乳无关。
│   └─ 十福业事（为未来增长善的资粮）：布施、持戒、禅修、服务、恭敬、说法、
│       随喜、回向、闻法、正见。以此十项增长**外功德**（利益他人）与
│       **内功德**（内心获得的丰盈与力量）——二者都是解脱的资粮。
│
├─ 四、六入支（第五支 · 六扇门）
│   └─ 六入（六处）＝眼、耳、鼻、舌、身、意**六扇门**。要点是：
│       **六入不是「我」，是六扇门**——门只是让境界进来的通道，
│       门本身没有「谁在看、谁在听」。
│
├─ 五、触支（第六支 · 三者和合）
│   ├─ 触＝**根 · 境 · 识**三者的和合。要点是：**不是「我」在触**，
│   │   而是根（六根）＋境（六境）＋识（六识）三者相遇，这个相遇就叫「触」。
│   │   原文：「只要有六入就有跟外境的接触，有触，就会有感受」——
│   │   即**门（六入）→ 遇（触）→ 纳（受）**。
│   └─ 五门心路（以眼门为例）＝**心的定则**。路心顺序固定为：
│       五门转向（1）· 眼识（1）· 领受（1）· 推度（1）· 确定（1）·
│       速行（7）· 彼所缘（2），合 14 个路心（＋3 个离路有分＝17 心识刹那）。
│       ⚠️ 这不是论师编排的，是**心的自然法则**——修名法时每一个心识刹那
│       就是这样生起的，是佛陀的伟大发现。
│       · 三个有分：色法寿命 17 心识刹那，扣掉最大路心 14 个，余 3 个离路有分，
│         依次名「过去有分」「有分波动」「有分断」。
│       · 确定心＝意门转向的确定作用，是决定善速行或不善速行的**重要转向（速行作意）**。
│
└─ 六、受支（第七支 · 三种领纳）
    ├─ 受＝三受，即触之后的「领纳」：**苦受 · 乐受 · 不苦不乐（舍）受**。
    │   因为**缘于六触**（眼触、耳触、鼻触、舌触、身触、意触），所以生起**六种受**——
    │   「由眼触缘后面的一切受」；此触不只缘眼识的受，还缘同一心路中一切心的受，
    │   即「**缘一切受**」。
    ├─ 触受非善恶，善恶在作意：触与受本身**没有善恶**，它们是果报、属**无记法**；
    │   善恶在于随后生起的**作意**——确定心若**不如理作意**，就生起不善速行；
    │   若如理作意，就生起善速行。**受是果，作意是因**。
    ├─ 无明从六门进来的路径：无明往往就在那一念「不如理作意」里进来——
    │   六扇门开着，境界进来，若不如理作意，无明与贪瞋就随之而起。
    ├─ 无明引发不善行的五种路径：
    │   ① 直接引发不善路心作意（主动朝向不该看的所缘，认为它带来快乐）
    │   ② 本意朝向善的所缘，结果确定心不如理作意（想打开佛法视频，结果不如愿而生瞋）
    │   ③ 不善果报引发不如理作意（走在街上被人撞倒，认为有个真实的我被撞到）
    │   ④ 善果报引发不如理作意（看到美丽的花而生贪，认为有真实美丽的花）
    │   ⑤ 纯粹的不如理作意（想入非非，编造贪瞋痴慢的快意人生）
    │   ⚠️ 结论：从深层次看，**「无明缘行」涉及的是整条心路**，不只是速行那一念。
    └─ 受不是终点——它正是下一支「爱」的缘起处：「**缘受而有爱**」。
       不管哪一种受（五识、领受、推度里的三十二种果报受），都会对随后升起的
       贪根心里那个「爱」，以**自然亲依止缘**为缘——苦者寻求乐、乐者更求乐，
       由寂静性故说舍为乐，所以**三种受皆对爱为缘**。
       这个爱会「爱屋及乌」（爱孩子就连带爱保姆），从单一的爱一次次地爱，
       一直变成「取」，变得很坚固。**受虽是果报、多分不由己，但它不是终点**——
       在这里停下来看清一次，就是为下周「受缘爱」埋下第一个观察的种子。
```

**本周要点**

1. 「行」是造作、「识」是果报、「名色」是身心最初的成形——这一切都在相续，却没有一个固定的「我」在搬来搬去。
2. 行＝福行（13 思）· 非福行（12 思）· 不动行（4 思），共 29 种思（＝29 种业行）；以「业」解释「行」，以「果报／业报」解释「识」。
3. 识＝32 种世间果报识（双五识 10 ＋ 意识 22：意界 2 ＋ 推度 3 ＋ 欲界有因 8 ＋ 色界 5 ＋ 无色界 4）；三论点证「无业则无果报」。
4. 「不一亦不异」：回声 · 灯明 · 印章 · 镜像四喻——「不从他处来，也不无因生」；相续连结故，结生仍在同一个生命相续流里。
5. 十福业事（布施·持戒·禅修·服务·恭敬·说法·随喜·回向·闻法·正见）增长内功德与外功德，都是解脱的资粮。
6. 面对果报不要直接采取行动（不是不作为，而是不带着贪瞋回应）——先认出「这是果报」，再以业果法则看待成因。
7. 六入不是「我」，是六扇门；触不是「我」在触，是根 · 境 · 识三者相遇；受是触之后苦 · 乐 · 舍三种领纳（缘于六触生六种受）。
8. 触与受本身没有善恶，善恶在于随后生起的作意——受是果，作意是因；无明往往就在那一念「不如理作意」里进来（无明引发不善行的五种路径）。
9. 心的定则：五门转向 · 眼识 · 领受 · 推度 · 确定 · 速行（7）· 彼所缘（2）；受不是终点，它正是下一支「爱」的缘起处。

各位贤友，这一周我们继续读十二缘起。上一周我们看清了一件事：无明，是造作的根源。这一周，我们把镜头推近一步，看无明之后究竟发生了什么——也就是第二支到第四支：行、识、名色。请先记住三句最朴素的话：行，是造作；识，在这里特指果报识；名色，就是我们常说的身心。这三句记住了，今晚就不会被名相淹没。这一段材料偏「论」，名相多、数字多，读到听不懂的地方，允许它先过去；我们抓住「业与果在相续」这条主线就好。

### 一、三支总说：从「无明」到「业与果」

十二缘起是一条彼此牵连的链：无明、行、识、名色、六入、触、受、爱、取、有、生、老死。今晚读的是紧接「无明」的三支——行、识、名色，它们正处在「过去因」通往「现在果」的第一段接续上。

上一支是「无明缘行」，说的是无明引发造作；接下来「行缘识」「识缘名色」，说的是造作如何感果、果报又如何在名色上成形。所以这三支合起来，其实都在回答同一个问题：如果没有一个「我」，那是什么在轮回？答案是——业与果在相续。请带着这个疑问往下听：行是谁在造作？识是谁在承受？名色又是谁的身心？

把这三支放回三世来看，会更清楚：无明与行属于「过去因」，识、名色（乃至六入、触、受）属于「现在果」。也就是说，我们今天的身心，是过去所造的因结出的果；而这一期生命里的一切，又都是业与果在相续。

### 二、行支：不是「行动」，是「造作」

先看「行」。要特别留意：行不是我们平常说的「行动」「行为」那个意思，它的本义是造作——是思心所驱使身、语、意去造业；造作之后，会留下「业的力量」，这个力量就是下一支「识」的缘。所以「行」既指造作的动作，也指造作留下的那股力量。

行分为三种。
第一，福行，就是善的造作，共有十三种思。它又分成两部分：依布施、持戒等生起的八种欲界善思，加上依修习禅定生起的五种色界善思，合起来十三种。
第二，非福行，就是不善的造作，依杀生等不善业生起，共有十二种不善思。
第三，不动行，是依修习禅定生起的四种无色界善思。

三类合起来：八加五，再加十二，再加四，一共二十九种思，也称作二十九种业行。为什么叫「不动行」？因为在无色界的禅定里，心非常寂静稳固，不容易被外缘扰动，所以称为「不动」。

由于这三种行共有二十九种思，所以在这里，是用「业」来解释「行」——强调造作之后会留下业的力量。经文在讲「无明缘行」时，还会提到行有三种表现：身行、语行、心行，也就是身、语、意三门的造作；它们同样都只是世间善与不善的思而已。换句话说，无论造作福行、非福行还是不动行，其背后都是无明。

再把「行」与下一支「识」连起来看：福行引生欲界、色界的善果报，非福行引生欲界的不善果报，不动行引生无色界的善果报。所以行与识，正是「因」与「果」的关系——有什么样的造作，就成熟什么样的果报。这里说的「思」，是心所法中推动造作的那一个心所；它一发动，身、语、意就动了起来。所以「行」的重心，在造作的意欲，而不在动作本身。

由此也可以看出：「行」与「无明」其实是一体的两面——无明是「把假的当成真的」，行就是在这个错认之下采取的行动。认清这一点，就明白十二缘起为什么要从无明讲起：不是先有行动才有问题，而是先有看不清，才有无谓的造作。

### 三、识支：不是泛泛的「心」，是「果报识」

再看「识」。这里说的「识」，并不是泛指一切的心，而是特指果报识——由过去的业所感得的结果。为什么要这样界定？因为在十二缘起支里，识、名色、六入、触、受这五支同属「果报轮转」，所以这里的「识」，要以「果报、业报」来解释。

世间果报识一共三十二种，可以分为两大部分。
一部分是前五识：眼识、耳识、鼻识、舌识、身识。这五识各有善与不善两类果报，所以也叫「双五识」，合起来十种。
另一部分是意识，共二十二种：其中意界果报心两种（两种领受心），无因意识界三种（三种推度心），有因欲界果报心八种，色界果报心五种，无色界果报心四种。十加二十二，正好三十二种。
要特别注意：出世间心不属于轮回论的范围，所以不计入这三十二种之内。

这二十二种意识里，各有各的作用：领受心，是五门心路里承接五识之后、只是单纯领纳所缘的心；推度心，则进一步审察、推究这个所缘；确定心，则决定接下来是善速行还是不善速行。有因欲界果报心的八种，则是依「悦俱／舍俱」与「智相应／智不相应」、再乘上「有行／无行」两两搭配而成的。所以要读到的不是这些名目本身，而是它们共同表达的一件事：识是果报，它由过去的业而来。

到这里，「行缘识」的意思就清楚了：它是「业」与「果」之间的因果连接——过去造作的业（行）为因，今天的果报识为果。说得再直接一点：我们今天会看、会听、会想的这个「识」，正是过去业的成熟。所以，日常生活中我们所见、所闻、所尝、所触的一切，其实都是果报；我们有缘坐在这里听闻佛法，也是果报。

### 四、三论点：证明「没有累积的业，就没有果报」

那凭什么说「识」一定以「行」为缘呢？《清净道论》用一个设问来回答：如何得知「识」是以行为缘而生起的？它给了三个论点，分别从「业」「果报」「作者」三个角度各推一遍。

论点一：没有累积的业，就没有果报。没有业，果报无从谈起。
论点二：此识本身就是果报，所以若没有累积的业，果报不会生起。
论点三：假若无业也能生起果报，那么一切有情都应该自动生起果报识——可事实绝非如此。既然不是人人都凭空生起果报识，就证明果报必须依业而生。

三个论点合起来，共同证明一件事：没有业，就没有果报；果报只是业缘的相续，背后并没有一个独立的「作者」在主宰。

把这三个论点换个角度看，会更清楚：第一个论点从「业」说——无业则无报；第二个论点从「果报」说——识本身就是报，无业则不生；第三个论点从「作者」说——假若无需业也能生报，那么一切有情都该自动生起果报识，可事实并非如此。由此反证：并没有一个独立自主的「作者」在背后主宰，有的只是业缘的相续。

这三个论点之所以重要，是因为它同时挡掉了两种误解：既不是「无需业就有果」，也不是「有一位主宰在派发果」。因果既不落空，也没有一个「谁」在里面。

### 五、名色支：身心

识生起之后，接着生起的是「名色」。「名」，是受、想、行这三种非色法，也就是精神的部分；「色」，是四大种以及所造色，也就是物质的部分，而且是业所感的果报色法。名与色合起来，就是我们平常说的「身心」。名与色是互相依靠的：没有名，色不能自己活动；没有色，名也无从依止。所以从这一刻起，生命就以「身心相续」的样子展开了。

再说细一点：四大种，就是地、水、火、风四大元素，它们是色法的基础；由四大种衍生出来的，叫「所造色」。这里的色，是业所感的果报色，也叫业生色。名与色就这样互相依持、彼此支撑，一起构成我们所说的「这一期身心」。

### 六、识与名色「不一亦不异」：四个譬喻

那么，识与名色到底是什么关系？经文说：「相续连结故，不一亦不异。」
所谓「不一」，是说上一期生命与这一期生命，并不是同一个生命——不是同一个「我」从这里搬到了那里。
所谓「不异」，是说这一期生命的结生与上一期生命是有关系的——你死后不会进入另一个毫不相干的生命相续流，而一定是在同一个生命相续流里。

为了把这个道理说清楚，经文给了四个譬喻，请一个一个对照着看。
第一，回声。敲钟之后产生的钟声与回声并不相同，但并非无关，正因为敲了钟，才有回声。
第二，灯明。后一盏灯由前一盏灯而燃，它不是前一盏灯，但也不是毫无关系。
第三，印章。纸上的印纹不是你手中那枚印章，却因你盖印而有了印纹。
第四，镜像。镜中的人不是你，却正是你的影像。

这四个譬喻共同说明一件事：「因声等而有回声、灯明、印章、镜像时，它们并未去到别处。」结生心也同样如此——它不从他处来，也不无因生。经文又补了一句：如果完全同一，就不会因牛乳而产生凝乳；如果完全相异，凝乳就与牛乳无关。所以，对由因而生的识，既不能说它和前一念完全相同，也不能说它毫无关系。「不一亦不异」，说的正是这种「相续而不等同」的关系。

把这个道理放回生活里看，也一样成立：今天的你和昨天的你，不是同一个人，却也不是毫无关系——因为相续，才有了今天的你；因为不一，你也不必被过去的某一个标签钉死。所以「结生一定在同一个生命相续流里」这句话的意思，并不是有一个灵魂搬了过去，而是因缘在相续。

再补一句关键的：这里说的识，特别指「结生识」——这一期生命的第一个心。结生识与过去的心识，正是「不是同一个、也不是没关系」：它不是过去那颗心的延续，却也不能离开过去的因而独立生起。

### 七、面对果报的态度：先认出，再回应

既然所见、所闻、所尝、所触，一切都是果报，那我们该怎么面对果报？经文反复提醒：不要对果报直接采取行动。注意，这句话不是叫我们「不作为」，而是叫我们「不带着贪瞋去反应」。

人的惯性往往是：面对好的果报，就希望它更好、继续好；面对不好的果报，就希望它立刻离开。经文说，这恰恰不是一个了知业果法则的人应有的基本态度。正确的做法是：先认出「这是果报」，再以业果法则去看待它的成因，然后才决定怎么行动。能退后一步看清它，就是我们修行的起点。

资料里举过一个例子：最早听闻阿毗达摩的五百位比库，过去生曾住在一个山洞里的蝙蝠，听比库们诵阿毗达摩，虽然并不理解义理，只是觉得好听；正因种下了这一份善业，这一生才有因缘成为果德玛（Gotama）佛陀时代最早听闻阿毗达摩的比库。可见，任何果报都有它的因。

所以，问题的核心不在于果报本身的好坏，而在于我们面对果报时的反应：面对好的果报，若只是希望它更好、继续好；面对不好的果报，若只是希望它立刻离开——这就不是了知业果法则的人应有的态度。能够先停下、先看清，就是我们练习的方向。

### 八、十福业事与收束

最后，怎样为未来增长善的资粮？经文提到「十福业事」，就是十种能增长福德的善行：布施，是把自己的所有分享出去；持戒，是守护身语意的清净；禅修，是修习止与观；服务，是为人做事、利益他人；恭敬，是对长者、对三宝心存敬重；说法，是把所知的法分享给他人；随喜，是见他人得善而欢喜；回向，是把功德分享给一切有情；闻法，是恭敬地听闻佛法；正见，是确立对业果、对四圣谛的正确见解。

以此十项善行，增长两种功德——「外功德」是利益他人、改变外在环境与人际因缘；「内功德」是内心获得的丰盈与力量。经文说，有内功德才有外功德；两者都是解脱的资粮。换句话说，十福业事不是十件事的清单，而是提醒我们：善的资粮，要从当下一点一滴地累积。

上篇我们就读到这里。请记住几句最朴素的话：行是造作，识是果报，名色是身心；业与果相续不断，却没有一个固定的「我」在搬来搬去；面对果报，先认出、再回应，而不是立刻反应。（上篇完）

## 🎯 第一轮主题讨论（10 min）

**讨论规则**（照读即可）：三个问题按顺序来，不跳序、不赶进度；一人发言时，其他人只听。主持人少说、多问，把话头交给大家。

讨论问题（按优先级）：

1. **「行缘识」到底在说什么？** 为什么「识」特指果报识？（抓住：三行共 29 种思＝业；32 种世间果报识＝果；无业则无果报。）
   - 追问路径：如果没有累积的业，果报识会不会生起？为什么说「没有业而有果报，不成立」？
   - 操作提示：若学员追问心所数量等细节，可回应「这些数字先记住结构，细节我们课后再查资料」，不必现场记诵。

2. **「不一亦不异」怎么理解？** 用回声、灯明、印章、镜像四个譬喻，说说「既不是同一个，也不是没有关系」是什么意思。
   - 追问路径：如果完全同一，会有什么过失？如果完全相异，又会有什么过失？「凝乳与牛乳」的比喻说明了什么？
   - 操作提示：这一问容易抽象，可先请学员用「今天的我」与「昨天的我」作对比，再说回「上一生与这一生」，会容易得多。

3. **面对果报的正确态度是什么？** 资料说「不要对果报直接采取行动」，这与「不作为」有什么不同？
   - 追问路径：什么是「了知业果法则的人的基本态度」？把「停三秒」放到你今天的某一个场景里，会发生什么？
   - 操作提示：可请学员现场选一个「今天的小场景」，三个人分别说出自己会怎么「不立刻反应」，主持人不评价，只记录关键词。

**参考要点（供主持人翻阅，不必逐字念）**：

- 第 1 问要点：资料说「行指福行、非福行、不动行，共有 29 种思」，又说「识指 32 种世间果报识」，所以「行缘识」是以「业」解释「行」、以「果报、业报」解释「识」。它用三个论点证明：一、没有累积的业则无果报；二、此识是果报，无业则不生；三、若无业也能生果报，则一切有情都会生起果报识——显然不会。故「识」特指果报识；十二缘起支中识、名色、六入、触、受都属于果报轮转。
- 第 2 问要点：回声、灯明、印章、镜像四喻都在说「不从他处来，也不无因生」。若完全同一，则牛乳不会生出凝乳；若完全相异，则凝乳与牛乳无关。故「相续连结故，不一亦不异」：上一期生命与这一期生命不是同一个生命，但这一期的结生与上一期有关系——你死后不会进入另一个生命相续流，而一定是在同一个生命相续流里。
- 第 3 问要点：资料说「不要对果报直接采取行动」，指的不是不作为，而是不带着贪瞋去回应。人的惯性是「好的希望更好、坏的希望立刻离开」，这恰恰不是了知业果法则者的基本态度。正确做法是：先认出「这是果报」，再以业果法则看待它的成因，然后才决定怎么行动。

**备用深水问题（时间富余时）**：如果这一生的结生识与过去生的心识「不是同一个、也不是没关系」，那么「我修行、我受报」这句话，还可以怎么说？

## 🧘 禅修练习（15 min）

> 💡 本周由连续两周合并，含两段禅修练习引导语；时间紧可读其一，或各取前半段（合计约15分钟）。

### 练习一

**主持人引导语**（照读即可）：

请找一个舒适的坐姿，眼睛微闭。先做三次深呼吸，把心放下来。

今晚的练习很简单：不是去改变什么，而是练习「知道」——知道有一个果报正在发生，知道心里升起的反应，也知道这些都会过去。

现在，回想今天让你不太舒服的一个小片段——也许是一句话、一个眼神、一件不顺的事。不要分析它，只是看着它。

然后，在心里轻轻说一句：这是果报。这是过去的因，在今天成熟。

不要急着改变它，也不要急着推开它。只是看着这个果报，像看一片落下来的叶子。

接着，注意心里升起了什么：想反驳？想逃避？想抓住？——这些都只是念头，不是「我」。

让这些念头来，让这些念头去。你只是知道：因在动，果在现，相续在继续，而没有一个固定的「我」在承受。

**练习要点提醒**：这个练习不是「想通」那件事，也不是「消除」不舒服；只是练习在果报面前，先不解救、先不判决，只是知道。做到「知道」，就已经做到了。

**若有人落泪或情绪起伏**：请轻声说一句「没关系，让它在，我们都在这里」。待其平稳后，再引导回到呼吸；必要时邀请其到旁边休息，不中断全场。

如果今天你什么感觉都没有，也很好——没有感觉，也是一种被知道的状态。修行不是追求特殊经验，而是越来越诚实地看着当下。

好，把注意力放回呼吸，安住在呼吸上……（静默约 3 分钟）……

现在，慢慢把注意力带回身体，感觉双手、感觉坐姿，准备好时，轻轻睁开眼睛。

**练习后的小分享（约 3 分钟，可省略）**：请两位贤友用一句话说说「停三秒」之后看到了什么。主持人只回应「谢谢你的分享」，不作点评、不作纠正。

**引导补充**：若有人在练习里生起较强烈的情绪，请把引导词改为最朴素的一句——「知道它在，就够」。并提醒大家：今天不需要解决任何事，只需要练习「看见」。

### 练习二

**主持人引导语**（照读即可）：

请大家坐好，轻轻闭上眼睛，做三次深呼吸，把身体安放在当下。

现在，我们来做一次「六门随观」。不必紧闭六门，反而让六门自然开着，只是知道每一门发生了什么。

先是眼门：眼睛是闭着的，但也许还有光感、有明暗。知道就好。接着耳门：身边有什么声音，远的、近的，只是听，不追。接着鼻门：空气进出的味道，知道就好。接着舌门：嘴里安静着，知道就好。接着身门：身体接触坐垫、衣服、空气的这些接触点，一处一处地感觉。最后是意门：心里有念头升起，知道有念头，不急着跟着它走。

现在，把注意放在「身门」的一个接触点上——比如手与腿相触的地方。那里有接触（根）、有温度或压力（境）、有正在感觉的心（识）。三者相遇，就有了一个「触」。在这个「触」上，它是舒服的，还是不舒服的？是乐受、苦受，还是不苦不乐？

不要改变它，也不要评价它。只是知道：这是「触」，这是「受」。它们生起，也会灭去。就像有人轻轻敲了一下门，你听见了，但它不会一直敲下去。

好，把注意力放回呼吸，安安静静地坐一会儿……（静默约 3 分钟）……

现在，慢慢把注意力带回身体，感觉坐姿、感觉双手，准备好时，轻轻睁开眼睛。

> ⚠️ **禅修禁忌提示**：若你正处在严重抑郁、焦虑、创伤后应激，或精神类疾病的发作／用药期，或正经历强烈的情绪危机，请先咨询医生或心理师，再决定是否练习；练习中若出现明显不适（如心悸、胸闷、情绪失控），请立即停止，睁开眼睛，把注意力放回呼吸与身体，必要时离场休息。

> ⚠️ 主持人操作：若有人闭眼易昏沉，可改半睁眼；「六门随观」重点在「知道」，不要求「专注到没有杂念」。结束时不要问「你观到什么」，只请大家记住那个「触与受之间」的空间。

### 一、从名色到六入：六扇门开了

六入，也叫六处、六内处，就是眼、耳、鼻、舌、身、意这六个门。请留意「门」这个字：门只是让境界进来的通道，它本身并没有一个「谁在看」「谁在听」。所以要点是：六入不是「我」，是六扇门。眼睛只是让颜色进来，耳朵只是让声音进来；门开着，境界就进来，除此之外，门背后没有别的什么在指挥。这一点先立住，后面就好懂了。

顺便认一认相关的分类：六入也叫六内处；把六根与六境合起来，就是十二处；再加上六识，就是十八界。这些分类，都是在帮我们把「看、听、嗅、尝、触、想」这一连串动作拆开来看清楚——哪一部分是根，哪一部分是境，哪一部分是识；拆开之后你会发现，里面并没有一个多余的「我」。

再说一层：六入本身也是「果报」的一支，属于果报轮转。也就是说，眼睛是什么样、耳朵灵不灵，这些很大程度上是过去业所感的果报，我们并不能任意挑选自己的六根。能做的，是在六门打开、境界进来的当下，学着看清楚。

### 二、心的定则：五门心路过程（以眼门为例）

门开了之后，境界进来，接下来发生的是什么呢？这里要先认识「心的定则」——也就是五门心路过程。我们以眼门为例。

当「色所缘」生起，撞击到「眼净色」的同时，也撞击到「有分」，这时第一个路心还不能马上生起。属于「离路」的有分心仍在继续生灭：第一个被撞击的有分心叫「过去有分」，第二个叫「有分波动」，第三个叫「有分断」。「有分断」灭去之后，诸路心才陆续生起，各自执行各自的作用：五门转向心一个，执行「转向」的作用；眼识一个，执行「看」的作用；领受心一个，执行「领纳」的作用；推度心一个，执行「推究」的作用；确定心一个，执行「意门转向」的确定作用，它是决定善速行或不善速行的重要转向，也就是速行作意；接着是速行心七个；最后是彼所缘两个。合起来，路心共十四个；再加上前面三个离路有分，一共十七个心识刹那。

这些心生起，需要种种「缘」的支持。资料把缘力分成六组：俱生组十五条缘，讲心所与心的关系；所缘组十一条缘，讲所缘与心的关系；无间组七条缘，讲前一心与后一心的关系；依处组六条缘，讲依处与心的关系；自然亲依止组一条缘；异刹那组两条缘。以眼识为例，它生起时就同时需要所缘组、依处组、无间组、俱生组、自然亲依止组、异刹那组这些缘的支持。

再说两个数字。色法（五所缘）的寿命，从「过去有分」算起，最长维持十七个心识刹那；若把每个心识刹那再分成生、住、灭三个小刹那，则色法可经历五十一（十七乘三）个小刹那。而且，色法只有在「住」时才能呈现于五门心路中。此外，除无色地众生外，欲地、色地的每一个心生起，都必须依靠「依处」：双五识依靠五净色之一，结生心依靠心所依处，其余的心则依靠与前一心同时生起的心所依处。

还有两处可作补充：能充当速行心的，分欲界速行心与安止速行心两类；讲五门心路时，只取欲界速行心即可。若只论善与不善速行，则取八大善速行心加十二不善速行心，共二十种。速行心之后会出现两次彼所缘，但彼所缘的出现是有条件的，要符合「彼所缘法则」才行。

这里有两个很关键的细节。第一，为什么会有三个「有分」？因为色法的寿命是十七个心识刹那，扣掉最大路心的十四个，还剩三个心识刹那属于离路的有分心，于是分别命名为「过去有分」「有分波动」「有分断」。第二，为什么叫「有分波动」而且要两次？有分心有自己的所缘目标，也就是这一期生命结生时所缘取的目标；当新的色所缘撞击眼门，原本缘取自己目标的有分心受到影响，无法立刻舍弃原有的目标，于是开始波动——要经过两次波动才能截断。古德用「树鸟」与「苍蝇」两个譬喻来说明：鸟栖息在树上时，鸟的影子同时出现在地面；两个糖罐放在一起，动一个，另一个也会受影响。眼净色与心所依处色虽然位置不同，却彼此关联，所以色所缘撞击眼净色时，也会投射到有分，使有分心开始波动。

再有一个要点：心生起的排序——五门转向、眼识、领受、推度、确定、速行七个、彼所缘两个——这是心的自然法则，不是论师编排出来的。修习名法时会发现，每一个心识刹那就是这样生起的。这是心的定则，是佛陀的伟大发现。每一个心生起，只执行一个心识刹那的作用就灭去，不会连续两个刹那；一旦灭去，又成为下一个心生起的因缘。

顺便提一句：五门心路是对眼、耳、鼻、舌、身五门而言的；若是意门自己缘取所缘，就称为「意门心路」。两者的基本道理一致，只是生起的路心略有不同。本周我们以眼门为例，把五门心路的骨架认清楚就够。

### 三、触支：根·境·识三者和合

门开了、境进来了，于是就有了「触」。触，是根、境、识三者的和合。以眼门为例：这里有色所缘（境），有眼净色（根），有眼识（识）；三者相遇，才有「看」，才有「触」。所以不是「我」在触，而是三者相遇。原文说得很直接：「只要有六入就有跟外境的接触，有触，就会有感受。」也就是：门（六入）→ 遇（触）→ 纳（受）。触，是「遇」这一环，也是六入与受之间的桥梁。

再以耳门为例：当声所缘撞击耳净色，就有了耳识、有了「听」；根（耳净色）、境（声所缘）、识（耳识）三者相遇，就有了「触」。其余鼻、舌、身、意各门，也只是把「色所缘」换成「香所缘、味所缘、触所缘、法所缘」，把「眼识」换成对应的识而已，道理完全相同。所以「触」这个名字，说的从来不是「我」在碰触，而是根、境、识三样条件刚好凑在一起。

### 四、受支：触后的领纳

触之后生起的是「受」，也就是领纳。受有三种：苦受、乐受、不苦不乐受（也叫舍受）。因为触是缘于六门而起的——眼触、耳触、鼻触、舌触、身触、意触——所以受也就有六种，这就是「缘于六触生六种受」。要留意，这里所说的触，不只缘眼识的受，还缘同一心路中一切心的受，也就是「缘一切受」。所以，触一生起，苦、乐、舍三种受就随之而起；这部分几乎是不由自主的。

这里还要分清：「触」与「受」是两步——触是三者和合的「遇」，受是触之后的「纳」。三受之中，乐受让心欢喜、想要更多；苦受让心排斥、想要逃开；不苦不乐受平平淡淡，最容易被忽略，却同样是一种领纳。所以受是心对境界最直接的一个反应，它先于我们的思考。

这里要小心一个误会：受虽然几乎不由自主，却不是「命运」。受只是果报——它是过去的因在今天成熟；真正能改变走向的，是紧接着生起的那一念「作意」。所以，看见受，不必认同它，也不必压制它，只是知道它在那里。

### 五、触受非善恶，善恶在作意

那么，触和受是善还是不善呢？要记清楚：触与受本身没有善恶，它们属于果报，是无记法。善恶在于随后生起的「作意」——确定心如果「不如理作意」，就生起不善速行；如果「如理作意」，就生起善速行。所以说是：受是果，作意是因。这里的「作意」，就是前面说的「速行作意」；它发生在确定心那一步，是整条心路的转向处。同一个所缘，如理作意，整条心路就转向善；不如理作意，就转向不善。

所以在这里，我们要分清两种「善恶」：一种是果报上的苦与乐，那是无记的、不由自主的；另一种是造业上的善与不善，那是我们可以作意、可以选择的地方。把两者分开看，就明白修行的着力点究竟在哪里——不在受上较劲，而在作意处留心。

### 六、无明从六门进来：五种路径

既然善恶在于作意，那么「无明」是怎么进来的呢？其实，无明往往就在那一念「不如理作意」里进来——六扇门开着，境界进来，若不如理作意，无明与贪瞋就随之而起。经文列出了无明引发不善行的五种路径。
第一，直接引发不善路心的作意。
第二，本意朝向善的所缘，结果确定心却不如理作意。
第三，不善的果报引发不如理作意。
第四，善的果报引发不如理作意。
第五，纯粹的不如理作意——心里想入非非，自己编造一套贪瞋痴慢的快意人生。

把这五种路径配上例子，会更容易记：第一种，主动朝向不该看的所缘，认定它会带来快乐，于是直接生起不善的作意；第二种，本意是想做一件善事，比如想打开一段佛法视频，结果不如愿，确定心不如理作意，反而生起瞋；第三种，遇到不善的果报，比如走在街上被人撞倒，心里认定「有一个真实的我被撞到了」；第四种，遇到善的果报，比如看到一朵美丽的花，心里认定「有一朵真实美丽的花」，因而生贪；第五种，什么外缘都没有，只是自己想入非非，编造出一套贪瞋痴慢的快意人生。

把这五种路径合起来看，就会得出一个结论：「无明缘行」涉及的其实是整条心路，而不只是速行那一念。这一点很要紧——它告诉我们，守门不是只看最后一刻，而是要看整条心路的过程。

回到生活里，这五种路径随时都在上演：一句不顺耳的话、一个不如意的画面，都可能成为无明进来的门。所以「守门」的意思，不是把六扇门统统关死，而是在门开、境来、受生之后，给自己留一个「如理作意」的机会。

### 七、受不是终点：受缘爱

最后要记住：受不是终点。它正是下一支「爱」的缘起处——「缘受而有爱」。不管哪一种受——五识、领受、推度里的三十二种果报受——都会对随后升起的贪根心里那个「爱」，以自然亲依止缘为缘。为什么三种受都对爱为缘？因为苦者寻求乐，乐者更求乐，而舍受由寂静性故也被说为乐，所以三种受都会引出爱。

这里要说明「自然亲依止缘」：它是一种很强的助缘，前面的受以强大的力量，支助后面贪根心的生起；所以在受与爱之间，主要就是靠自然亲依止缘把它们连起来。这个爱还会「爱屋及乌」——从单一的爱，一次次地爱，慢慢变得坚固。所以，受虽然是果报、多分不由己，但它不是终点；在这里停下来看清一次，就是为下一周「受缘爱」埋下第一颗观察的种子。

### 八、收束

下篇我们就读到这里。请用三个字带走它：门、遇、纳。门，是六入——眼耳鼻舌身意六扇门；遇，是触——根、境、识三者和合；纳，是受——触之后苦、乐、不苦不乐三种领纳。还要记住：眼门心路里那一串排序，是「心的定则」，不是谁在背后指挥；触与受本身没有善恶，善恶在于随后生起的作意；而无明，往往就是在那一念「不如理作意」里进来的。这一周练习的重点很朴素：不关闭六门，只在「触」与「受」之间，留一点觉知。（下篇完）

**分享规则**：本轮只谈「感受与体会」，不谈义理对错；每人 1–2 分钟，主持人计时；可以只说一句「我今天的发现是……」；不愿分享的可以举手跳过，静静听着也是参与。分享时请尽量用第一人称描述「我身体的感觉」「我当时的反应」，避免对他人或事情的评判；若涉及他人隐私，请只讲自己的那一半。

请就以下问题，任选一个分享：

1. 今天静心时，你「听见／感觉到」的那个当下，有没有一丝「原来是条件聚在一起，才发生的事情」的感觉？那一刻你身体哪里最明显？
2. 回想最近一次让你不太舒服的「触」（一句话、一个眼神、一种味道），请只描述：经由哪一门进来的、当时身体的感受是什么。不必讲事情本身的对错。
3. 读到「触与受本身没有善恶，善恶在于随后生起的作意」这一句，你心里第一反应是什么？

> ⚠️ 主持人操作：若有人开始讲很长的故事或评判他人，温和打断：「我们先把镜头拉近到你身体的那一处感受，好吗？」；先请平时少发言的人，再请活跃的人。

## 🎯 第二轮主题讨论（10 min）

讨论问题（按优先级）：

1. **「我看见了」的那个「我」，到底在哪里？** 资料说：眼门心路里，有眼净色（根）、色所缘（境）、眼识（识），三者相遇才有「看」，才接着有「触」「受」。那么，我们平时说的「我在看」，是不是把「根境识和合」错认成了一个「我」？追问路径：先请大家指出「看」这件事里，哪一部分是「我」？若三者任一缺席，还有「看」吗？——引导到「六入不是『我』，是六扇门；触不是『我』在触，是三者相遇」。可再补一问：如果「看」要三者齐备，那「闭眼不看」算不算一种选择？引导到「六门可以关，但不必压抑，只需知道」。
2. **「触」是先于「受」的，那我们对「受」还有多少选择？** 资料说「缘于六触生六种受」。触一生，苦／乐／舍受随之而起，这部分几乎不由自主。追问路径：既然受不由己，我们真正能「作意」的地方在哪里？——引导到「受是果，作意是因」；本周不解决，只把它当作观察的入口，留待第三周「受缘爱」再深谈。
3. **为什么「无明」会从六门进来？** 资料列出无明引发不善行的五种路径，其中都有「不如理作意」。追问路径：请一位学员举自己「刷手机／被一句话惹恼」的例子，一起标出：是哪一门、什么触、什么受、什么作意。引导到「守门」不是压抑六门，而是在触与受之间留一点觉知。

> **分层追问**（可视时间取用，由浅入深）：
> - 【现象】今天哪一次接触——一个声音、一个眼神——让你心里起了明显波动？
> - 【影响】那个感觉一升起，你通常本能地做了什么？说说当时的反应。
> - 【应对】这周选一次不愉快的触碰，先停留在「刚才有个感受」，不急着反应。

> ⚠️ 主持人操作：第 1 问是本周的「眼」，务必留足时间；第 3 问容易滑向自我批评，要随时把「这是观察，不是定罪」带回现场。讨论中出现名相分歧（如「意处」到底含几心），记下来，说「课后再查证」。

## 🔚 收尾与回向（15 min）

**1. 总结引导**（照读即可）

今晚我们读了三支：行、识、名色。「行」是造作，「识」是果报，「名色」是身心最初的成形。资料反复告诉我们一件事：这一切都在相续，却没有一个固定的「我」在搬来搬去。所以，面对果报，不必慌、不必怨——认出它、看清它，就是修行的开始。

今晚听得懂多少，其实没那么重要。重要的是：当你回家、看到家人的那一刻，能不能比昨天多停三秒。这就是缘起在我们身上的样子。

**2. 本课后半段 · 总结引导**（照读即可）

后半段我们读了第五至七支——六入、触、受。我们用三个词把它们串了起来：「门」「遇」「纳」。门，是六入——眼耳鼻舌身意六扇门；遇，是触——根、境、识三者和合；纳，是受——触之后苦、乐、不苦不乐三种领纳。资料告诉我们：眼门心路中的五门转向、眼识、领受、推度、确定、七速行、二彼所缘，是「心的定则」，不是谁在背后指挥；也告诉我们：触与受本身没有善恶，善恶在于随后生起的作意——而无明，往往就是在那一念「不如理作意」里进来。所以这一周练习的重点很朴素：不关闭六门，只在「触」与「受」之间，留一点觉知。

**给主持人的一句话**：不要把「受」讲成宿命。受虽是果报、多分不由己，但它不是终点——它正是下一支「爱」的缘起处；我们在这里停下来看清一次，就是为下周「受缘爱」埋下第一个观察的种子。

**3. 给第一次参加的朋友**

如果你今晚有很多地方没听懂，那完全没关系。带着今晚的那一句话、一个新问题回家，就已经足够。四周很长，我们一起来。

**4. 本周作业细则**（向成员逐条确认）

- 每天留意一次「根境识和合」的当下（听见一个声音、碰到一处温度），看看其中有没有一个「我」
- 试着在「触」与「受」之间留一点觉知，记下当天的一次「停一停」
- 请成员确认已记录在记录表上

**5. 收尾的三种收束方式**

① **简收**（时间紧）：只做三件事——念一句总结「因在动，果在现，相续在继续，没有固定的我」；念后半段主题；念回向词四句；
② **平收**（常规）：按「总结引导＋后半段总结＋回向」走；
③ **深收**（时间富余）：在回向前后各留 30 秒静默，让大家把今天的一句话带进身体再起身。

**一句共勉**（可照读）：不关闭六门，只在「触」与「受」之间，留一点觉知。

**6. 离场提醒与下周预告**（约 3 min）

提醒大家带走自己的讲义；下次请提前 5 分钟到场，方便我们准时开始静心。

**下周预告**：第3周，我们将顺着「受」往下走，进入第八至十支——爱、取、有。看看「三受」如何生出「三渴爱」，渴爱又如何硬化成「四取」，进而积成「业有」，推向未来的「生」。

**7. 回向词**（主持人领读，全体合掌齐诵，照读不省）：

> **愿我此功德，导向诸漏尽！**
> **愿我此功德，为证涅槃缘！**
> **我此功德分，回向诸有情！**
> **愿彼等一切，同得功德分！**

> ⚠️ 主持人操作：回向语速放慢，一句一句，让大家合掌跟随；结束时不急于散场，留 30 秒安静，让善业在心里落定；散场前可轻声提醒一句「路上慢一点」。
