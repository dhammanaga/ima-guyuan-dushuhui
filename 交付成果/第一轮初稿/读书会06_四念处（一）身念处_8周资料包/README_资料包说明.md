## 🧭 使用顺序建议

**第一次拿到资料包**：
1. 主持人读 `00_主持人总指南.md`（10分钟）——角色定位、流程、守则、8周总览
2. 翻一眼 `README_资料包说明.md`（本文件）——知道每份文档是干什么的
3. 有兴趣可翻 `原文全集.md` 的第1周部分，熟悉共读原文的样子

**每周活动前（主持人）**：
1. 打开**当周主持人版**：读"⭐ 主持人速览"→ 看"⏱ 时间弹性指南"→ 把"📖 共读原文"和"🧘 禅修练习"的引导词过一遍（约15分钟）
2. 第5、6周务必先读文末"📌 本讲主持人特别提醒"的心理安全专项条目
3. 打印或准备好学员版（或提前发给学员）

**每周活动当天**：
按流程推进：静心开场 → 共读原文 → 第一轮分享 → 主题讨论 → 禅修练习 → （扩展内容包）→ 收尾回向

**学员**：
- 每周打开**当周学员版**即可——共读原文、讨论问题、练习引导词、回向文与主持人版完全一致，不需要提前做任何功课
- 课后想重读原文：直接看学员版，或翻《原文全集.md》对应周部分

**时间弹性**：
- 时间不够 → 按"⏱ 时间弹性指南"浓缩：共读只读★核心段、讨论只讨论问题①、练习缩至8分钟、收尾缩至10分钟
- 时间富余 → 加读◈扩展段、做"📚 扩展内容包"中的延伸讨论与小练习、延长练习时间
- 原则：**讨论比读完重要，体验比讲完重要；宁可少讨论，不省略练习环节**

## 📐 格式说明（双版本差异与标注约定）

- **双版本结构**：每周2份文档（主持人版/学员版），共读原文、讨论、练习、扩展、回向**逐字一致**；差异仅在主持人专属内容——学员版无"主持人速览/时间弹性指南/主持人操作提示/特别提醒"（改为"学习提示"），多"📖 延伸阅读"清单。
- **★核心 / ◈扩展**：每份共读材料标注"段落优先级"——**★核心段落**为时间不够时的必读段；**◈扩展段落**为时间富余时的可选段（个别材料整段为◈扩展，可整体跳过）。
- **出处六要素行**：每份共读材料开头均标注：**标题／文件类型／说明／知识库出处／media_id／打开方式**，六要素齐全，可溯源。
- **"（依据录音转写整理）"的含义**：该材料来自录音转写稿，已按上下文校对明显同音错字（各材料"说明"行内注明主要校对项），非逐字原稿；转写段首的时间码（如[00:01:45]）是出处标记，朗读时跳过不念。
- **"[generated, not original text]"标注的含义**：知识库提取工具返回该标注时，表示返回文本为整理版而非逐字原稿；相关材料在"说明"行如实保留该标注，照常使用。
- **PDF/Word 教材的处理**：本系列共读材料以**摄菩提分讲义（Word）、禅修营开示（录音转写）与 PDF 课件**为主。Word 讲义与 PDF 课件文字（含知识库提取返回带 `[generated, not original text]` 标注者）可逐段照读；个别 PDF 的图形页/表格提取缺口（如第6周"（课件图：……）"）均在对应材料"说明"行**如实注明**——不虚构、不臆补原文，共读以义理相通为准。
