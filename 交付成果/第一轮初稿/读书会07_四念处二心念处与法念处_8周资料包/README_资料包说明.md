## 🧑‍🤝‍🧑 两类使用者怎么用

- **主持人**：每周拿《00_主持人总指南》＋当周《主持人版》即可主持——速览2分钟看完，引导语全部照读，原文直接读。
- **学员**：每周拿当周《学员版》即可全程参与——共读原文、讨论问题、练习引导与主持人版完全一致；课后可看文末延伸阅读。
- **组织者**：开营前把《00_主持人总指南》发给全部轮值主持人；每讲可由不同成员主持。

## 🔎 本系列学什么

- **心念处**（第1—2周）：从身、受走向心——用"八对十六种心"如实观察自己此刻的心。
- **法念处·五盖**（第3—4周）：认识五种心灵雾罩（贪欲/嗔恚/昏沉睡眠/掉举追悔/疑）的成因，并拿到一串串"对治钥匙"。
- **法念处·七觉支**（第5—6周）：盖被揭掉之后长出来的七种觉醒品质，以及"平衡五根"的调心之道。
- **法念处·蕴处**（第7周）：五取蕴（抓取清单）与十二处（抓取进出的六扇门），把观照落到最日常的看听嗅尝触想。
- **整合实修**（第8周）：以四圣谛总图整合八周内容，按根性选择自己的念处之门，圆满回向。
