## 🗺 本周知识地图

**本周是四周的收束课（＝8W7＋8W8）：把十二支合起来，看它在自己身上怎么转。**
一句话说清：**十二支按「过去二支、现在八支、未来二支」分成三世，串成两重因果；
两重因果上有三个连接点，其中只有「受→爱」这一处是当下能碰的；
而整条链之所以转个不停，是因为无明与爱这两个根本没有被断。**
看清这三个连接，就知道今生唯一的下手处在哪里。

```
三世两重因果 · 三连接 · 三轮转 · 从缘起看解脱（全链收束）
│
├─ 一、三世两重因果（＝两条链子首尾相接）
│   ├─ 第一重「过去因 → 现在果」：过去（无明·行）→ 现在（识·名色·六入·触·受），
│   │   以**无明**为根本、以**受**为终结——这一生的果报，是从过去因缘而来的
│   ├─ 第二重「现在因 → 未来果」：现在（爱·取·有）→ 未来（生·老死），
│   │   以**爱**为根本、以**老死**为终结——此刻的执取，正在结出未来的生死
│   └─ 两重并说的用意是**同时根除二边**：由「果」的生起显明诸因不断，故根除断见；
│       由已生的识、名色、六入、触、受终归坏灭，故根除灵魂说、梵我说等常见
│
├─ 二、二八二支与三时
│   ├─ 过去二支：无明 · 行（已过去，看不见、也下不了手）
│   ├─ 现在八支：识 · 名色 · 六入 · 触 · 受 · 爱 · 取 · 有（生命期间一直在转的八支）
│   ├─ 未来二支：生 · 老死（尚未到来）
│   └─ 所谓「二八二」＝过去二、现在八、未来二，共十二支配属三世
│
├─ 三、两种有轮的安立（同一个轮回，两种说法）
│   ├─ **践行者**以无明为根本：见解很坚固、凡事「通过控制来完成」的人，
│   │   其执取只要会导致愁、悲、苦、忧、恼升起，它都是无明
│   ├─ **爱行者**以爱为根本：贪图色声香味触的享受、或「躺平算了」的人，
│   │   其轮回的根本是贪爱，故属爱为根
│   ├─ 说第一种有轮（无明为根本）→ 为**根除断见**：果报有因而生，显明诸因不断，
│   │   不是偶然、不是父母精卵结合就无因出现
│   └─ 说第二种有轮（爱为根本）→ 为**根除常见**：这一生的识名色六入触受终归坏灭，
│       没有灵魂、梵我式的永生
│
├─ 四、胎生者与化身者（两种结生方式）
│   ├─ **胎生者**配第一种有轮：如人类十月怀胎、渐次发育——无明爱取之业与父母相合，
│   │   在受精卵上结生「羯罗兰」（入胎的结生名色，仅头发丝尾尖大小），
│   │   最初只有三十种色（心所十法聚 · 性根十法聚 · 身净色十法聚），
│   │   再心脏先发育、肢体发育、六根出现，走「名色→六处→触→受」的次第
│   └─ **化身者**配第二种有轮：如天人死而生天，结生那一刹那**五蕴同时具足**，
│       不经渐次发育——「有」直接产生「生」，生即是五根五蕴一时生起
│
├─ 五、三连接（两重因果的三个咬合点）
│   ├─ 第一处「行 → 识」＝**因果连接**（业 → 果）：过去的业行，导致这一生的结生识生起
│   ├─ 第二处「受 → 爱取有」＝**果因连接**（果 → 烦恼）：受是果报，遇到果报就采取行动，
│   │   果报一出来，人就开始造业——这个行动不是善的就是不善的，没有中间状态
│   ├─ 第三处「有 → 生」＝**因果连接**（业 → 果）：所造之业在临死时成熟，
│   │   导致未来结生；从死亡到结生，也是业成熟
│   └─ 三处连起来是「因果 · 果因 · 因果」，故说「**因果因而有三连接**」
│
├─ 六、二十行相有轮（把两重因果铺成一张完整的循环图）
│   ├─ 过去五因（无明 · 行 · 爱 · 取 · 有）→ 现在五果（识 · 名色 · 六入 · 触 · 受）
│   ├─ 现在五因（爱 · 取 · 有 · 行 · 业）→ 未来五果（生 · 老死 · 愁 · 悲 · 苦 · 忧 · 恼）
│   ├─ 二十行相的构成：过去五因 · 现在五果 · 现在五因 · 未来五果，合共二十行相
│   └─ 「现在五因」里也含无明：爱、取与其相应的无明同在，「有」则涵盖其前分的行——
│       所以根除无明不是回到过去，而是在当下每一个「受缘爱」处下手
│
├─ 七、缘起图与四象限（轮回图怎么看）
│   ├─ 图共**八个圈**（从无明起转到最外），分作**四个大区域**
│   ├─ **内圈：无明与爱**＝轮回的两个根本——无明以过去的无明缘行代表，
│   │   爱以这一生的受缘爱的爱、取代表（受缘爱此处亦有无明，只是简说）
│   ├─ 第一象限（过去因：无明 · 行）＝**集谛所摄**：属过去因的阶层，是烦恼轮转
│   ├─ 第二象限（现在果：识 · 名色 · 六入 · 触 · 受）＝**苦谛所摄**：
│   │   果报只要出生就不圆满、低劣、会坏掉，这就是苦
│   ├─ 第三象限（现在因：爱 · 取 · 有）＝**集谛所摄**：每个当下正在发生的造作
│   └─ 第四象限（未来果：生 · 老死）＝**苦谛所摄**：未来果的实内容仍是识名色六处触受
│
├─ 八、三轮转（有轮为什么转个不停）
│   ├─ **烦恼轮转**＝无明 · 爱 · 取（过去的无明 ＋ 今生的爱取）
│   ├─ **业轮转**＝行 · 业有（过去的行 ＋ 今生的业有）
│   ├─ **果报轮转**＝识 · 名色 · 六处 · 触 · 受 · 生 · 老死（今生果报 ＋ 来生生老死）
│   └─ 三种轮转相续成「有轮」：**只要尚未断除烦恼轮转，就会持续不断地滚动不息**
│
├─ 九、唯一下手处——受缘爱
│   ├─ 过去世的无明与行**已经过去**：未修到观智之前，不可控，也无从了知——
│   │   过去的业跟这一生到底什么关系，是佛教最深奥、也最下不了手的地方
│   ├─ 三处连接里，只有「受 → 爱」是**当下可碰**的：第一处在过去，第三处在临终来生
│   └─ 所以面对果报时，应当**如理作意**——这是课程里反复强调的一句话；
│       「受是果报」，随后那个「要」才是当下可作意的
│
├─ 十、过去爱 · 现行爱与果报受（受凭什么引生爱）
│   ├─ **过去爱**是轮转的根：过去爱导致现在的爱生起；对过去未来而言，现在爱也是过去爱
│   ├─ **果报受**以「**亲依止缘**」为爱之源：受是果报，它不能「生」爱，
│   │   只作强有力的助缘
│   ├─ **非果报受**（速行上的受）以「俱生 · 无间 · 亲依止」等为爱的缘：
│   │   速行上的受若与贪相应则俱生，速行之间是无间
│   └─ 现行爱分两种：**觅求爱**（为追求受用而奔走，如行于羊肠小道）·
│       **觅得爱**（已求得受用、正享用时生起的爱）——都是为了某一种感受而追求
│
├─ 十一、从爱到一切恶不善法（九种次第与四种胜解）
│   ├─ **九种次第**＝寻求 → 得 → 抉择 → 欲贪 → 耽着 → 固执 → 悭吝 → 守护 → 执持刀杖：
│   │   一条从最微细到最粗重的放大线，全都从爱出发；看清次第，就知在哪一步刹车
│   ├─ 爱与寻求：因爱存在故寻求存在——如寻求四种食物（段食 · 触食 · 意思食 · 识食）
│   ├─ **四种胜解**（抉择的四种性质）：**智胜解**（知乐及其因、照做以致未来有乐，即自觉者）·
│   │   **贪胜解**（基于一百零八种爱而抉择）· **见胜解**（依六十二种邪见而抉择）·
│   │   **寻思胜解**（以寻思斟酌可欲非可欲、我将享用储藏等）
│   └─ 现行爱生起时「有如被揪发、令人嚎叫而偏离一向之路径」：极难控制，往往会倒在里面
│
└─ 十二、从缘起看解脱（本周落点）
    ├─ 过去的无明与行已不可及，未来果尚未到来——**今生唯一的下手处就是受缘爱**
    ├─ 帕奥禅师：以**毗婆舍那智**断除「见」与「爱」两种根本，如以**智剑斩有轮**，方能出离
    ├─ **还灭不是把什么打碎**：看清「我所爱的，究竟是哪一种受、那样的受可否依止」，
    │   爱自然松了一分；一分一分地松，还灭就从这里开始
    ├─ 解脱不是逃到哪里去：就在当下这一念「受缘爱」里，**不再被自动带走**
    └─ 能停一停，就是希望在的地方：看清机制是修行的起点，不是给自己定罪
```

**本周要点**

1. **三世两重因果**＝两条链子首尾相接：过去（无明·行）→ 现在（识·名色·六入·触·受）；现在（爱·取·有）→ 未来（生·老死）。第一重以无明为根本、受为终结，第二重以爱为根本、老死为终结。
2. **两重并说的用意**是同时根除二边：破断见（果报有因而生，非偶然）＋破常见（此生识名色终归坏灭，无灵魂永生）。
3. **二八二支与三时**：过去二支（无明·行）／现在八支（识·名色·六入·触·受·爱·取·有）／未来二支（生·老死）。
4. **两种有轮**：践行者（见解坚固、靠控制完成）以无明为根本；爱行者（贪图享受）以爱为根本。其余生方式亦两分：胎生者渐次发育（羯罗兰→三十种色→六根出现），化身者结生一刹那五蕴同时具足。
5. **三连接**：行→识（因果连接 · 业→果）· 受→爱取有（果因连接 · 果→烦恼）· 有→生（因果连接 · 业→果）——「因果因而有三连接」。
6. **二十行相有轮**：过去五因 · 现在五果 · 现在五因 · 未来五果，合共二十行相；所谓轮回，就是「遇到果报 → 作出反应」被重复了无数次。
7. **缘起图八圈四象限**：内圈无明与爱为轮回根本；第一象限过去因与第三象限现在因属集谛所摄，第二象限现在果与第四象限未来果属苦谛所摄。
8. **三轮转**：烦恼轮转（无明·爱·取）· 业轮转（行·业有）· 果报轮转（识·名色·六处·触·受·生·老死）；只要烦恼轮转未断，有轮就持续滚动。
9. **唯一下手处——受缘爱**：过去已不可及、未来尚未到来，三处连接里只有「受→爱」是当下可碰的；面对果报应如理作意。
10. **受凭什么引生爱**：过去爱是轮转的根；果报受以亲依止缘为爱之源（是助缘不是「生」）；非果报受以俱生·无间·亲依止为缘。现行爱分觅求爱与觅得爱。
11. **九种次第**＝寻求→得→抉择→欲贪→耽着→固执→悭吝→守护→执持刀杖，全从爱出发；**四种胜解**＝智·贪·见·寻思。
12. **从缘起看解脱**：以毗婆舍那智断见与爱、以智剑斩有轮；还灭不是把什么打碎，而是看清后自然不取——解脱就在当下这一念「受缘爱」里，不再被自动带走。
