## 🧘 静心开场（10 min）

> 💬 **破冰｜3–5分钟**：此刻你身上的温度、心情和念头，都是过去留下的果；而你接下来做什么，又会成为新的因。说说现在的你正处在什么样的「果」里？

> 🛡️ **心理安全三约定**（每次开场在心里过一遍）：① **保密**——这里说的话不出这间屋子；② **不评判**——不评价任何人的分享，也不急着评价自己；③ **可随时暂停**——任何时候觉得不舒服，都可以停下来休息、喝水或离开，不需要解释。

**主持人引导语**（照读即可）：

请大家轻轻坐好，背脊自然挺直，双手安放在腿上，眼睛微闭，或轻轻下垂。先做三次深长的呼吸，慢慢把一天的忙碌放下。

现在，把注意力带回到呼吸。吸气，知道自己在吸气；呼气，知道自己在呼气。不去控制它，不去调整它，只是陪着它。

静下来之后，我们轻轻做一件事：回顾今天。今天，一定有某一件「果报」来到你面前——可能是一句话、一个眼神、一个消息、一次身体的感觉。它来的时候，你心里先有了一点感受：舒服、不舒服，或者不苦不乐。请挑一件今天就发生的，慢慢回想。

想起来了，就停在那里。看清楚：先有的，是那个「受」——舒服还是不舒服；接着，几乎是同时，心里有了一股力量，想要什么、想推开什么、想说什么、想做什么。那一股想要动起来的力量，就是今天我们要温柔地认识的——「爱」和「取」。

不用急着评价自己。只是看见：一个果报来了，一个受起来了，一个爱、取跟着来了，于是我又造了一个新的「行」。一条链子，就在我身上转了一圈。这一圈，就是「三世两重因果」里的第二重——现在因，正在为未来种下果。

如果你愿意，可以再往前追一步：这一串反应里，有没有一个「我」在？还是说，只是「受」生了，「爱」就跟着生？不必急着回答，只是轻轻地看。

好，现在把注意力放回呼吸，安安静静地坐一会儿……（静默约 3 分钟）……

也请留意：这三分钟里，念头一定还会跑掉。跑掉不是失败——恰恰相反，你「发现它跑掉了」，就是你第一次转身，看见了那颗平常一直自动转的心。每一次把它轻轻带回呼吸，都是在松开那张「受→爱」的网一点点。我们不需要做到「不跑」，只需要练习「发现」。

现在慢慢把注意力带回身体，感觉坐姿、感觉双手，准备好时，轻轻睁开眼睛，回到我们这个教室。

> ⚠️ 主持人操作：引导语照读即可，语速放慢；说到「挑一件今天就发生的」时，提醒大家「不必说出内容，自己知道就好」，避免暴露隐私；静默时间用手机计时，不要因安静而慌张。若有人一时想不起具体的事，就请他停在「一个不舒服的感觉」上即可，不必强求场景。

## 🗺 本周知识地图

**本周是四周的收束课（＝8W7＋8W8）：把十二支合起来，看它在自己身上怎么转。**
一句话说清：**十二支按「过去二支、现在八支、未来二支」分成三世，串成两重因果；
两重因果上有三个连接点，其中只有「受→爱」这一处是当下能碰的；
而整条链之所以转个不停，是因为无明与爱这两个根本没有被断。**
看清这三个连接，就知道今生唯一的下手处在哪里。

```
三世两重因果 · 三连接 · 三轮转 · 从缘起看解脱（全链收束）
│
├─ 一、三世两重因果（＝两条链子首尾相接）
│   ├─ 第一重「过去因 → 现在果」：过去（无明·行）→ 现在（识·名色·六入·触·受），
│   │   以**无明**为根本、以**受**为终结——这一生的果报，是从过去因缘而来的
│   ├─ 第二重「现在因 → 未来果」：现在（爱·取·有）→ 未来（生·老死），
│   │   以**爱**为根本、以**老死**为终结——此刻的执取，正在结出未来的生死
│   └─ 两重并说的用意是**同时根除二边**：由「果」的生起显明诸因不断，故根除断见；
│       由已生的识、名色、六入、触、受终归坏灭，故根除灵魂说、梵我说等常见
│
├─ 二、二八二支与三时
│   ├─ 过去二支：无明 · 行（已过去，看不见、也下不了手）
│   ├─ 现在八支：识 · 名色 · 六入 · 触 · 受 · 爱 · 取 · 有（生命期间一直在转的八支）
│   ├─ 未来二支：生 · 老死（尚未到来）
│   └─ 所谓「二八二」＝过去二、现在八、未来二，共十二支配属三世
│
├─ 三、两种有轮的安立（同一个轮回，两种说法）
│   ├─ **践行者**以无明为根本：见解很坚固、凡事「通过控制来完成」的人，
│   │   其执取只要会导致愁、悲、苦、忧、恼升起，它都是无明
│   ├─ **爱行者**以爱为根本：贪图色声香味触的享受、或「躺平算了」的人，
│   │   其轮回的根本是贪爱，故属爱为根

│   │   不是偶然、不是父母精卵结合就无因出现
│   └─ 说第二种有轮（爱为根本）→ 为**根除常见**：这一生的识名色六入触受终归坏灭，
│       没有灵魂、梵我式的永生
│

│   ├─ **胎生者**配第一种有轮：如人类十月怀胎、渐次发育——无明爱取之业与父母相合，
│   │   在受精卵上结生「羯罗兰」（入胎的结生名色，仅头发丝尾尖大小），
│   │   最初只有三十种色（心所十法聚 · 性根十法聚 · 身净色十法聚），

│   └─ **化身者**配第二种有轮：如天人死而生天，结生那一刹那**五蕴同时具足**，
│       不经渐次发育——「有」直接产生「生」，生即是五根五蕴一时生起

│   ├─ 第一处「行 → 识」＝**因果连接**（业 → 果）：过去的业行，导致这一生的结生识生起
│   ├─ 第二处「受 → 爱取有」＝**果因连接**（果 → 烦恼）：受是果报，遇到果报就采取行动，
```

**本周要点**

1. **三世两重因果**＝两条链子首尾相接：过去（无明·行）→ 现在（识·名色·六入·触·受）；现在（爱·取·有）→ 未来（生·老死）。第一重以无明为根本、受为终结，第二重以爱为根本、老死为终结。
2. **两重并说的用意**是同时根除二边：破断见（果报有因而生，非偶然）＋破常见（此生识名色终归坏灭，无灵魂永生）。
3. **二八二支与三时**：过去二支（无明·行）／现在八支（识·名色·六入·触·受·爱·取·有）／未来二支（生·老死）。
4. **两种有轮**：践行者（见解坚固、靠控制完成）以无明为根本；爱行者（贪图享受）以爱为根本。其余生方式亦两分：胎生者渐次发育（羯罗兰→三十种色→六根出现），化身者结生一刹那五蕴同时具足。
5. **三连接**：行→识（因果连接 · 业→果）· 受→爱取有（果因连接 · 果→烦恼）· 有→生（因果连接 · 业→果）——「因果因而有三连接」。
6. **二十行相有轮**：过去五因 · 现在五果 · 现在五因 · 未来五果，合共二十行相；所谓轮回，就是「遇到果报 → 作出反应」被重复了无数次。
7. **缘起图八圈四象限**：内圈无明与爱为轮回根本；第一象限过去因与第三象限现在因属集谛所摄，第二象限现在果与第四象限未来果属苦谛所摄。
8. **三轮转**：烦恼轮转（无明·爱·取）· 业轮转（行·业有）· 果报轮转（识·名色·六处·触·受·生·老死）；只要烦恼轮转未断，有轮就持续滚动。
9. **唯一下手处——受缘爱**：过去已不可及、未来尚未到来，三处连接里只有「受→爱」是当下可碰的；面对果报应如理作意。
10. **受凭什么引生爱**：过去爱是轮转的根；果报受以亲依止缘为爱之源（是助缘不是「生」）；非果报受以俱生·无间·亲依止为缘。现行爱分觅求爱与觅得爱。
11. **九种次第**＝寻求→得→抉择→欲贪→耽着→固执→悭吝→守护→执持刀杖，全从爱出发；**四种胜解**＝智·贪·见·寻思。
12. **从缘起看解脱**：以毗婆舍那智断见与爱、以智剑斩有轮；还灭不是把什么打碎，而是看清后自然不取——解脱就在当下这一念「受缘爱」里，不再被自动带走。

#### 6. 三世两重因果

#### 6.1 无明与爱为根本

接下来，讲到《清净道论》中讲到三世两重因果。它说：“如此了知后，还更应知：彼之无明、爱为根，过去等而有三时，以诸支中之同类，而有二支与八支。”这二支与八支后面会讲。即当知这有轮的无明与爱恶法为根本。此有轮有两种：从前际带来果报，故无明为根本，受为终结；与后继相连，故爱为根本，老死为终结。其中的前者是依“践行者”而说的，后者是依“爱行者”而说的。确实，践行者的无明及爱行者的爱，能够导致轮回。

或者，正因为通过“果”的生起，能显明诸因的不断，所以为了根除断见而说第一种有轮。正因为能够显明已生的识、名色、六入、触、受的老死，所以为了根除常见而说第二种有轮。或者，正因为能够显明“以行为缘故有识，以识为缘故有名色”等，而有诸法的次第转起，所以依“胎生者”而说第一种；正因为能够显明所生诸蕴的一同生起，所以依“化身者”而说第二种。

#### 6.2 两种有轮的安立（践行者与爱行者）

再者，过去、现在、未来是那有轮的三时。其中的无明与行两支是过去时；由识开始，识、名色、六处、触、受、爱、取、有这个八支是现在时；生与老死二支是未来时。这个“二八二”就这样出来了。

经文说“彼之无明、爱为根，过去等而有三时，与诸支中之同类，而有二支与八支”，意思是：这有轮有两重因果——以过去业带来的果报，就是这一生的识、名色、六入、触、受，以无明为根本；无明缘行、行缘识、识缘名色、名色缘六处、六处缘触、触缘受，以受为终结。而从爱取有到老死这一路连接，以“爱”为根本、老死为终结。这就是过去因、现在果，现在因、未来果的两重。

为什么这么安立？前者——无明为根本——是给“践行者”说的：见解很坚固、往往也比较聪明的人，称为践行人。后者以爱为根本，是给“爱行人”说的：大部分以贪爱为根，即贪性行者。经典里践行者、爱行者与嗔行者、贪行者是分开讲的，为说明方便，这里大致对应。

为什么践行者以无明为根本？因为他会坚固地执持某一种见解，而只要这种执持会导致愁、悲、苦、忧、恼升起，它都是无明。禅修里有种“高智商综合征”：紧张、抓取、控制。他们在世间往往获得过很多成功，被高度评价、受很多人关注，于是对那份愉悦执取而生爱，爱又变成执取——这执取就是邪见：“凡到我面前来的事，我都能通过控制来完成。”可禅修是自然如实的，一旦不如实，就想“我觉得要控制”，这就是以他的见为根。所以他以无明为根本。

那么爱行者，他是以“爱”为根本。爱行者，他就是比较贪图享受。要么去贪着色、声、香、味、触，要么就贪图“我躺平了算”。那么他的这个轮回的根本，是这些原因导致他——他反过来，见解不多，你说怎么样都行，反正你得让我乐呵。就是那样的一种思路了。所以佛陀以这两个角度来讲这个过去因、现在果和现在因、未来果。

#### 6.3 根除断见与常见

还有一种，就是“或者正因为通过‘果’的生起，能显明诸因的不断”——就是因为这个，你看有识、名色、六入、触、受这个果生起，这个果生起是有原因的，什么呢？无明、爱、取、行、业，所以产生这个诸因的不断。所以它会根除这个断见——你认为生命是偶然出现，或者是父母精卵结合的偶然现象——它这种无因见，我们过去讲的无因见、生命是无原因开始的。再一个，“正因为能够显明以生起的识、名色、六入、触、受的老死，所以为了根除灵魂说、梵我说、有生等常见，而说第二种有轮”。就是这个你现在这个识、名色、六入、触、受，也就是下一生的这个生、老死、愁、悲、苦、忧、恼这些内容，它都会死掉的，最后会死掉。就是你这一生的爱取导致下一生的结生，它是会死掉。那么这个就可以破除我们讲说的灵魂说、梵我说、永生——不会永生的。这样的第二种的来说明这第二种轮回。

#### 6.4 胎生者与化身者

那么第三类，就是“或者正因为能够显明‘以行为缘故有识，以识为缘故有名色’等，而有诸法次第转起，所以依‘胎生者’而说第一种”。就像我们人类，它是十月怀胎，渐次发育。首先，父母准备好的一个受精卵，然后你刚好你的无明、爱、取、行业跟你这个父母这个家庭它相契合，所以你的业就会在那个受精卵上生起一个结生名色。这个入胎的结生名色，我们过去叫“羯罗兰”。然后从这个只有像头发丝的尾巴那么一点点的这么大的东西，慢慢地发育，发育成一个胎儿。我们最初结生的色法，有心所、心色十法聚、性根十法聚和身净色十法聚，它只有三十种色法。然后慢慢的发展——它会心脏先发育，然后慢慢的肢体发育，然后六根就会出现。这个就是从名色再到六处、再到触、受这样的过程。这是胎生者的一种情况。

那么对于这个化身，“正因为能够显明所生诸蕴的一同生起，所以依‘化身者’而说第二种”。就像天人，这个化身的时候：如果你这一生死了，那么以你的这个善业导致在天界生起，不管是色界天还是欲界天。在结生的那个刹那，如果你是五蕴的生命，那五根具足了，五蕴同时在一刹那同时生起来。那以此来说这个“有缘生，老死、愁、悲、苦、忧、恼”——就是这个“有”，直接产生这个“生”，这个“生”就是你的五蕴同时具足。所以佛陀讲这个两种有轮的三时，还有这样的一个背景。

#### 6.5 二八二支与三时

再者，过去、现在、未来是那有轮的三时。当知通过依同类而出自圣典的方式，其中的无明与行两支是过去时；由识开始，识、名色、六处、触、受、爱、取、有这个八支，是现在时，就是我们在生命期间，你的这个缘起支就是这个八支；而生、老死呢，这个两支是未来时。这个就是前面偈颂讲的“二八二支”的这个的具体表述。

#### 7. 三连接与四类色

#### 7.1 因果连接与果因连接

除此之外，他还说：“还更应知，此有轮以过去因果，因而有三连接四种类。”或者四摄、二十行相有轮。三轮转的有轮滚动不息，始终诸行与时之间。是一种“因果连接”——行与识之间；受与爱之间是一种“果因连接”；有与生之间是一种“因果连接”。当如此了知此有轮以过去因果，因而有三连接。

那个“行缘识”——行，过去的业行，导致这一生的结生识生起来，这个是因果连接。这一生由于“受缘爱”，“爱缘取”，“取缘有”——这个是果因连接：受是果报，然后我们讲你每天都在干些事儿——就是每天遇到一个果报，对它采取行动。遇到一个果报，对它采取行动。反正你就是不断地跟果报干，那就是这样的一个方式。所以它是果因连接：果报一出来，你就开始采取一个行动。这个行动不是善的，就一定是不善的，它不会有中间的状态。那只要造业呢，它就会在临死的时候成熟，导致未来结生。这个从死亡到结生呢，也是一个业成熟，它是因果连接——“有”到“生”，是因果连接。所以它是因果、果因、因果，叫“因果因而有三连接”。

**【◈扩展段落一 · 二十行相有轮】**

「三连接」之外，《清净道论》还把这一圈铺成一张更完整的图，叫「二十行相有轮」——就是把十二支在三世两重因果上完全展开：过去有五因，结出现在的五果；现在又有五因，再结出未来的五果，合起来正好二十个行相。

具体说：**过去五因**是无明、行、爱、取、有；由这五因成熟，感得**现在五果**——识、名色、六入、触、受，也就是我们这一生全部的果报。而现在这一生，又在造**现在五因**——爱、取、有，以及它所涵盖的行与业；这五因成熟，就结出**未来五果**——生、老死，以及随之而来的愁、悲、苦、忧、恼。

这里有一个容易误解的地方：既然「无明」被列在过去五因里，是不是说无明只属于过去、跟现在没关系？不是的。现在五因里的「爱」与「取」，本身就与其相应的无明同在；而「有」也涵盖着它前分的「行」。所以无明、爱、取并不是三个各自独立的东西，而是同一股「不明真相而伸手」的力量的三种作用。明白了这一点就知道：所谓根除无明，不是要回到过去把它挖出来，而是在当下每一个「受缘爱」的地方下手。

所以「轮回」这个词，落到实处就是一句大白话——**遇到果报，作出反应；这个反应又成为新的因，再结出新的果**，如此被重复了无数次。我们过一天，其实就是这张图转过了一圈。

## 🎯 第一轮主题讨论（10 min）
讨论问题（按优先级，主持人可根据现场选择）：

> 讨论总原则：**先落到具体的事，再谈抽象的名相**。任何一次讨论，只要有人开始复述原文的名相清单，就请他举一个昨天真实发生的例子，从「当时是什么果报、什么受、什么反应」讲起。

1. **「三世两重因果」到底在说什么——为什么它不是「一个我」从过去走到未来？**
   追问路径：先请一位学员用自己的话说出「二八二支」（过去两支＝无明、行；现在八支＝识到有；未来两支＝生、老死）→ 再追问：如果说「过去的我」就是「现在的我」，那会落入哪一种见？（常见／灵魂说）如果说「过去的业跟我毫无关系」，又落入哪一种见？（断见）→ 落到：佛陀用「两重因果」正是为了同时根除断见与常见——果从因来，故非常；果灭了不再有同一实体延续，故非断。
   主持人可补一句：材料①说，第一种有轮「为根除断见」而说，第二种「为根除常见」而说。所以「三世两重因果」不是「有一个人在轮回」，恰恰是「没有一个人，却仍然相续」。
2. **三个连接点，今生我们能下手的究竟在哪一个？为什么？**（本周重点）
   追问路径：先请学员分别说出三个连接——（一）过去行→现在识（因果连接）、（二）现在受→爱取有（果因连接）、（三）现在有→未来生老死（因果连接）→ 追问：第一个连接，过去的业我们看不看得见、控不控得住？（看不见，也控不住）第三个连接，是一期生命结束时才成熟，当下能不能改？（只能等果）→ 只剩第二个——「果报受引生爱取」，是每天都在发生、就在眼前的。→ 落到：材料②说「我们真正今生能下手的，关键其实是受缘爱」；材料③补一句：「你要看到那个受……那这个东西你要把它破掉，不把它破掉，后面那个爱和执取是很难破的」。
   主持人可再追问：为什么偏偏是「受」？因为材料③说「一切法与受会合」——一切五蕴之法，都要通过受来体验；爱和执取，都是因为我们倾向某一种受。
3. **「每天遇到果报，就动手」——请各人举一个今天真实发生的例子，找出背后的「欲取」还是「见取」。**
   追问路径：请学员描述一次「遇到一件事→立刻反应」的片段 → 追问：这个反应，是「我想要那个感觉」（欲取），还是「我认为应该这样」（见取）？→ 再追问：那个「爱」后面，你真正想要的是哪一种「受」？如果那个受得不到，会怎样？→ 落到：材料①说「你每天都是在干果报——果报来了，就干」，又说「你要去找到那个爱后面的这个受——你失去什么受」。
   主持人可给一个区分的小口诀：**「只是想做」= 欲取；「必须这样才对」= 见取**。请学员各举一例对号入座。
4. **（时间富余时）「二十行相有轮」说过去五因、现在五果、现在五因、未来五果。请说说：为什么「现在五因」里也隐含了「无明」？**
   追问路径：学员常见误解是「无明只是过去的」→ 请回到材料①：现在五因是爱、取、有，而「爱、取」与其相应的无明同在，「有」则涵盖其前分「行」→ 落到：无明、爱、取不是三个独立的「东西」，而是同一股「不明真相而伸手」的力量的三种作用。所以「根除无明」不是回到过去，而是在当下每一个「受缘爱」处下手。

5. **（时间富余／老学员）「三连接」里，为什么说「受→爱取有」是唯一「活」的连接？**
   追问路径：引导学员把三个连接排成一列，逐个问「这一处，我此刻能不能碰得到？」→ 第一处（行→识）在过去，碰不到；第三处（有→生）在临终与来生，此刻碰不到；只有第二处（受→爱取有）就在当下每一次反应里。→ 落到：材料②说「我们真正今生能下手的，关键其实是受缘爱」。最后请每人用一句话说出「我今天想守住的是哪一个受」。

> **分层追问**（可视时间取用，由浅入深）：
> - 【现象】今天你享用到的一件事，其实是更早时候的付出换来的——是哪一个？
> - 【影响】如果今天的行动正在为将来写下因，你对「此刻」的分量感受如何？
> - 【应对】这周挑一件每天都做的小事，有意识地做一次，把它当成给未来的播种。

### 讨论常见误区与应答（主持人备用）

- **误区一：「三世两重因果＝宿命论」**。学员可能会问：「既然过去五因已经定死了现在五果，那我努力还有用吗？」应答：五果（识、名色、六入、触、受）确实是过去业所感的「果报」，这一部分不能改；但「现在五因」（爱、取、有）正是你现在正在造作的——**果报不能改，对果报的反应可以改**。所以轮回「相续」不等于「注定」，关键就在第二个连接点上。可回扣材料②：过去已经过去，你无从了知、也控不住；能下手的，是当下的受缘爱。
- **误区二：「既然无我，那是谁在轮回？」**。应答：佛陀不是说「有一个我在轮回」，也不是说「没有相续」；而是说「因缘的相续」——像灯焰，前一念灭、后一念生，不是同一团火，也不是凭空而来。这正是「两重因果」要**同时**破掉的断、常二见：说「果从因来」破断见，说「没有一个实体越世延续」破常见。
- **误区三：「过去世的业我又看不见，讲它有什么用？」**。应答：材料②自己就说了——「过去的无明和行，你根本无从了知」。但《清净道论》立「三世两重因果」，不是为了让你去查前世，而是为了让你看清「现在因→未来果」这一条当下可控的链子。看得懂过去，是为了知道现在该在哪里松手。
- **误区四：「受有什么好观的？不就是感觉吗？」**。应答：材料③说「一切法与受会合」——一切五蕴之法都要**通过受来体验**；爱和执取，都是因为我们倾向某一种受。所以「受」不是无关紧要的感觉，它是「爱、取」的门口。看得住受，就看得住后面那一大串（从寻求一直到执持刀杖）。
- **误区五：「那是不是要压住感受、不许有爱？」**。应答：不是。材料③明说「如果你觉得我不能爱，其实你是不能解决问题的」。方法不是把它压下去、也不是骂自己「怎么又贪了」，而是**看清你爱的是哪一种受、那个受有什么过患**，于是自然地削弱——「看到所受，比急着消灭爱更有效」。
- **误区六：「九种次第从寻求一直到执持刀杖，是不是太夸张了？」**。应答：它是一条完整的「从微细到粗重」的放大过程——每天从「想要」到「得到」到「耽着、守护」到「争执」，其实都在重演同一条线。看清这条线，是为了在**最早的「寻求」那一端**就松手，而不是等闹到「执持刀杖」才后悔。
- **误区七（老学员）：「十二支和二十四缘具体怎么配？」**。应答：这属于下一阶段（读书会12）的内容。本周只把「三世两重因果」与「二十行相」这一张总图认下来，把「受缘爱」这一处落实在自己身上。请勿现场展开。

### 主持人串场话术（照读参考）

- 从静心进入共读时：「刚才我们各自看见了一次心里的循环。现在，让我们看看《清净道论》是怎么把这条链子讲清楚的。」

- 从材料②进入材料③时：「前面讲了『受缘爱』才是今生下手处；那么从『受』这一环往后，到底会长出什么？材料③把这条线索一直拉到我们每天的争执。」

### 练习一
**主持人引导语**（照读即可）：

请大家重新坐好，背脊挺直，手轻轻放在腿上，眼睛微闭。先做三次深呼吸，把身体放松下来。

现在，我们不急着找什么特别的对象，只是安静地坐着，让身体自然地呼吸。呼吸的时候，请留意自己此刻的感受：坐得舒服吗？有没有哪里紧、哪里痛？这些是身体的感受——先只是知道它，不急着改变它。

接下来，我们做一件很朴素的事：在这十五分钟里，不管心里生起什么——一个念头、一段回忆、一点情绪——请留意它带来的「受」：是舒服的，不舒服的，还是中性的。当舒服的受生起，看看心里会不会马上伸出一只手，想抓住它、想多要一点；当不舒服的受生起，看看心里会不会马上想推开它、想让它快走。

不用去压制那只手，也不用责备自己。只是看着它：一个受起来了，一个反应跟着来了——就在这短短的一瞬里，我们每天不知重复多少次的那个「受缘爱」，正在发生。你不是要去把它消灭掉，只是第一次这样清楚地看见它。

如果你愿意，可以再细看一步：那只「想抓」或「想推」的手，它背后真正想要的，是哪一个「受」？是想要那种舒服再多停留一会儿，还是想要那种不舒服快点消失？看清楚这个「想要什么受」，往往比急着推开那个念头更有用。

如果发现自己被卷进去了，不要着急。轻轻回到呼吸，回到此刻的这一个感受，重新开始。看见一次，就少一分盲目；少一分盲目，那一根连接的绳子上，就松了一点点。

现在慢慢把注意力带回身体，感觉坐姿、感觉双手，准备好时，轻轻睁开眼睛，回到这个教室。

### 练习二
**主持人引导语**（照读即可）：

请大家坐好，轻轻闭上眼睛，做三次深呼吸，把身体安放在当下。

今天我们不刻意去找什么，只是安静地坐着，让心自然放松。慢慢地，留意一下此刻身体上最明显的一处感受——也许是坐垫的压迫、空气的凉、肩膀的紧。知道它，就够了。

现在，把这个感受辨认一下：它是舒服的、不舒服的，还是不苦不乐的？这是「受」。受，多半是过去业带来的果报，不由我们挑选。

接着，轻轻地问自己一句（不用回答出声）：对这个感受，我心里有没有一点点「想要它多一点」或「想要它走开」？如果有，那就是「爱」。它可能很细微，甚至只是一个方向。**注意：这就是今晚说的下手处——受已经在了，爱刚刚要起，我们就在这一线之间停一停。**

我们不阻止它，也不责备自己，只是知道：受在这里，爱在这里。看清它，它就松了一点。这就是「受缘爱」的练习——不是要马上没有爱，而是给它一点觉知的空间。

再试一次，换一个当下的感受：也许是坐久了腿麻，也许是一阵风、一声响。看它，命名它是舒服、不舒服还是不苦不乐；再看心里那一点「想让它变」。就这样，一次，两次。你会发现——原来「停一停」是可以练的，而且越练越熟。

好，把注意力放回呼吸，安安静静地坐一会儿……（静默约 3 分钟）……

现在，慢慢把注意力带回身体，感觉坐姿、感觉双手，准备好时，轻轻睁开眼睛。请大家在心里记住今晚这一张图：果报轮转 →（受缘爱）→ 烦恼轮转 → 业轮转 → 果报轮转。我们下手的地方，就在那个括号里。

最后，把这句话带回生活：受来了，不必赶它走；爱升起了，不必骂自己；只要在它们之间，留一个呼吸的空间。这就是我们今天能找到的、当下就能做的一件事——不是等到「什么时候修好了」，而是从下一杯茶、下一句话开始。

主讲： 古源尊者
日期： 2024年5月12日

「1. 回顾与开场」

礼敬那位世尊，阿拉汉，正自觉者。各位尊者，各位法师，各位贤友，吉祥。萨度！萨度！萨度！

好，今天呢，我们继续来学习《清净道论》的十二缘起的杂论。

「2. 三轮转与三连接」

上一堂课呢，我们讲到了这个三世两重因果的二十形象的轮回。《清净道论》说：再者，当知于此三轮转滚动不息中，行有时是业轮转。无明、爱、取是烦恼轮转，行、识、名色、六处、触、受是果报轮转。以此三者轮转而有三轮转的有轮，只要尚未断除烦恼轮转，就应持续不断，支援而不息，又因一再转动而滚动。

「2.1 缘起图与四象限」

大家来看这个缘起图，一个是著名的缘起图，全世界都在用，换成各种各样的这个语言。

当我们看到这个缘起图有八个圈，从无明开始一直到外面，这一圈有八个圈。那分成四个大区域。

「2.1.1 内圈：无明与爱（轮回根本）」

最内层是无明跟爱，代表轮回的两个根本。图上分别以过去世的无明和行、以及现在世的爱、取、有来体现：无明用过去“无明缘行”的无明代表，爱用这一生“受缘爱”的爱、取代表。其实受缘爱这里也有无明，无明缘行也要有爱、取才有行——只是简说而已。

「2.1.2 第一象限：过去因（无明、行）——集谛所摄」

第一象限代表过去世的无明和行——它其实包括了爱、取，属于过去因的阶层，是集谛所摄：无明缘行属过去世，涵盖许多过去世或下意识，因为是烦恼轮转。

「2.1.3 第二象限：现在果（识、名色、六入、触、受）——苦谛所摄」

第二象限代表今世的识、名色、六入、触、受——我们这一生的果报都含在这五个缘起支里，属现在果的阶层，是苦谛所摄：果报只要出生，识、名色、六处、触、受都是不圆满、低劣、会坏掉的，这就是苦（Dukkha）。

「2.1.4 第三象限：现在因（爱、取、有）——集谛所摄」

第三象限代表当下的爱、取、有——包括业有与生有；爱、取里面也包括无明，业有里面包括行、业。它属于现在阶层，是每个当下正在发生的事，也是集谛所摄。

「2.1.5 第四象限：未来果（生、老死）——苦谛所摄」

第四象限代表未来世的生、老死。生、老死的果报其实也是识、名色、六处、触、受，称为未来果，所以未来果的阶层也是苦谛所摄。

「2.2 三轮转归纳」

过去世的无明和今生的爱、取，这三个合起来属于烦恼轮转；过去世的行和今生的业有，这两个合起来称为业轮转；今生的识、名色、六处、触、受和来生的生、老死，属于果报轮转。这就是三轮转了。

「2.3 三连接」

然后又说有三连接：

- **第一重连接：过去生的行和这一生的识**——过去的业，即业轮转导致这一生的果报轮转生起。
- **第二重连接：今生当下的受**——每天坐在这里听课，眼睛看到的、听到的而产生的感受就是果报受；由此引发爱、取、有。今生的果报导致烦恼轮转生起，就是果报轮转导致烦恼轮转生起。每一个当下，我们就是接受果报，根据这个感受做出无明、爱、取、行、业这样的行为。
- **第三重连接：今生的业有和来生的生、老死**——这一生的业导致未来的果报轮转生起。

以此三种轮转而有三种有轮，不断轮转。只要还没有断除烦恼——无明和爱、取没有断除——就持续不断地缘，不会熄灭，一直滚动。

「3. 修行下手处：受缘爱」

无明和爱、取是轮回的根本。无明缘行我们在课程一开始已用很多课时阐述过；而过去的无明和行已经过去了——对我们现在来讲，如果还没有修到观智，其实不可控，不但不可控，根本无从了知。这也是佛教最深奥的地方：过去的业跟我们这一生到底什么关系？因为看不见、无从了知，所以有很多疑惑，也就下不了手。

其实，我们真正今生能下手的，关键就是受缘爱——好在它就在第二层连接上。所以我们在很多课程里总是不断强调：面对果报的时候，你应该如理作意。

「3.1 过去爱、现行爱与果报受」

根据《中部·大因缘经》的译注：受缘爱，这个爱有过去爱和现行爱。佛陀说，过去爱是轮转的根——过去爱导致我们现在的爱生起；而现在爱对于过去未来来讲，它就是过去爱。

爱之源是受。在此，果报受以“亲依止缘”为爱之源；其他的非果报受，以“俱生”、“无间”、“亲依止”等为爱的缘——非果报受就是速行上的受，速行上的受若与贪相应则俱生，速行之间是无间。当然，过去的爱依然以亲依止缘为爱之源。这三种缘我们前面已经学过了。

「3.2 从爱到一切恶不善法」

那么对于这个现行爱呢，就是你当下生起来的爱，再发生的这个爱。佛陀用九个词来论述它，说它的这个重要性。佛陀说：如是，阿难，缘于受，爱生起，等等。他说呢，这个有如，即被揪发，令人嚎叫而偏离一向之路径般。就是这个由受缘爱呢，那个发生的时候，你是很难控制它的，那往往会倒在里面。

其次呢，在这里面呢，他说这个现行爱者，又分两种，一种叫“觅求爱”，一种叫“觅得爱”。那以彼爱而行于羊肠小道等，觅求追求受用，这个称为叫觅求爱。与彼等以觅求、以追求，以得诸受用正生起之爱，此名为觅得爱。那是源于受的这两种爱，为了某一种感受，我们会去这样追求。

源于爱呢，佛陀讲就有九种事情我们就会去做。

1. **寻求**：对于色、声、香、味、触等所缘的寻求。前面讲过欲爱有三十六种，因爱存在故寻求存在——因为有这种爱，你每天都会去寻求，如寻求四种食物（段食、触食、意思食、识食）。
2. **得**：源于寻求，你就会得到——色、声、香、味、触等所缘就会获得。因为寻求存在，所以这个得迟早都会存在，或多或少都会存在。
3. **抉择**：源于得，你就会有抉择——抉择在心所法里叫“胜解”。胜解有四种：**智胜解**、**贪胜解**、**见胜解**、**寻思胜解**。其中当知乐觉者，知乐及其因而抉择，并践行内在之乐，这就是自觉者；反之不懂这些、总是给未来种苦因的，就不是自觉者。前面讲过一百零八种爱遍寻——基于一百零八种贪而作的抉择，就叫“爱抉择”；《梵网经》讲有六十二种邪见，以这种见而作的抉择，就叫“见抉择”；至于以寻思为因缘而斟酌可欲非可欲、妙美非妙美，若干将为我之色所缘、我将享用、我将储藏等等，就叫“寻思抉择”。寻求、得到，然后就开始折腾，有很多的抉择。

**【◈扩展段落二 · 九种次第】**

源于爱，佛陀用九个词讲一条完整的线：**寻求、得、抉择、欲贪、耽着、固执、悭吝、守护，一直到执持刀杖争斗**。

因为有所爱就去寻求，寻求便有得，得到了就起抉择；抉择定了，倾向越来越强，成为欲贪；得到了便耽着不放，耽着久了变成固执；固执进而悭吝，不愿分享；悭吝便要守护，严防失去；守护不住，最后竟至于执持刀杖而相争斗。

这条线不是夸张，也不是宣判，只是把一件天天经历的小事从头摊开——从「想要」到「争执」，都在重演同一条线，而它的起点小得几乎看不见，就是一次「寻求」。所以不必等到闹到「执持刀杖」才后悔，而可以在**最早的「寻求」那一端**就松手。你最容易在哪一步被带走？看清那一步，那就是你的下手处。

**【◈扩展段落三 · 以受为突破口】**

那么具体从哪里下手？关键在「受」。

一切五蕴之法，都要**通过受来体验**——看到的、听到的、想到的，最后都落成一个「受」。所以爱和执取追到底，都是因为我们**倾向某一种受**：想要舒服的受多一点，想要不安的受快走开。这就是「受」是门口的原因——看得住受，就看得住后面那一大串。

方法**不是**把感受压下去，也不是爱一起就骂自己「怎么又贪了」。有用的做法，是去看**我所爱的，究竟是哪一种受？那样的受，能不能依止？**看清了，爱自然松了一分；一分一分地松，还灭就从这里开始。

为说明这种颠倒有多深，经典用了一组譬喻：**盲人失足**——看不见路的人一脚踏空而不知险在何处；**饮用盐水增渴**——越喝越渴，以为在解渴，其实在加渴；**鱼因贪饵咬钩**——为着一点饵食，咬上的却是钩。它们说的是**颠倒**，不是**宣判**：把那么一点「受」当成可依靠的，是多么不可靠。

**【◈扩展段落四 · 从缘起看解脱】**

看清了轮回怎么转、在哪里下手，最后要回答：解脱的路在哪里？

帕奥禅师在《观察缘起》里讲得直接：以**毗婆舍那智**断除「见」与「爱」这两种根本，如以**智剑斩有轮**，方能出离。这里的工具是「智」而不是「意志」——不是下决心「我不要再爱了」，而是看得足够清楚，让执取自然失去力量。

这也正是「还灭」的意思：**不是**把什么东西打碎，而是看清之后**自然不取**——看清那只是一个果报、那只是一个受，后面那个「要」就没有那么非伸不可了。解脱不是逃到哪里去，而是在当下这一念「受缘爱」里，不再被自动带走。

经典里还有一句分量很重的话：**不悟缘起，则不得解脱**。落到每天的生活，这条出路就是八正道落于日常——对自己、对他人、对事情、对饮食，都能如实去看，而不是自动反应。所以这一周真正要带走的，是下一次一个「受」起来、手要伸出去的那一瞬，你能**停一停，看一眼**。能停一停，就是希望在的地方。

## 💬 第二轮分享（10 min）

请就以下问题，任选一个分享：

1. 今天静心时，当你回想到那个「很舒服」或「很不舒服」的时刻，有没有一丝「想要它多一点／想让它走开」的微细倾向？它出现得快还是慢？你能在身体哪里感觉到它？
2. 读或听「三轮转」这一张图，你心里第一反应是什么？是觉得复杂，还是觉得它说中了什么？请只描述你当下的感受，不必讲义理。
3. 听到「受缘爱是今生唯一能下手的地方」这句，你心里是松了一口气，还是有点沉重？请说说那一刻你真实的反应。

> 本周是收束课，也是「有情绪的一课」。请主持人把节奏放慢一点：每人分享前先说一句「不急着有答案」，分享后不点评、不总结，只回应一句「谢谢你让我们听见」。若全场都很安静，也不必硬找话题——安静本身，就是这一课的一部分。

## 🎯 第二轮主题讨论（10 min）
本周讨论请「慢而深」，宁可只把第 1 问谈透，也不要把三问都走马观花。开始前先说一句：今晚我们谈的是「机制」，不是「对错」；每个人的答案都从自己的经验里长出来，没有标准解。

讨论问题（按优先级）：

1. **轮回的回路，是在哪一环闭合的？** 原文说：无明、爱、取是烦恼轮转，行、业有是业轮转，识、名色、六处、触、受与生、老死是果报轮转；只要烦恼轮转未断，有轮就持续滚动。追问路径：请一位学员用「刚才的一次不愉快」举例，一起在图里标出：哪一段是果报（不由己）、哪一段是烦恼、哪一段是业？——引导到「轮回不是外面有个轮子，是我此刻的受→爱→取→业在转」。可再补一问：三轮转里，哪一轮是你此刻最能认出来的？看清这一点，会让你更沮丧，还是更有希望？引导到「看清机制＝修行起点」。
2. **过去世的因看不见、下不了手，那今生到底能在哪一环下手？** 原文说：无明、行已经过去，若未修到观智，不可控也无从了知；真正今生能下手的关键，是「受缘爱」——在第二重连接上。追问路径：请一位学员举「被一句话惹恼／被一句赞美说动」的例子，一起标出：哪一个是受（不由己），哪一个是爱（可作意）？——引导到「受不是『我』，爱也不是『我』，但爱正是我们能看清、能作意的地方」。也可追问原文的九种次第——从寻求、得到、抉择，到欲贪、耽着、固执、悭吝、守护、执持刀杖——问大家：你最容易在哪一步被带走？看清那一步，就是你的下手处。可再补一问：如果下手处这么窄、这么小，你愿意从这一小处开始吗？
3. **看清轮回的颠倒，与「解脱」是什么关系？** 原文用盲人失足、饮用盐水增渴、鱼因贪饵咬钩等譬喻说生死，又说「爱和执取，都是因为我们倾向某一种受」，所以要去看到「你所爱的是什么样的受、那样的受可否依止」。反过来，帕奥禅师说：以毗婆舍那智断见与爱、以智剑斩有轮，方能出离。追问路径：请大家比较「沉溺」与「看清」两种状态的区别，问：不急着消灭爱，先看清「我爱的其实是那种受」，会不会已经松了一分？——引导到「还灭不是把什么打碎，而是看清后自然不取」。可再补一问：把「解脱」想成一个遥远的大目标，和想成「今天在受与爱之间停一次」，哪一种更让你愿意当下就试？收束时把话带回「当下可操作的受缘爱下手处」。

> **分层追问**（可视时间取用，由浅入深）：
> - 【现象】回想这周，什么时候你感到「受」一起来，就自动被牵走了？
> - 【影响】如果过去已经改不了，把力气放在「感受生起」这一环，你怎么看？
> - 【应对】这周在感受最强烈的一刻，只做一件事：认出「这是一个感受」，别的先不做。

> ⚠️ 主持人操作：第 1 问是本周的「眼」，务必留足时间；第 2 问是本讲的落点，不能只停在「我下不了手」的无力感，要落到「受一生、爱未成时，我能看它一眼」；第 3 问涉及解脱，容易滑向恐惧或空谈，要随时把「这是观察，不是定罪」带回现场，并把结尾指向可操作的动作。讨论中出现名相分歧（如三轮转与三连接的归类），记下来，说「课后再查证」。若第 3 问触及生死话题、全场忽然安静，不必强行填满——可以说「我们先安静一分钟，再请愿意的人说一句」，把沉默也当作参与。

## 🔚 收尾与回向（15 min）

**总结引导**（主持人用自己的话串讲，不必照读）：

今天我们只做了一件事——把十二支合起来，看它在自己身上怎么转。我们用《清净道论》的「三世两重因果」看见：过去五因结出现在五果，现在五因又结出未来五果；用「三连接」看见三个轮子怎样咬合：过去行→现在识、现在受→爱取有、现在有→未来生老死；用「二十行相有轮」看见「过去五因、现在五果、现在五因、未来五果」这一张完整的循环图。而在这三个连接里，唯一当下就在我们眼前、每天都在发生的，是中间那一个——果报受引生爱取。所以材料才反复强调：今生能下手的，是「受缘爱」；面对果报时，应当如理作意。

请带一句话回家：**轮回，不在遥远的过去或未来，它就在「一个受起来、我立刻伸手」的这一瞬间**。看见这一瞬间，就是松动的开始。看清楚那个「爱」后面你要的是哪一种「受」，比急着压下那个念头更有力。

也许今天你还不能立刻做到「不伸手」——没关系。能看见那只手，就已经和从前不一样了。修行不是一次到位，而是一次一次又一次地，把那个「自动」慢慢变成「知道」。

我们今晚没有要求你「不要爱」、也不要求你「马上断轮回」。原文说得很实在：爱和执取，都是因为我们倾向某一种受，所以真正有用的，是去看「我所爱的，是什么样的受？那样的受，能不能依止？」看清了，爱自然就松了一分；一分一分地松，「还灭」就从这里开始。这就是「从缘起看解脱」——解脱不是逃到哪里去，而是在当下这一念「受缘爱」里，不再被自动带走。

**本周核心回顾（可板书，收尾前 1 分钟带大家念一遍）**：

1. **两重**：过去（无明·行）→ 现在（识·名色·六入·触·受）；现在（爱·取·有）→ 未来（生·老死）。
2. **三连接**：行→识（业→果）、受→爱取有（果→烦恼）、有→生（业→果）。
3. **一个下手处**：三处连接里，只有「受→爱」这一处是当下可碰的——这就是「受缘爱」。
4. **一句话**：果报来了，不必改果报；改的是它来了之后，你伸不伸手、伸手时清不清楚。

**四周回顾与结语**：四周里，我们认了十二支、看了三世两重因果、把轮回收成三轮转——无明、爱、取是烦恼轮转；行、业有是业轮转；识、名色、六处、触、受、生、老死是果报轮转。只要烦恼轮转没断，这个有轮就一直转、一直转。今天我们把它们收成一个环，又在环上找到了一个可以停一停的地方。请记得，这不是结束，而是一种新的开始。愿这四周的学习，成为大家日后如实观察缘起的一点灯；这个系列的共读到这里告一段落，后续若有「缘起深入与二十四缘」的课程，欢迎愿意继续的朋友一起来（本周只讲三世两重因果与二十行相，二十四缘各缘的展开属于下一阶段）。

**收尾现场应对**：

- 若现场气氛偏沉重（有人因看见自己的「爱、取」而自责）：请及时把话头转回「看见即起点」。可以说：「我们今天认出的，不是罪，是机制；能认出机制，就已经在路上了。」
- 若气氛偏兴奋（大家急着回家立刻改造自己）：也请收一收：「不必立一个大计划，只守住一个观察点——下一次一个受起来、手要伸出去的那一瞬。」
- 若有人问「那我是不是什么都别要、什么都别做」：请回：「不是不要做，而是看清楚你为什么做。同样的行动，看清了，力量完全不同。」
- 若时间不足、要提前散场：至少保留「一句总结＋核心回顾＋回向词四句」三段，其余略过。
- 收尾最后一句话建议（可照读）：「愿大家带着今天这一次的看见回家——轮回不在别处，就在你下一次伸手的那一瞬。」

**回向词四句（全体齐诵，照读不省，任何场合不得改动、删减、另写）**：

> **愿我此功德，导向诸漏尽！**
> **愿我此功德，为证涅槃缘！**
> **我此功德分，回向诸有情！**
> **愿彼等一切，同得功德分！**

> ⚠️ 主持人操作：收尾别再开新话题；回向语速放慢，让大家合掌跟随；结束时不急于散场，留 30 秒安静。若场上有情绪，散场后单独陪伴，不在众人前处理。收尾务必带出「当下可操作的受缘爱下手处」，让大家带着一个能落地的动作离开；结束前提醒大家作业，并说一句鼓励的话（例如「今天你能把这根链条看见一次，就已经很了不起了」）。若时间富余，可请每人用一句话说出「我今晚带走的一个动作」（例如「喝茶时看一眼想要」），主持人只点头、不点评，让大家带着彼此的分享散场。

## 📌 本讲主持人特别提醒

1. **本周名相密集，守住「一根主线」**。三世·两重·二八二支·三连接·四类色·二十行相——概念很多，但主线只有一个：**「果报→受→爱取→行」这个每天都在转的小循环**。当讨论开始飘向名词辨析时，请把大家拉回「你昨天遇到了什么、当时怎么反应的」。
2. **严格守边界，不展开二十四缘**。本周只讲三世两重因果与二十行相；凡涉及「十二支与各缘的对应」「发趣法」等，一律归读书会12，请答「我们课后再查证」，不在现场展开。若学员反复追问，可记下问题，课后整理给大家。
3. **「过去业」的讲解要留温度**。讲到「过去的无明、行我们看不见、控不住」时，容易引出无力感甚至宿命论。请补一句：正因为它已过去，我们才不必困在悔恨里；能改变的，正是当下这个「受缘爱」。轮回「相续」不等于「宿命」——因为下一个连接点正握在你手里。
4. **心理安全指引**。本周「九种次第」（从寻求一路到执持杖刀争斗）会让人照见自己平日里种种拉扯，可能引发自我批判。请提前说明：「看清机制，是修行的起点，不是给自己定罪」；分享涉及个人隐私时，主持人主动守边界，允许沉默与不分享。若有人在练习中落泪，不要围上去追问，安静陪伴即可；必要时课后单独问候。请始终记得：本讲的目标是让人「松一口气」，而不是「多背一层压力」。
5. **关于「我大／事大」的比喻要慎用**。原文用它说明「我大就是执取邪见」，但它容易被听成「人不够成功就没修行」。请只取其「检查是欲取还是见取」的用意，不要评判谁的成就高低。
6. **技术提醒**。材料②为音声转写，请提前确认播放／领读安排；材料中的时间码不念，只作切分；全篇强调「内部学习资料，请勿外传」。

**一句话总结本周精神**：三世两重因果讲的是「两条链子怎么接」，二十行相讲的是「这一圈有多少个零件」，而三连接里只有一处是活的、是你现在能碰的——「受」与「爱」之间。**守住这一处，就是本周全部的意义。**
