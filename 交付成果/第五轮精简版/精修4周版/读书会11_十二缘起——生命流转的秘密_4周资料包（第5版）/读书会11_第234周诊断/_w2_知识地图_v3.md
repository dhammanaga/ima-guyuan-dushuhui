## 🗺 本周知识地图

**本周走十二缘起的第二至第七支：行 · 识 · 名色 · 六入 · 触 · 受。**

一句话说清这六支的关系：**「行」是造作，「识」是果报，「名色」是身心成形，「六入」是六扇门，「触」是三者和合，「受」是三种领纳**——一路下来都在相续，却没有一个固定的「我」在搬来搬去。

```
行 · 识 · 名色 · 六入 · 触 · 受（第二至七支）
│
├─ 一、行支（第二支 · 造作）
│   ├─ 行＝「造作」，不是「行动」——是**思心所**驱使身、语、意去造业；
│   │   造作之后会留下「业的力量」，这个力量就是下一支「识」的缘。
│   ├─ 行分三种（合称 29 种思，亦称 29 种业行）：
│   │   · **福行**＝善的造作，共 13 种思——依布施、持戒等生起的 8 种欲界善思，
│   │     加上依修禅定生起的 5 种色界善思
│   │   · **非福行**＝不善的造作，共 12 种思——依杀生等不善业生起的 12 种不善思
│   │   · **不动行**＝禅定中的造作，共 4 种思——依修禅定生起的 4 种无色界善思
│   │   ⚠️ 三类共 29 种思：8＋5＋12＋4＝29。所以「以业解释行」——行造作后留下业的力量。
│   └─ 三论点证「无业则无果报」（《清净道论》设问「如何得知识以行为缘而生起？」后的三答）：
│       · 论点1【没有业则没有果报】：没有累积的业，就没有果报（业报）
│       · 论点2【有业才有果报】：此识本身就是果报，若无累积的业，果报不会生起
│       · 论点3【没有业而有果报，不成立】：若无业也能生起，则一切有情都会自动生起果报识，
│         事实绝非如此
│       ⚠️ 三答分别从「业」「果报」「作者」三个角度各推一遍，共同证明「无业则无果报」。
│
├─ 二、识支（第三支 · 果报）
│   ├─ 识＝「果报识」。这里说的不是泛泛的「心」，而是**果报心**——由过去业所感得的结果；
│   │   十二缘起支中，识·名色·六入·触·受同为「果报轮转」，故以「果报／业报」解释「识」。
│   ├─ 共 32 种世间果报识（＝89 种心中的 32 种果报心），分六识与二十二种意识：
│   │   · 眼、耳、鼻、舌、身五识各有善、不善果报两类，称**双五识**（共 10 种）
│   │   · 意识 22 种＝意界果报心 2（2 领受心）＋ 无因意识界 3（3 推度心）
│   │     ＋ 有因欲界果报心 8 ＋ 色界果报心 5 ＋ 无色界果报心 4
│   │   ⚠️ 10＋22＝32。**出世间心不属于轮回论，不计入**。
│   └─ 行缘识＝业 → 果的因果连接：业（行）是因，识（果报）是果；
│       即**过去的造作如何感得这一期生命的第一个果**。
│
├─ 三、名色支（第四支 · 身心成形）
│   ├─ 名色＝「身心」。**名**＝受、想、行、识四种非色法（精神部分）；
│   │   **色**＝四大种及所造色（业生色，是果报的色法）。
│   ├─ 「相续连结故，不一亦不异」：
│   │   · 「**不一**」＝上一期生命与这一期生命不是同一个生命
│   │   · 「**不异**」＝这一期生命的结生与上一期生命有关系——
│   │     你死后不会进入另一个生命相续流，一定是在**同一个生命相续流**里
│   ├─ 四喻（写清「A 喻 B」）：
│   │   · **回声**——敲钟后产生的钟声与回声不同，但并非无关，因敲钟而有回声
│   │   · **灯明**——后灯由前灯而燃，不是同一盏灯，也不是毫无关系
│   │   · **印章**——纸上的印纹不是你手中那枚印章，却因你盖印而有了印纹
│   │   · **镜像**——镜中的人不是你，却是你的影像
│   │   ⚠️ 四喻共同说明：「因声等而有回声、灯明、印章、镜像时，它们并未去到别处」，
│   │   结生心也同样如此——**不从他处来，也不无因生**。
│   │   原文又补：若完全同一，则不会因牛乳而产生凝乳；若完全相异，则凝乳就与牛乳无关。
│   └─ 十福业事（为未来增长善的资粮）：布施、持戒、禅修、服务、恭敬、说法、
│       随喜、回向、闻法、正见。以此十项增长**外功德**（利益他人）与
│       **内功德**（内心获得的丰盈与力量）——二者都是解脱的资粮。
│
├─ 四、六入支（第五支 · 六扇门）
│   └─ 六入（六处）＝眼、耳、鼻、舌、身、意**六扇门**。要点是：
│       **六入不是「我」，是六扇门**——门只是让境界进来的通道，
│       门本身没有「谁在看、谁在听」。
│
├─ 五、触支（第六支 · 三者和合）
│   ├─ 触＝**根 · 境 · 识**三者的和合。要点是：**不是「我」在触**，
│   │   而是根（六根）＋境（六境）＋识（六识）三者相遇，这个相遇就叫「触」。
│   │   原文：「只要有六入就有跟外境的接触，有触，就会有感受」——
│   │   即**门（六入）→ 遇（触）→ 纳（受）**。
│   └─ 五门心路（以眼门为例）＝**心的定则**。路心顺序固定为：
│       五门转向（1）· 眼识（1）· 领受（1）· 推度（1）· 确定（1）·
│       速行（7）· 彼所缘（2），合 14 个路心（＋3 个离路有分＝17 心识刹那）。
│       ⚠️ 这不是论师编排的，是**心的自然法则**——修名法时每一个心识刹那
│       就是这样生起的，是佛陀的伟大发现。
│       · 三个有分：色法寿命 17 心识刹那，扣掉最大路心 14 个，余 3 个离路有分，
│         依次名「过去有分」「有分波动」「有分断」。
│       · 确定心＝意门转向的确定作用，是决定善速行或不善速行的**重要转向（速行作意）**。
│
└─ 六、受支（第七支 · 三种领纳）
    ├─ 受＝三受，即触之后的「领纳」：**苦受 · 乐受 · 不苦不乐（舍）受**。
    │   因为**缘于六触**（眼触、耳触、鼻触、舌触、身触、意触），所以生起**六种受**——
    │   「由眼触缘后面的一切受」；此触不只缘眼识的受，还缘同一心路中一切心的受，
    │   即「**缘一切受**」。
    ├─ 触受非善恶，善恶在作意：触与受本身**没有善恶**，它们是果报、属**无记法**；
    │   善恶在于随后生起的**作意**——确定心若**不如理作意**，就生起不善速行；
    │   若如理作意，就生起善速行。**受是果，作意是因**。
    ├─ 无明从六门进来的路径：无明往往就在那一念「不如理作意」里进来——
    │   六扇门开着，境界进来，若不如理作意，无明与贪嗔就随之而起。
    ├─ 无明引发不善行的五种路径：
    │   ① 直接引发不善路心作意（主动朝向不该看的所缘，认为它带来快乐）
    │   ② 本意朝向善的所缘，结果确定心不如理作意（想打开佛法视频，结果不如愿而生嗔）
    │   ③ 不善果报引发不如理作意（走在街上被人撞倒，认为有个真实的我被撞到）
    │   ④ 善果报引发不如理作意（看到美丽的花而生贪，认为有真实美丽的花）
    │   ⑤ 纯粹的不如理作意（想入非非，编造贪嗔痴慢的快意人生）
    │   ⚠️ 结论：从深层次看，**「无明缘行」涉及的是整条心路**，不只是速行那一念。
    └─ 受不是终点——它正是下一支「爱」的缘起处：「**缘受而有爱**」。
       不管哪一种受（五识、领受、推度里的三十二种果报受），都会对随后升起的
       贪根心里那个「爱」，以**自然亲依止缘**为缘——苦者寻求乐、乐者更求乐，
       由寂静性故说舍为乐，所以**三种受皆对爱为缘**。
       这个爱会「爱屋及乌」（爱孩子就连带爱保姆），从单一的爱一次次地爱，
       一直变成「取」，变得很坚固。**受虽是果报、多分不由己，但它不是终点**——
       在这里停下来看清一次，就是为下周「受缘爱」埋下第一个观察的种子。
```

**本周要点**

1. 「行」是造作、「识」是果报、「名色」是身心最初的成形——这一切都在相续，却没有一个固定的「我」在搬来搬去。
2. 行＝福行（13 思）· 非福行（12 思）· 不动行（4 思），共 29 种思（＝29 种业行）；以「业」解释「行」，以「果报／业报」解释「识」。
3. 识＝32 种世间果报识（双五识 10 ＋ 意识 22：意界 2 ＋ 推度 3 ＋ 欲界有因 8 ＋ 色界 5 ＋ 无色界 4）；三论点证「无业则无果报」。
4. 「不一亦不异」：回声 · 灯明 · 印章 · 镜像四喻——「不从他处来，也不无因生」；相续连结故，结生仍在同一个生命相续流里。
5. 十福业事（布施·持戒·禅修·服务·恭敬·说法·随喜·回向·闻法·正见）增长内功德与外功德，都是解脱的资粮。
6. 面对果报不要直接采取行动（不是不作为，而是不带着贪嗔回应）——先认出「这是果报」，再以业果法则看待成因。
7. 六入不是「我」，是六扇门；触不是「我」在触，是根 · 境 · 识三者相遇；受是触之后苦 · 乐 · 舍三种领纳（缘于六触生六种受）。
8. 触与受本身没有善恶，善恶在于随后生起的作意——受是果，作意是因；无明往往就在那一念「不如理作意」里进来（无明引发不善行的五种路径）。
9. 心的定则：五门转向 · 眼识 · 领受 · 推度 · 确定 · 速行（7）· 彼所缘（2）；受不是终点，它正是下一支「爱」的缘起处。
