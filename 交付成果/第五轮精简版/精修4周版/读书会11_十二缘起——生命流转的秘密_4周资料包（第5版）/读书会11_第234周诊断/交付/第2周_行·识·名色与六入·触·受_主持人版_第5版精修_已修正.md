## 🗺 本周知识地图

**本周走十二缘起的第二至第七支：行 · 识 · 名色 · 六入 · 触 · 受。**

一句话说清这六支的关系：**「行」是造作，「识」是果报，「名色」是身心成形，「六入」是六扇门，「触」是三者和合，「受」是三种领纳**——一路下来都在相续，却没有一个固定的「我」在搬来搬去。

```
行 · 识 · 名色 · 六入 · 触 · 受（第二至七支）
│
├─ 一、行支（第二支 · 造作）
│   ├─ 行＝「造作」，不是「行动」——是**思心所**驱使身、语、意去造业；
│   │   造作之后会留下「业的力量」，这个力量就是下一支「识」的缘。
│   ├─ 行分三种（合称 29 种思，亦称 29 种业行）：
│   │   · **福行**＝善的造作，共 13 种思——依布施、持戒等生起的 8 种欲界善思，
│   │     加上依修禅定生起的 5 种色界善思
│   │   · **非福行**＝不善的造作，共 12 种思——依杀生等不善业生起的 12 种不善思
│   │   · **不动行**＝禅定中的造作，共 4 种思——依修禅定生起的 4 种无色界善思
│   │   ⚠️ 三类共 29 种思：8＋5＋12＋4＝29。所以「以业解释行」——行造作后留下业的力量。
│   └─ 三论点证「无业则无果报」（《清净道论》设问「如何得知识以行为缘而生起？」后的三答）：
│       · 论点1【没有业则没有果报】：没有累积的业，就没有果报（业报）
│       · 论点2【有业才有果报】：此识本身就是果报，若无累积的业，果报不会生起
│       · 论点3【没有业而有果报，不成立】：若无业也能生起，则一切有情都会自动生起果报识，
│         事实绝非如此
│       ⚠️ 三答分别从「业」「果报」「作者」三个角度各推一遍，共同证明「无业则无果报」。
│
├─ 二、识支（第三支 · 果报）
│   ├─ 识＝「果报识」。这里说的不是泛泛的「心」，而是**果报心**——由过去业所感得的结果；
│   │   十二缘起支中，识·名色·六入·触·受同为「果报轮转」，故以「果报／业报」解释「识」。
│   ├─ 共 32 种世间果报识（＝89 种心中的 32 种果报心），分六识与二十二种意识：
│   │   · 眼、耳、鼻、舌、身五识各有善、不善果报两类，称**双五识**（共 10 种）
│   │   · 意识 22 种＝意界果报心 2（2 领受心）＋ 无因意识界 3（3 推度心）
│   │     ＋ 有因欲界果报心 8 ＋ 色界果报心 5 ＋ 无色界果报心 4
│   │   ⚠️ 10＋22＝32。**出世间心不属于轮回论，不计入**。
│   └─ 行缘识＝业 → 果的因果连接：业（行）是因，识（果报）是果；
│       即**过去的造作如何感得这一期生命的第一个果**。
│
├─ 三、名色支（第四支 · 身心成形）
│   ├─ 名色＝「身心」。**名**＝受、想、行、识四种非色法（精神部分）；
│   │   **色**＝四大种及所造色（业生色，是果报的色法）。
│   ├─ 「相续连结故，不一亦不异」：
│   │   · 「**不一**」＝上一期生命与这一期生命不是同一个生命
│   │   · 「**不异**」＝这一期生命的结生与上一期生命有关系——
│   │     你死后不会进入另一个生命相续流，一定是在**同一个生命相续流**里
│   ├─ 四喻（写清「A 喻 B」）：
│   │   · **回声**——敲钟后产生的钟声与回声不同，但并非无关，因敲钟而有回声
│   │   · **灯明**——后灯由前灯而燃，不是同一盏灯，也不是毫无关系
│   │   · **印章**——纸上的印纹不是你手中那枚印章，却因你盖印而有了印纹
│   │   · **镜像**——镜中的人不是你，却是你的影像
│   │   ⚠️ 四喻共同说明：「因声等而有回声、灯明、印章、镜像时，它们并未去到别处」，
│   │   结生心也同样如此——**不从他处来，也不无因生**。
│   │   原文又补：若完全同一，则不会因牛乳而产生凝乳；若完全相异，则凝乳就与牛乳无关。
│   └─ 十福业事（为未来增长善的资粮）：布施、持戒、禅修、服务、恭敬、说法、
│       随喜、回向、闻法、正见。以此十项增长**外功德**（利益他人）与
│       **内功德**（内心获得的丰盈与力量）——二者都是解脱的资粮。
│
├─ 四、六入支（第五支 · 六扇门）
│   └─ 六入（六处）＝眼、耳、鼻、舌、身、意**六扇门**。要点是：
│       **六入不是「我」，是六扇门**——门只是让境界进来的通道，
│       门本身没有「谁在看、谁在听」。
│
├─ 五、触支（第六支 · 三者和合）
│   ├─ 触＝**根 · 境 · 识**三者的和合。要点是：**不是「我」在触**，
│   │   而是根（六根）＋境（六境）＋识（六识）三者相遇，这个相遇就叫「触」。
│   │   原文：「只要有六入就有跟外境的接触，有触，就会有感受」——
│   │   即**门（六入）→ 遇（触）→ 纳（受）**。
│   └─ 五门心路（以眼门为例）＝**心的定则**。路心顺序固定为：
│       五门转向（1）· 眼识（1）· 领受（1）· 推度（1）· 确定（1）·
│       速行（7）· 彼所缘（2），合 14 个路心（＋3 个离路有分＝17 心识刹那）。
│       ⚠️ 这不是论师编排的，是**心的自然法则**——修名法时每一个心识刹那
│       就是这样生起的，是佛陀的伟大发现。
│       · 三个有分：色法寿命 17 心识刹那，扣掉最大路心 14 个，余 3 个离路有分，
│         依次名「过去有分」「有分波动」「有分断」。
│       · 确定心＝意门转向的确定作用，是决定善速行或不善速行的**重要转向（速行作意）**。
│
└─ 六、受支（第七支 · 三种领纳）
    ├─ 受＝三受，即触之后的「领纳」：**苦受 · 乐受 · 不苦不乐（舍）受**。
    │   因为**缘于六触**（眼触、耳触、鼻触、舌触、身触、意触），所以生起**六种受**——
    │   「由眼触缘后面的一切受」；此触不只缘眼识的受，还缘同一心路中一切心的受，
    │   即「**缘一切受**」。
    ├─ 触受非善恶，善恶在作意：触与受本身**没有善恶**，它们是果报、属**无记法**；
    │   善恶在于随后生起的**作意**——确定心若**不如理作意**，就生起不善速行；
    │   若如理作意，就生起善速行。**受是果，作意是因**。
    ├─ 无明从六门进来的路径：无明往往就在那一念「不如理作意」里进来——
    │   六扇门开着，境界进来，若不如理作意，无明与贪嗔就随之而起。
    ├─ 无明引发不善行的五种路径：
    │   ① 直接引发不善路心作意（主动朝向不该看的所缘，认为它带来快乐）
    │   ② 本意朝向善的所缘，结果确定心不如理作意（想打开佛法视频，结果不如愿而生嗔）
    │   ③ 不善果报引发不如理作意（走在街上被人撞倒，认为有个真实的我被撞到）
    │   ④ 善果报引发不如理作意（看到美丽的花而生贪，认为有真实美丽的花）
    │   ⑤ 纯粹的不如理作意（想入非非，编造贪嗔痴慢的快意人生）
    │   ⚠️ 结论：从深层次看，**「无明缘行」涉及的是整条心路**，不只是速行那一念。
    └─ 受不是终点——它正是下一支「爱」的缘起处：「**缘受而有爱**」。
       不管哪一种受（五识、领受、推度里的三十二种果报受），都会对随后升起的
       贪根心里那个「爱」，以**自然亲依止缘**为缘——苦者寻求乐、乐者更求乐，
       由寂静性故说舍为乐，所以**三种受皆对爱为缘**。
       这个爱会「爱屋及乌」（爱孩子就连带爱保姆），从单一的爱一次次地爱，
       一直变成「取」，变得很坚固。**受虽是果报、多分不由己，但它不是终点**——
       在这里停下来看清一次，就是为下周「受缘爱」埋下第一个观察的种子。
```

**本周要点**

1. 「行」是造作、「识」是果报、「名色」是身心最初的成形——这一切都在相续，却没有一个固定的「我」在搬来搬去。
2. 行＝福行（13 思）· 非福行（12 思）· 不动行（4 思），共 29 种思（＝29 种业行）；以「业」解释「行」，以「果报／业报」解释「识」。
3. 识＝32 种世间果报识（双五识 10 ＋ 意识 22：意界 2 ＋ 推度 3 ＋ 欲界有因 8 ＋ 色界 5 ＋ 无色界 4）；三论点证「无业则无果报」。
4. 「不一亦不异」：回声 · 灯明 · 印章 · 镜像四喻——「不从他处来，也不无因生」；相续连结故，结生仍在同一个生命相续流里。
5. 十福业事（布施·持戒·禅修·服务·恭敬·说法·随喜·回向·闻法·正见）增长内功德与外功德，都是解脱的资粮。
6. 面对果报不要直接采取行动（不是不作为，而是不带着贪嗔回应）——先认出「这是果报」，再以业果法则看待成因。
7. 六入不是「我」，是六扇门；触不是「我」在触，是根 · 境 · 识三者相遇；受是触之后苦 · 乐 · 舍三种领纳（缘于六触生六种受）。
8. 触与受本身没有善恶，善恶在于随后生起的作意——受是果，作意是因；无明往往就在那一念「不如理作意」里进来（无明引发不善行的五种路径）。
9. 心的定则：五门转向 · 眼识 · 领受 · 推度 · 确定 · 速行（7）· 彼所缘（2）；受不是终点，它正是下一支「爱」的缘起处。

## 🧘 静心开场（10 min）

> 💬 **破冰｜3–5分钟**：深呼吸三次，感觉一下：你说「我」的时候，指的是身体、念头，还是说不清的一团？带着这个疑问，说说今天的你是怎样。

> 🛡️ **心理安全三约定**（每次开场在心里过一遍）：① **保密**——这里说的话不出这间屋子；② **不评判**——不评价任何人的分享，也不急着评价自己；③ **可随时暂停**——任何时候觉得不舒服，都可以停下来休息、喝水或离开，不需要解释。

**主持人引导语**（照读即可）：

请大家轻轻坐好，背脊自然挺直，双手安放在腿上，眼睛微闭，或轻轻下垂。先做三次深长的呼吸，把一天的忙碌，随着呼气慢慢放下。

现在，把注意力带回呼吸。吸气，知道自己在吸气；呼气，知道自己在呼气。不去控制它，不去调整它，只是陪着它。

今晚的静心，我们不做特别的技巧，只是先把身体安顿好，把心从「赶路」的状态里请回来。你会发现，光是「知道自己在呼吸」，心就已经开始安静了。

你会发现：每一次吸气，是「因」在动；每一次呼气，是「果」在现。呼吸在生灭，感受在生灭，念头也在生灭。它们不是「我」，却又不离「我」；它们不是同一个，却又相续不断——这就是今晚我们要慢慢体会的「不一亦不异」。

若有人今天心里有事、坐不下来，也没有关系——你只要坐在那里，知道「心很乱」，这已经是在观察了。我们不是在追求一种特别安静的状态，只是练习知道当下正在发生什么。

好，我们一起，安静地观察呼吸与身心的生灭……（静默约 3 分钟）……

现在，慢慢把注意力带回身体，感觉坐姿、感觉双手，准备好时，轻轻睁开眼睛，回到我们这个教室。

####   一、“行缘识”释义

（一）以何种行为缘生起何种识？

一、「行缘识」——以何种行为缘生起何种识？

（此处原为课件图形页：「不善21／善12／心36／果报心／界21／有因心15／无因心」等心法对应图，OCR 无法逐条还原，完整表见《原文全集》。）

《清净道论》中首先提出这个问题：以何种行为缘生起何种识？

刚学过的缘起支是“无明缘行”，无明引发欲界福行、非福行，色界福行，无色界不动行，这四种行分别可生起四类36种果报识，即欲界不善果报识7种，欲界善果报识16种，色界报识5种，无色界果报识4种。

####   （二）“识”的释义

“行缘识”中“识”的释义——《清净道论》

（原文此处为一张「识」的分类表，属课件图形页，OCR 无法逐条还原；可读条目据上下文整理如下，完整表见《原文全集》）

- 无因不善果报：七种（眼识、耳识、鼻识、舌识、身识、舍俱领受心、舍俱推度心）。
- 无因善果报：八种（眼识、耳识、鼻识、舌识、身识、舍俱领受心、舍俱推度心、悦俱推度心）。
- 色界果报心：五种（初禅至第五禅）。
- 无色界果报心：四种（空无边处、识无边处、无所有处、非想非非想处）。
- 欲界有因大果报心：八种（悦俱／舍俱、智相应／不相应、有行／无行）。

因此，所谓「行缘识」的识，特指果报识（十二缘起支中，识、名色、六入、触、受为果报轮转，因此‘识’为果报识）。果报识有眼、耳、鼻、舌、身、意六种。其中眼识、耳识、鼻识、舌识、身识

各有善和不善果报两类，也称双五识。意识有二十二种，即善、不善果报意界两种【意界果报心：2 领受心】，三种无因（果报）意识界【3推度心】，八种有因欲界果报心，五种色界果报心【5色界果报心】以及四种无色界果报心【4 无色界果报心】。六识包括这三十二种世间（有漏）果报识。出世间心不属于轮回论，所以不包括在内。

（三）如何得知“识”是以行为缘而生起的？

《清净道论》中又问到：如何得知“识”是以行为缘而生起

的？

答：因为没有累积的业，则无果报（业报）；因为此识是果报，若无累积的业，果报是不会生起的。如果无业也能生起的话，则一切有情都会生起果报识，绝不会这样生起，这是识如何以行为缘而生起。

业（行指福行、非福行、不动行，共有 29 种思）；果报（识指 32种果报识）。

论点 1：没有累积的业则没有果报（业报）——【没有业则没有果报】

论点 2：因为此识是果报，若无累积的业（业行），果报是不会

生起的——【有业才会有果报】

论点3：如果无业（业行）也能生起的话，则一切有情都会生起果报识，绝不会这样生起——【没有业有果报，不成立。】

####   二、行与识的对应关系

> 【原文此处为图示/流程图代码（graph TD 思维导图），照录从略】

行，有三种：

(1)「福行」有十三种思：依布施、持戒等所生起的八种欲界善思，以及依修习禅定所生起的五种色界善思。

(2)「非福行」依杀生等而生起的有十二种不善思。

(3)「不动行」依修习禅定所生起的四种无色界善思。

这三种行共有二十九种思（亦称为29种业行）。这里要留意：**「行」不是「行动」，而是「造作」——是思心所驱使身、语、意去造业**；造作之后会留下「业的力量」，这个力量就是下一支「识」的缘。

由于福行、非福行、不动行，这三种行共有二十九种思，故在此以“业”解释“行”（造作‘行’之后，会留下业的力量）。识指三十二种果报识，故在此以“果报、业报”解释“识”。所以**「行缘识」说的正是业与果的因果连接：业（行）是因，识（果报）是果**——即过去的造作如何感得这一期生命的第一个果。

####   （一）以欲界福行为缘生起识

####   1. 以欲界福行为缘有16识

《清净道论》中提到：“以欲界福行为缘生起识”。

十六种是由欲界福行为缘所生起的识：眼识善果报等五种【5善果报五识心】，意识中的意界一种【1善果报领受心】与无因意识界两种【2善果报推度心：舍俱和悦俱】，以及欲界果报八种【8大善果报心】。

即所谓：「由于造作、累积欲界善业，故善果报的眼识生起；耳、鼻、舌、身识亦然…乃至果报意界生起【1善果报领受心】…悦俱意识界生起【1悦俱善果报推度心】…舍俱意识界生起【1舍俱善果报推度心】…悦俱智相应（无行）【1悦俱智相应无行果报心】…悦俱与智相应有行【1悦俱智相应有行果报心】…悦俱智不相应（无行）【1悦俱智不相应无行果报心】…悦俱智不相应有行【1悦俱智不相应有行果报心】…舍俱智相应（无行）【1舍俱智相应无行果报心】…舍俱智相应有行【1舍俱智相应有行果报心】…舍俱智不相应（无行）【1悦俱智不相应无行果报心】…舍俱智不相应有行果报心】…

作为欲界众生的人类，每天眼睛看到的、耳朵听到的、鼻子闻到的、舌头尝到的、身体接触到的都是果报。大家坐在这里听闻佛法是果报。如果我们过去没有造作与佛法相应的善业，乃至于与阿毗达摩、二十四缘相应的善业，今生就不可能坐在这里学习阿毗达摩、二十四缘。如同最早听闻阿毗达摩的五百位比库，他们的过去生曾是住在一个山洞里的蝙蝠，听闻比库们诵阿毗达摩，它们只是觉得好听，但并不理解义理，因此，这一生有因缘成为果德玛(Gotama)佛陀时代最早听闻阿毗达摩的比库。所以，任何的果报都有因。日常生活中，你的所见、所闻、所尝、所触，一切都是你的果报。为什么一再说“不要对果报直接采取行动，要退后看一看，尤其不要采取不善的、不正确的行动？”因为好坏都是你的果报。问题的核心是，面对好的果报，我们希望更好或者继续好；面对不好的果报，希望立即离开，这就不是一个了知业果法则的人的基本态度。

**三、名色支：识与名色「不一亦不异」**

前面讲到「行缘识」——过去的无明、爱、取、行、业五因，成熟为这一生的果报识。识生起之后，接着生起的是「名色」。**名**，是受、想、行、识四种非色法；**色**，是四大种与所造色。名色合起来，就是我们常说的「身心」。

**识与名色是什么关系？** 原文说：「**相续连结故，不一亦不异**。」「不一」，是说上一期生命与这一期生命不是同一个生命；「不异」，是说这一期生命的结生与上一期生命有关系——你死后不会进入另一个生命相续流，一定是在同一个生命相续流里。原文给四个譬喻：**回声、灯明、印章、镜像**。敲钟后的钟声与回声不同，却因敲钟而有了回声；镜中人不是你，却是你的影像；纸上印章不是你手中那个印章，只因用它盖印而有了印章的模样——它们并未去到别处，这个结生心也同样如此。原文又说：若完全同一，则不会因牛乳而产生凝乳；若完全相异，则凝乳就与牛乳无关——所以对由因而生的识，不应认为完全同一或相异。

**十福业事。** 怎样为未来增长善的资粮？原文提到「十福业事」：布施、持戒、禅修、服务、恭敬、说法、随喜、回向、闻法、正见。以此十项善行增长**内功德**与**外功德**——外功德利益他人，内功德是内心获得的丰盈与力量，二者都成为解脱的资粮。

> ⚠️ 主持人操作：本段为本周第四支「名色」的正文。时间紧时可先念「相续连结故，不一亦不异」与四喻名称，十福业事请学员自行看资料。

## 🎯 第一轮主题讨论（10 min）
**讨论规则**（照读即可）：三个问题按顺序来，不跳序、不赶进度；一人发言时，其他人只听。主持人少说、多问，把话头交给大家。

讨论问题（按优先级）：

1. **「行缘识」到底在说什么？** 为什么「识」特指果报识？（抓住：三行共 29 种思＝业；36 种果报识＝果；无业则无果报。）
   - 追问路径：如果没有累积的业，果报识会不会生起？为什么说「没有业而有果报，不成立」？
   - 操作提示：若学员追问心所数量等细节，可回应「这些数字先记住结构，细节我们课后再查资料」，不必现场记诵。

2. **「不一亦不异」怎么理解？** 用回声、灯明、印章、镜像四个譬喻，说说「既不是同一个，也不是没有关系」是什么意思。
   - 追问路径：如果完全同一，会有什么过失？如果完全相异，又会有什么过失？「凝乳与牛乳」的比喻说明了什么？
   - 操作提示：这一问容易抽象，可先请学员用「今天的我」与「昨天的我」作对比，再说回「上一生与这一生」，会容易得多。

3. **面对果报的正确态度是什么？** 原文说「不要对果报直接采取行动」，这与「不作为」有什么不同？
   - 追问路径：什么是「了知业果法则的人的基本态度」？把「停三秒」放到你今天的某一个场景里，会发生什么？
   - 操作提示：可请学员现场选一个「今天的小场景」，三个人分别说出自己会怎么「不立刻反应」，主持人不评价，只记录关键词。

**参考要点（供主持人翻阅，不必逐字念）**：

- 第 1 问要点：原文说「行指福行、非福行、不动行，共有 29 种思」，又说「识指 32 种果报识」，所以「行缘识」是以「业」解释「行」、以「果报、业报」解释「识」。它用三个论点证明：一、没有累积的业则无果报；二、此识是果报，无业则不生；三、若无业也能生果报，则一切有情都会生起果报识——显然不会。故「识」特指果报识；十二缘起支中识、名色、六入、触、受都属于果报轮转。
- 第 2 问要点：回声、灯明、印章、镜像四喻都在说「不从他处来，也不无因生」。若完全同一，则牛乳不会生出凝乳；若完全相异，则凝乳与牛乳无关。故「相续连结故，不一亦不异」：上一期生命与这一期生命不是同一个生命，但这一期的结生与上一期有关系——你死后不会进入另一个生命相续流，而一定是在同一个生命相续流里。
- 第 3 问要点：原文说「不要对果报直接采取行动」，指的不是不作为，而是不带着贪嗔去回应。人的惯性是「好的希望更好、坏的希望立刻离开」，这恰恰不是了知业果法则者的基本态度。正确做法是：先认出「这是果报」，再以业果法则看待它的成因，然后才决定怎么行动。

4. **十福业事与我们**（材料③）：布施、持戒、禅修、服务、恭敬、说法、随喜、回向、闻法、正见——你最容易做到的是哪一项？最难的是哪一项？为什么？
   - 追问路径：原文说要「以十福业事增长内外功德」，什么是内功德、什么是外功德？「德不配位」这句话，你怎么理解？
   - 参考要点：内功德指内在的心理素质（智慧、戒律、福报的圆满），外功德指外在环境与人际因缘的改变。原文以「内圣外王」为喻：有内功德才有外功德；禅修上不去，往往是相应的内功德（如五根五力）还不足，被五盖所覆盖。

**备用深水问题（时间富余时）**：如果这一生的结生识与过去生的心识「不是同一个、也不是没关系」，那么「我修行、我受报」这句话，还可以怎么说？

> **分层追问**（可视时间取用，由浅入深）：
> - 【现象】从早上睁眼到现在，有哪一个「我」的感觉，是前后完全一样的？
> - 【影响】如果那个「我」其实一直在变，你对自己的担心会松动一点吗？
> - 【应对】这周试着在一句话里，把「我要怎样」换成「条件是怎样的」，先改口头的一句。

> ⚠️ 主持人操作：本周讨论宜「少而深」，若时间紧，只深挖第 1 问；第 2、3 问留作作业或下周开场暖身。遇法义分歧，记下不辩。

## 🧘 禅修练习（15 min）

> 💡 本周由连续两周合并，含两段禅修练习引导词；时间紧可读其一，或各取前半段（合计约15分钟）。

### 练习一
**主持人引导语**（照读即可）：

请找一个舒适的坐姿，眼睛微闭。先做三次深呼吸，把心放下来。

今晚的练习很简单：不是去改变什么，而是练习「知道」——知道有一个果报正在发生，知道心里升起的反应，也知道这些都会过去。

现在，回想今天让你不太舒服的一个小片段——也许是一句话、一个眼神、一件不顺的事。不要分析它，只是看着它。

然后，在心里轻轻说一句：这是果报。这是过去的因，在今天成熟。

不要急着改变它，也不要急着推开它。只是看着这个果报，像看一片落下来的叶子。

接着，注意心里升起了什么：想反驳？想逃避？想抓住？——这些都只是念头，不是「我」。

让这些念头来，让这些念头去。你只是知道：因在动，果在现，相续在继续，而没有一个固定的「我」在承受。

**练习要点提醒**：这个练习不是「想通」那件事，也不是「消除」不舒服；只是练习在果报面前，先不解救、先不判决，只是知道。做到「知道」，就已经做到了。

**若有人落泪或情绪起伏**：请轻声说一句「没关系，让它在，我们都在这里」。待其平稳后，再引导回到呼吸；必要时邀请其到旁边休息，不中断全场。

如果今天你什么感觉都没有，也很好——没有感觉，也是一种被知道的状态。修行不是追求特殊经验，而是越来越诚实地看着当下。

好，把注意力放回呼吸，安住在呼吸上……（静默约 5 分钟）……

现在，慢慢把注意力带回身体，感觉双手、感觉坐姿，准备好时，轻轻睁开眼睛。

回顾无明缘行

无明是行的主要基础。佛陀说：“诸比库，无知者，达至无明者，造作福行，造作非福行，造作不动行。”无论造作福行、非福行或不动行，其背后都是无明。根据《清净道论》：福行、非福行、不动行三种，及身行、语行、心行三种的此等六种为“由无明之缘而有行”的行；它们都只是世间的善及不善的思而已。也就是这里的行是善不善速行心里的思，速行是发生在六门心路中的，为此，在学习“无明缘行”整体课程之前我们先来学习各种心路生起所需的所有的缘，再看其中无明的作用。

缘组简介：分 6 组缘力（上图右边说明：1.俱生组 10 缘：心所与心的关系；2.所缘组 4 缘：所缘与心的关系；3.无间组 5 缘：前一心与后心的关系；4.依处组 6 缘：依处与心的关系；5.自然亲依止组1 缘；6.异刹那组 2 缘）我们先以图解的方式，将各种「心路过程」里的每个「路心」，单一拆解说明。以眼识为例极大所缘「眼门心路过程」（最完整的五门心路过程）的定义当「色所缘」生起（于过去有分生起），撞击「眼净色」的同时，也撞击「有分」，这时作为第一个「路心」的五门转向心并不能马上生起；属于「离路」的有分心仍在继续生灭，第一个被撞击的有分心称为「过去有分心」，第二个称为「有分波动」、第三个称为「有分断」。「有分断」灭去后，诸「路心」才陆续生起，并执行其各自的作用，包括：五门转向心（1 个，执行转向的作用）、眼识（1 个，执行看的作用）、领受心（1 个，执行领纳的作用）、推度心（1 个，执行推究

的作用）、确定心（1 个，意门转向的确定作用，是决定善速行或不善速行的重要转向，是速行作意）、速行心（7 个）、彼所缘（2 个）。其余根门如耳门，只需把「色所缘」改为「声所缘」、「眼识」改为「耳识」（执行「听」的作用）即可。※ 每个心生起，只执行一个心识刹那的作用后即灭去，不会持续两个心识刹那，且一旦灭去即作为下一个心生起的因缘（如无间缘、等无间缘、重复缘等）。所以五门转向、眼识、领受、推度、确定、速行心 7、彼所缘 2 这种排序，是心的自然法则——不是论师编排的，修名法时会发现每一个心识刹那就是如此生起，这是心的定则，是佛陀的伟大发现。为什么有分会波动？有分心有自己的所缘目标（即此生结生时所缘取的目标）。当新的色所缘撞击眼门，原本缘取自己目标的有分心受到影响，意门（有分）无法立即舍弃原有目标，于是开始波动——两次有分波动。为什么眼门看到一个色所缘，心脏里的有分心会先变化？过去古德用树鸟与苍蝇的譬喻来解释。

色所缘在有分波动住刹那明显生起，五门转向心转向所缘、开始注意目标，随后眼识依色所缘生起，接着意门接受色所缘——领受，再推度，再确定，然后依序生起速行心 7 次和彼所缘 2 次。速行心 7 次有速行作用；能充当速行心的共有 55 种心，分欲界速行心与安止速行心两类，讲五门心路只取欲界速行心 29 种即可。彼所缘的出现有条件，须符合彼所缘法则才能出现两次。29 欲界速行心含唯作速行心，讲善不善速行时不列入，实为 8 大善速行心＋12 不善速行心，共 20 欲界速行心。1.【所缘】每一个心生起都必须取一个所缘；同一根门里所有路心都取同一个所缘，即与「过去有分」同时生起且处「住时」的色法。色法（五所缘）的寿命从「过去有分」算起，最长维持 17 个心识刹那——若把每个心识刹那再分生、住、灭 3 小刹那，则色法可经历 17×3＝51 个小刹那。

色法（五所缘）的寿命从「过去有分」算起，最长维持 17 个心识刹那，且在「住」时才能呈现于五门心路中。2.【依处】除无色地众生外，欲地及色地每一个心生起都必须依靠「依处」：除「双五识」依靠「五净色」之一、「结生心」依靠「心所依处」外，其余 75 心皆依靠「与前一心同时生起的心所依处」。3.【三个有分】色法寿命 17 个心识刹那，扣除最大的「路心」14 个（＝1 转＋1 识＋1 领＋1 推＋1 确＋7 速＋2 彼）后，仍有 3 个心识刹那属「离路心」的有分心，故个别命名：第一个叫「**过去有分**」，第二个叫「**有分波动**」，第三个叫「**有分断**」（路心生起前最后一个有分）。名称虽不同，其实都是有分心，都只取「前一世」最后一个心路过程（临死速行）的所缘作为所缘。一个色所缘只能维持 17 个心识刹那：极大所缘时五门心路有 17 个心识刹那，第 17 个灭去时色所缘同时灭去；大所缘时速行心生起得少；

若为微细所缘，五门心路中无速行、彼所缘生起；极微细所缘则连推度、确定也无。五门心路最多生起 17 个心识刹那，只可少不能多。眼识生起所需的缘：所缘组 4 缘、依处组 6 缘、无间组 5 缘、俱生组 10 缘、自然亲依止组 1 缘、异刹那组 2 缘。

**四、六入＝六扇门**

六入（六处）即眼、耳、鼻、舌、身、意六扇门。门只是让境界进来的通道，**本身没有「谁在看、谁在听」**——六入不是「我」，是六扇门。

**五、触＝根 · 境 · 识三者的和合**

门开了、境界进来，就发生「触」——**根**、**境**、**识**三者相遇，而非「我」在触。原文说：「只要有六入就有跟外境的接触，有触，就会有感受。」即**门（六入）→ 遇（触）→ 纳（受）**。

**六、受＝三受**

触之后生起的是「受」，即领纳：**苦受、乐受、不苦不乐（舍）受**。因为**缘于六触**（眼触、耳触、鼻触、舌触、身触、意触），所以生起**六种受**——「由眼触缘后面的一切受」；此触不只缘眼识的受，还缘同一心路中一切心的受，即「**缘一切受**」。

**七、触受非善恶，善恶在作意**

触与受本身没有善恶，是果报、属无记法。善恶在于随后生起的**作意**：确定心若**不如理作意**，就生起不善速行；如理作意则生善速行。**受是果，作意是因**。而无明，往往就在那一念「不如理作意」里进来。

**八、无明如何引发不善行——五种路径**

**①** 直接引发不善路心作意（主动朝向不该看的所缘，认为它带来快乐）。**②** 本意朝向善所缘，确定心却不如理作意（想打开佛法视频却不如愿，生嗔）。**③** 不善果报引发不如理作意（被人撞倒，认为有真实的「我」被撞到）。**④** 善果报引发不如理作意（见美花生贪，认为有真实美丽的花）。**⑤** 纯粹的不如理作意（想入非非，编造贪嗔痴慢的快意人生）。所以**「无明缘行」涉及整条心路**，不只是速行那一念。

**九、受不是终点——它正是下一支「爱」的缘起处**

原文说：「**缘受而有爱**。」不管哪一种受（五识、领受、推度里的三十二种果报受），都对随后升起的贪根心里那个「爱」以**自然亲依止缘**为缘——苦者寻求乐、乐者更求乐，由寂静性故说舍为乐，所以**三种受皆对爱为缘**。这个爱会「爱屋及乌」，从单一的爱一次次地爱，一直变成「取」，变得很坚固。受虽是果报、多分不由己，但它不是终点；在这里看清一次，就是为下周「受缘爱」埋下第一颗种子。

> ⚠️ 主持人操作：以下四～九为本周第五至第七支「六入·触·受」的正文。时间紧时至少念「六入＝六扇门」「触＝根·境·识三者和合」「受＝三受」「缘受而有爱」四句，其余请学员自行看资料。

**2. 本课后半段 · 总结引导**（照读即可）

**5. 收尾的三种收束方式**

① **简收**（时间紧）：只做三件事——念一句总结「因在动，果在现，相续在继续，没有固定的我」；念后半段主题；念回向词四句；
② **平收**（常规）：按「总结引导＋后半段总结＋回向」走；
③ **深收**（时间富余）：在回向前后各留 30 秒静默，让大家把今天的一句话带进身体再起身。

**一句共勉**（可照读）：不关闭六门，只在「触」与「受」之间，留一点觉知。

**6. 离场提醒与下周预告**（约 3 min）

提醒大家带走自己的讲义；后半段请提前 5 分钟到场，方便我们准时开始静心。

**下周预告**：第3周，我们将顺着「受」往下走，进入第八至十支——爱、取、有。看看「三受」如何生出「三渴爱」，渴爱又如何硬化成「四取」，进而积成「业有」，推向未来的「生」。

**7. 回向词**（主持人领读，全体合掌齐诵，照读不省）：

> **愿我此功德，导向诸漏尽！**
> **愿我此功德，为证涅槃缘！**
> **我此功德分，回向诸有情！**
> **愿彼等一切，同得功德分！**

> ⚠️ 主持人操作：回向语速放慢，一句一句，让大家合掌跟随；结束时不急于散场，留 30 秒安静，让善业在心里落定；散场前可轻声提醒一句「路上慢一点」。

## 📌 本讲主持人特别提醒

以下几件事，请在开场前默读一遍，并在需要时随时回看。

1. **心理安全第一**：本周讲到「业果」「果报」，容易引发自责。凡出现「我业障重」「我活该」等语言，请温和提醒：「业果是用来观察的，不是用来定罪的。」
2. **不劝人接受「轮回」**：本讲内容属于教理学习，允许有人暂时存疑。主持人不必为「证成轮回」而辩论，只需把原文读清楚。
3. **名相不必讲透**：29 种思、36 种果报识、十九种结生识等数字，听懂结构即可；听不懂，允许它先过去。
4. **避免恐吓式语言**：谈恶趣、地狱时，只作客观陈述，不渲染、不吓唬，收尾一定回到「善业可造、当下可用」。
5. **注意个人隐私**：分享环节若有人谈到家庭、健康、感情，主持人只陪伴、不追问，必要时把话题带回「感受」而非「细节」。
6. **设备与材料**：提前打印材料①③相关页；本周有音视频设备需求时，先测一遍，避免现场等待。
7. **不要用「业果」评价他人**：讨论中若出现「他这样是业障」之类的话，请立即温和地拉回——业果是用来观照自己的，不是用来评判别人的。
8. **收尾务必回到温度**：本周谈因果、谈死生，内容容易偏冷。结束时一定用「今天你愿意来，本身就是善业的成熟」这类话，把大家带回暖处。
