### 1·1「本周知识地图」节（★必加，2026-10-12 尊者令）

> **尊者原话**：「每周开头要附上"本周的知识地图、知识框架和要点"。」

- **位置**：紧跟 `## 📋 本周信息卡` 之后、`## 🧘 静心开场` 之前。
- **内容**：
  1. **树形知识地图**（用代码块 ` ``` ` 画层级框架，一眼看清本周全部子目）；
  2. **本周要点** 3–8 条（每条一行，把地图展开成可带走的结论）。
- **来源**：仓库 `知识框架与要点/读书会NN_<系列名>_知识框架与要点.md`，取对应周次（4 周版取「三、4周版 · 4WN」；8 周版取「二、8周版 · WN」）。
  **不得凭空编造**，要改写可压缩，但框架结构与要点必须与源文件一致。
- **用途**：共读前的框架回顾（3 分钟），让成员先看到全局再看细节。
- 节末注明 `📌 来源：<文件路径> → 「<章节名>」`，便于回查。
- **自检**：`count_spoken.py` 会检测此节是否存在，缺失报 `✗缺「本周知识地图」节`。

## 二、朗读正文与字数上限（硬约束）

> ⚠️ **2026-10-12 尊者裁定：本节已按新口径重写，旧口径（4周版8000/8周版6000 总量）作废。**

### 2.1 唯一算法：时长 × 语速 = 朗读字数

**语速口径：中等偏慢朗读 = 180 字/分钟**（受众为中老年、中年女性；常规朗读 250–300 字/分钟不算）。

| 版本 | 共读环节时长 | **该环节朗读字数上限** | 判定方式 |
|:--|:--:|--:|:--|
| **4 周版** | 共读原文1 = **20 分钟** | **≤ 3600 字** | **逐段各自独立判定**，不合并 |
| **4 周版** | 共读原文2 = **20 分钟** | **≤ 3600 字** | **逐段各自独立判定**，不合并 |
| **8 周版** | 共读 = **25 分钟** | **≤ 4500 字** | 单段判定 |

推导：20 × 180 = 3600；25 × 180 = 4500。

**要点**：
- **只计算"要念出来"的字数**。不念的（速览表、信息卡、讨论题、特别提醒、延伸阅读、主持人操作行、课前准备清单）**一律不算**。
- 4 周版是**两段共读**，两段**各自 ≤3600**，**不是**两段相加再比。
- 8 周版只有一段，≤4500。

### 2.2 「朗读正文」判定范围（怎么数）

**＝ 仅 `## 📖 共读原文N` 整节内的可朗读文字。**

| 计入 | 不计入 |
|:--|:--|
| 材料正文段落（原文照录） | 整份文件总字符数（含速览表、信息卡、讨论题、特别提醒、延伸阅读） |
| `**一、xxx**` / `**【◈扩展…】**` 等段标题行本身 | `### 原文材料X：…` 材料标题行 |
| | `- **文件**：《…》` 行 |
| | `> ⚠️ 主持人操作：` 行、`> 主持人：` 行 |
| | `**主持人课前准备…**` 及其下 1./2./3. 编号清单（备料，不朗读） |
| | `---` 分隔行 |

### 2.3 ★核心 / ◈扩展 与扩展段上限

- **★核心＝要念的**，量须控制在 2.1 的上限内。
- **◈扩展＝时间富余才加读的**：**整节 ◈ 扩展合计 ≤ 5 分钟 × 180 = 900 字**。
  > 尊者原话（2026-10-12）：「扩展内容也不要多，不要超过5分钟字数」。
- 合起来：一段共读 = ★核心念满 20 分钟 ＋ ◈ 扩展最多再加 5 分钟 ＝ **不超过 25 分钟**。

### 2.4 双向字数令（尊者）

> 「字数限制要遵守，不足要补足（要符合知识框架和要点，不跑题不重复），超过要减少（不丢要点）。材料来源于知识库，也可以直接用原文全集里的内容。」

- **不足 = 缺口，必须补**：优先补「讲稿正文已引用、但没落到原文」的悬空段落。
- **补写来源优先级**：仓库内 `原文全集.md` > IMA 知识库。
- ⚠️ 补进来的正文仍受 ★/◈ 分级约束，**别把 ◈ 全提成 ★**。
- ⚠️ 补原文必须剔掉原文自带的层级标题行 `^#{1,6}\s`（会与讲稿编号形成「一、二、一」跳号并造成内容错位）。

### 2.5 超限处置（顺序不可颠倒）

1. **先删 / 压 ◈扩展段落**（整段或其中次要段）；
2. 再对 **★核心段落做句内压缩**（去口头填充、去重复例证）；
3. **不得删掉当周课题的任何知识要点**——★核心段的知识要点、术语、数字、经文引文一个不许丢。
4. 删掉的整段要在该材料「⚠️主持人操作」行注明去向（例："整段不收入本周正文，见延伸阅读"）。

### 2.6 计数工具（交付前必跑）

`_规范/脚本/count_spoken.py`
```bash
python3 _规范/脚本/count_spoken.py <文件.md>…# 逐段报字数并判合规
python3 _规范/脚本/count_spoken.py -v <文件.md>     # 另附逐段明细
python3 _规范/脚本/count_spoken.py <目录>/          # 批量扫，末尾汇总超标清单
```
- 输出形如 `共读原文1=3385/3600(扩868)`：全段字数／上限（＋◈扩展字数）。
- 同时自检**「本周知识地图」节是否存在**（见第一节），缺失报 `✗缺「本周知识地图」节`。
- 以 `len()` 统计（**禁用 `wc -c`**，那是字节数，中文虚高一倍多）。
- **交付前必跑**，压到 `✓ 合规` 才许 commit。

### 2.7 其他保留约束

- **只保留可朗读的正文**；材料信息一律只写 `- **文件**：《…》` 一行。
- 保留 `**★核心段落**` / `**◈扩展段落**` 小标题与「一、二、三」编号小标题，维持次第。
- 保留录音转写的时间码 `[00:01:35]`（朗读跳过，供定位），**不得删除**。
- 术语与数字**一字不动**，仅可删减冗余句，不可改写术语、不可改数字。
- 音频转写来源标注「依据录音转写整理，已校对明显同音错字」按需保留（可简化）。

## 三、表格改文字 / 用图

- **共读正文里的表格一律换成可朗读的文字**：改写成有序/无序条目（`1.`、`-`），信息点一条不丢；若表格是 PDF 课件 OCR 乱码（如 `54|15色界|初神一第四神善…`），**据上下文还原为正确条目**，无法还原的**整表删除**并在该处标 `（原表为课件图形页，见《原文全集》）`。
- 仅当**图示关系用文字说不清**时，才用图：在该处插入 `![说明](素材图_xxx.png)`，**图片文件名必须来自本系列已有的素材图/课件原图**（见第六节资源清单），不得引用不存在的文件。
- 插图后不必再重复图表文字；图片下方不需要再写长说明。

## 四、延伸阅读（EXT_READ）压缩

```
## 📖 延伸阅读（课后自由选读）
- 《〈文件名〉》——〈一句话推荐〉
- 《〈文件名〉》——〈一句话推荐〉
```
（media_id、知识库出处移到《原文全集》。）

## 五、通用文字要求

- 中文标点用全角；名词规范译名后用括号补常用名/旧译名（如「阿拉汉（阿罗汉）」「比库（比丘）」）。
- 不得出现任何临时链接、`fetch` 返回标注、内部脚本名。
- 学员版**不要**手写，由脚本从主持人版派生。
- 内容与第4版**逐字比对**：除本规范允许的删除/压缩外，不得改动原文用词。
