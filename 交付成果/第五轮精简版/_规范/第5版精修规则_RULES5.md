# 第5版·精修规范（RULES5）— 主持人版改写

目标：把第4轮「朗读优化版」的每周主持人版，精修为**可直接打印、可直接朗读**的第5版；
**篇幅受朗读容量约束**，但**每周课题的架构与内容次第必须完整**。

## 一、产出结构（主持人版，按序；不需要的整块删除）

```
<div align="right">📅 最近更新：YYYY-MM-DD HH:MM　|　第5版精修（朗读优化版）</div>

# 第X周：〈周标题〉（主持人版）
> ⭐ **本讲主持人速览**（…）      ← 保留并精简：一句话定位＋环节时长表（含时间不够/富余）＋守则
> 本周主题：〈一句话〉
---
## 📋 本周信息卡           ← 保留，精简到「时长／核心问题／共读原文（只列文件名）／本周作业」4 行
## 🧘 静心开场（NN min）    ← 保留
## 📖 共读原文1（NN min）   ← 保留
### 原文材料①：〈标题〉
- **文件**：《〈文件名〉》
〈朗读正文：见第二节〉
### 原文材料②：〈标题〉
- **文件**：《〈文件名〉》
…
## 💬 第一轮分享（NN min）  ← 保留
## 🎯 第一轮主题讨论（NN min）← 保留
## 🧘 禅修练习（NN min）    ← 保留
## 📖 共读原文2（NN min）   ← 同上（若本周只有一段共读则无）
## 💬 第二轮分享 / 🎯 第二轮主题讨论 ← 保留
## 🔚 收尾与回向（NN min）  ← 保留
## 📌 本讲主持人特别提醒     ← 保留（佛禅模块必含情绪应对指引）
<!--EXT_READ-->## 📖 延伸阅读（课后自由选读） …<!--/EXT_READ-->   ← 压缩为清单（见第四节）
```

**必须删除的整块/整行**
1. 顶部「🔴🔴🔴 【存疑·未改】…」审计说明行（保留其覆盖的文字本身）。
2. `## ⏱ 时间弹性指南（本讲通用）` 整块（其要点已并入速览表）。
3. `📚 扩展内容包（时间富余时使用）` 整块 —— 内容另存进《原文全集》，不留在周文档。
4. `🖼 课件原图（源 PDF 渲染·供投屏）` 独立区 —— 必要的图**就近插入**到对应原文处（见第三节）。
5. `🗂 更新记录` 表 —— 移出周文档，只保留在《更新日志_CHANGELOG》。
6. `【本周朗读段 · 开始/结束】` 两行标记**及其后「默读／选读／延伸」正文**（该正文只进《原文全集》）。
7. `> 📎 完整原文见《原文全集》…` 提示行。
8. 材料信息行中除「标题」外全部（文件类型／说明／知识库出处／media_id／打开方式／段落优先级）。
9. 主持人版里出现的「制作说明／素材分工／查重边界说明」等内部过程性文字。

## 二、朗读正文与字数上限（硬约束）

- **只保留可朗读的正文**；材料信息一律只写 `- **文件**：《…》` 一行。
- **朗读正文总字数上限**：8 周版每周 ≤ **6000 字**；4 周版每周（含两段共读）≤ **8000 字**。
  - 超出时：**先删 ◈扩展段落**（整段或其中次要段），再对 ★核心段落做**句内压缩**（去口头填充、去重复例证），**不得删掉当周课题的任何知识要点**。
- 保留原有 `**★核心段落**（必读）` / `**◈扩展段落**（可选）` 小标题与「一、二、三」编号小标题，维持次第。
- 保留录音转写的时间码 `[00:01:35]`（朗读跳过，供定位），**不得删除**。
- 术语与数字**一字不动**，仅可删减冗余句，不可改写术语、不可改数字。
- 音频转写来源的固定标注「依据录音转写整理，已校对明显同音错字」按需在材料标题中保留（可简化）。

## 三、表格改文字 / 用图

- **共读正文里的表格一律换成可朗读的文字**：改写成有序/无序条目（`1.`、`-`），信息点一条不丢；若表格是 PDF 课件 OCR 乱码（如 `54|15色界|初神一第四神善…`），**据上下文还原为正确条目**，无法还原的**整表删除**并在该处标 `（原表为课件图形页，见《原文全集》）`。
- 仅当**图示关系用文字说不清**时，才用图：在该处插入 `![说明](素材图_xxx.png)`，**图片文件名必须来自本系列已有的素材图/课件原图**（见第六节资源清单），不得引用不存在的文件。
- 插图后不必再重复图表文字；图片下方不需要再写长说明。

## 四、延伸阅读（EXT_READ）压缩

把原来「材料／出处／media_id／说明」四列表，压缩为**清单**（3–6 条）：

```
## 📖 延伸阅读（课后自由选读）
- 《〈文件名〉》——〈一句话推荐〉
- 《〈文件名〉》——〈一句话推荐〉
```
（media_id、知识库出处移到《原文全集》。）

## 五、通用文字要求

- 中文标点用全角；名词规范译名后用括号补常用名/旧译名（如「阿拉汉（阿罗汉）」「比库（比丘）」）。
- 不得出现任何临时链接、`fetch` 返回标注、内部脚本名。
- 学员版**不要**手写，由脚本从主持人版派生。
- 内容与第4版**逐字比对**：除本规范允许的删除/压缩外，不得改动原文用词。

## 六、资源

- 原始第4版 md：`/sandbox/workspace/_r4/交付成果/第4轮朗读优化版/朗读优化{4,8}周版/〈系列目录〉/`
- 图片资源：`/sandbox/workspace/assets/读书会NN/…`（与系列目录同名放款）

## 七、执行纪律（子代理）

大规模改写的执行规范见 **`第5版子代理作业流程_TASK5.md`** 末节「子代理执行纪律」。要点：每轮只派 1（≤2）个子代理、优先 light、任务书 ≤500 字、派发那轮不并行其它工具调用；并发 ≥4 个 heavy 或会话进入限流态会被整批拒绝，须换新任务再试；数百篇批量活优先用脚本机械处理，只把需判断的少数交子代理。
