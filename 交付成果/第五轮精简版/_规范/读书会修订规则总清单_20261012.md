## 一、绝对红线（违反即作废）

1. **共读原文一字不改** —— 逐字照录，不改写、不缩写、不"润色"、不拼接、不虚构。
2. **学员版禁止手工编辑** —— 必须由脚本从主持人版派生。
3. **术语与数字一字不动** —— 仅可删减冗余句，不可改写术语、不可改数字。
4. **定界标记不许动** —— `、` 及其位置。
5. **绝覆盖原版本** —— 修订必另立目录/另存文件名。
6. **禁临时链接** —— 一律用「知识库出处＋media_id＋打开方式」，`https?://` 扫零。
7. **media_id 原样整串复制** —— 严禁手工拆分/拼接/重排（曾因手拼一字符整篇报废）。
8. **时长必封顶 120 分钟** —— 各环节之和 ≤120，超时是读书会最常见的致命伤。
9. **时区一律北京时间**。

## 二、字数规则（2026-10-12 尊者裁定·唯一算法）

### 2.1 硬线：时长 × 中等偏慢 180 字/分钟，**逐段独立判定**

| 版本 | 共读环节 | 时长 | **朗读字数上限** | 判定 |
|:--|:--|--:|--:|:--|
| **4 周版** | 共读原文1 | 20 min | **≤ 3600 字** | **独立判**，不相加 |
| **4 周版** | 共读原文2 | 20 min | **≤ 3600 字** | **独立判**，不相加 |
| **8 周版** | 共读 | 25 min | **≤ 4500 字** | 单段判定 |

推导：20 × 180 = 3600；25 × 180 = 4500。

### 2.2 ◈扩展段另有限额：≤ 900 字（5 分钟）

> 尊者原话：「扩展内容也不要多，不要超过5分钟字数」。

- **★核心＝要念的**（控在 2.1 上限内）；**◈扩展＝时间富余才加读的**。
- **每个共读节的 ◈ 扩展合计 ≤ 900 字**（5 分钟 × 180）。
- 合起来：一段共读 = ★核心 20 分钟 ＋ ◈扩展 ≤5 分钟 ＝ **不超过 25 分钟**。

### 2.3 只算「要念出来」的量

**＝ 仅 `## 📖 共读原文N` 节内的可朗读文字。**

| 计入 | 不计入 |
|:--|:--|
| 材料正文段落（原文照录） | 整份文件总字符数（速览表/信息卡/讨论题/特别提醒/延伸阅读） |
| `**一、xxx**` 等段标题行本身 | `### 原文材料X：…` 材料标题行 |
| | `- **文件**：《…》` 行 |
| | `> ⚠️ 主持人操作：`、`> 主持人：` 行 |
| | `**主持人课前准备…**` 及其下 1./2./3. 编号清单 |
| | `---` 分隔行 |

### 2.4 双向字数令（尊者）

> 「字数限制要遵守，不足要补足（要符合知识框架和要点，不跑题不重复），超过要减少（不丢要点）。材料来源于知识库，也可以直接用原文全集里的内容。」

- **不足 = 缺口**：优先补「讲稿已引用、但没落到原文」的悬空段落；来源优先级 仓库内 `原文全集.md` > IMA 知识库。
- ⚠️ 补进来的正文仍受 ★/◈ 分级约束，**别把 ◈ 全提成 ★**。
- ⚠️ 补原文必须剔掉原文自带的层级标题行 `^#{1,6}\s`。

### 2.5 超限压缩优先序（不可颠倒）

**先删/压 ◈扩展段 → 再对 ★核心段做句内压缩**（去口头填充、去重复例证）。
★核心段的知识要点、术语、数字、经文引文**一个不许丢**。
删掉的整段要在该材料「⚠️主持人操作」行注明去向。

### 2.6 统计纪律

- 用 `len()`，**禁用 `wc -c`**（那是字节数）。
- 工具：`_规范/脚本/count_spoken.py`（已按新口径重写：逐段判「全段字数 + 扩展字数」，并自检知识地图节）。
  ```
  python3 _规范/脚本/count_spoken.py <文件.md>…      # 逐段报并判合规
  python3 _规范/脚本/count_spoken.py -v <文件.md>     # 逐段明细
  python3 _规范/脚本/count_spoken.py<目录>/          # 批量扫，末尾汇总
  ```
  输出形如 `共读原文1=3385/3600(扩868)  合规`。
- **交付前必跑**，压到 `✓ 合规` 才许 commit。

## 六、录音转写校对规则

### 6.2 存疑核对表

- 全部录音转写材料结合知识库源文档**逐段核对**（段级时间码）。
- 产出 `录音转写存疑核对表_读书会NN_YYYYMMDD.md`，每条含：周次｜材料｜资料包标注时间码｜源实际时间码｜差异说明｜等级（高·中·低）｜**指向 GitHub 对应行的可点击链接**。

### 6.3 存疑标记格式

三个红点 🔴🔴🔴；句级写作 `🔴🔴🔴【存疑·未改】……【存疑·未改·止】🔴🔴🔴`，整块首尾包夹，文档顶部加图例。

**校对**＝依源文档**逐处订正**原整理稿，**保留其原有形态与结构**，**不得整段替换/重写**。修订时二者必须区分。

## 十五、AI 8 类典型错误（自查用）

1. **幻觉与伪事实** —— 具体事实逐一回溯来源，核不准宁可不写
2. **编造原文/引用/出处** —— 最致命。所有原文必须来自可信来源逐字复制，禁止 AI"回忆"原文
3. **术语误用与教义曲解** —— 核心术语建术语表＋权威来源；AI 生成的解释一律标"待专业核对"
4. **时间分配想当然** —— 环节时长程序求和比对
5. **空泛同质、伪个性化** —— 每周至少含本周专属真实素材
6. **语气说教、鸡汤化、过度自信** —— 检出并弱化
7. **前后不一致、跨周跨系列重复** —— 术语统一表＋md5 对撞
8. **安全合规缺失** —— 后果最重（见第九节）
