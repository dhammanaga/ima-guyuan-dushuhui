# TASK5 · 第5版精修·子代理标准作业流程

你负责把一个「系列版本」（读书会NN 的 4周版 或 8周版）的**全部周主持人版**精修为第5版。
**唯一文字依据**：`/sandbox/workspace/work/RULES5.md`（先完整读它）。下面是固定操作。

## 路径约定（把 {V} 换成 4周 或 8周）
- 源目录 SRC = `/sandbox/workspace/_r4/交付成果/第4轮朗读优化版/朗读优化{V}版/<系列目录名（朗读优化版）>`
- 输出目录 DST = `/sandbox/workspace/交付成果/第5版精修版/精修{V}版/<系列目录名（第5版）>`（**已建好**）
- 图片资源 IMG = `/sandbox/workspace/assets/<读书会NN>/`

## 步骤
1. `ls SRC`，列出所有 `第X周_*_主持人版.md`。
2. 对每个源文件，先跑预清理得到底稿：
   ```
   python3 /sandbox/workspace/work/preclean.py "SRC/第X周_…_主持人版.md" "DST/_draft_第X周.md" "DST/_meta_第X周.ext.md"
   ```
3. **逐周**按 RULES5 把底稿精修成终稿，写到 `DST/第X周_…_主持人版.md`。
   - 朗读正文总字数：4周版 ≤8000 / 8周版 ≤6000（超了先删◈扩展段，再对★核心做句内压缩，**不得删知识要点**）。
   - 表格→可朗读条目；仅有必要图示时才插图，图名必须取自 IMG 且写相对路径（如 `![说明](素材图_xxx.png)` 或 `![说明](课件原图/xxx.jpg)`）。
   - 术语、数字一字不动；时间码保留；材料信息只留 `- **文件**：《…》` 一行。
   - 保留速览/信息卡/六环节/特别提醒/`<!--EXT_READ-->…<!--/EXT_READ-->`（延伸阅读压成「《文件名》——一句话」清单）。
   - 删除：审计行、时间弹性指南、扩展内容包、课件原图独立区、更新记录表、`【朗读段】`标记及其后"延伸"正文、内部过程文字。
4. 把 IMG 里**用到的**图片复制到 DST（含 `课件原图/` 子目录；复制整个 IMG 目录最省事）。
5. 自检：`grep -c "media_id\|【本周朗读段\|彻底'"`（应无残留）、核对每周字数。

## 报告（≤200字）
每周一行：`第X周 | 共读正文字数 | 删了什么 | 表格处理 | 插图数`；末行给 DST 路径与异常。
