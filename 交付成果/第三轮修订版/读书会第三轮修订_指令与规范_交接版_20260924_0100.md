## 八、坑与教训（务必避免）

1. 改文档头「📅 最近更新」时间戳，**禁止**「先匹配日期+时间、再匹配仅日期」两条 regex 顺序替换（会叠加成 `YYYY-MM-DD HH:MM HH:MM`）；用**单条锚定完整时间戳**的正则一次替换。
2. 定点替换用**引号宽容正则**（`"`→`[""“”]`、`'`→`['‘’]`）；`RE` 型规则**不再** `re.escape`；逐处先 dry-run 报计数，0 命中或计数异常先查因。
3. `media_id` **严禁手工拆拼**；音频转写文本只能经 `fetch` 获取。
4. 打包 zip 时若输出文件与 glob 扫描目录相同，会把正在写入的 zip 自身纳入 → 死循环卡死；收集待打包列表时显式排除 `.zip` 及输出文件，或先收集列表再创建 ZipFile。中文名 zip 用 python `zipfile`（默认 UTF-8 较稳）。
5. 大批量并发子代理易触发限流（报「ima无法执行这个任务」）；改为**串行、一次一个**。
6. `get_knowledge_list` 等接口连续调用会 403，需间隔 ≥5s＋指数退避。
7. 产物落 `/sandbox/workspace/`（勿放 `/tmp`）。

```
python3 genword.py NN        # → 4周版/Word版/*.docx
```
- `md2docx.py <in.md> <out.docx> host|stu`；配色 host 藏青 / stu 墨绿。

### 11. zip 打包 —— `mkzip.py`
```
python3 mkzip.py NN          # 4周版主包（不含 Word）＋ 独立 Word 包
```
- 命名 `…_YYYYMMDD_HHMM_vX.Y`（UTC）；**收集文件时排除输出 zip 自身**。

### 12. 推送 —— `push_gh4.py` / `push_d15.py` / `push_d16.py` / `push_d17.py`
```
python3 push_gh4.py NN [NN …]
```
- **Git Data API 四步**：`POST git/blobs`（base64 内容）→ `POST git/trees`（`base_tree`＝当前 head tree）→ `POST git/commits`（`parents=[head]`）→ `PATCH git/refs/heads/main`。
- **逐系列一次 commit**，可单系列 `revert`；403/422/5xx 退避重试（timeout 180）。
- 推 **4周版 ＋ 8周版**；8周源仅本地不推。单文件更新可用 `pushfile.py`（Contents API PUT）。

### 13. 终检 —— `qa4.py`
```
python3 qa4.py NN
```
- 校验：环节/时长（和＝120）、`（原第` 残留、学员版纯净度（`STU_BAN`/`HOST_BAN` 黑名单）。

### 14. 收尾与交付
按系列登记**决策日志**（D 编号＋commit 哈希）→ 追写 **CHANGELOG** → 同步**文档头时间戳** → `provide_file` 给出 zip/Word/文档下载链接。

### 通用技巧（省 token / 防错）
- 大批量处理（拉取、时长替换、学员版派生、终检、删注、打包、推送）**一律用脚本在磁盘完成**，不把文档全文读入上下文；仅「破冰/分层提问/去说教腔」等做定点小片段写作。
- 改头部时间戳用**单条锚定完整时间戳**的正则（避免 `YYYY-MM-DD HH:MM HH:MM` 重复）。
- 复核用 `grep -rn`，注意子串陷阱（如「四种无记」是「十四种无记」的子串，`grep` 会误报"残留"）。
- 沙箱时钟 UTC ＝ 北京时间 −8h。
