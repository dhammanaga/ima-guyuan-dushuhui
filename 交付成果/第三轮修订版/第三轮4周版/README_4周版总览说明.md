# 第三轮 · 4周版系列资料包

本目录存放「读书会」各系列的 **4周版** 资料包。每个系列独立建目录，与「第三轮8周版」下的 8周版资料包平行对应。

## 改制口径（依《读书会修订执行手册》v1.5 第十一节 · 《读书会修订系列需求全集》v1.0）

- **合并方式**：8周版按**连续两周合并** → 第1周＝原1+2、第2周＝原3+4、第3周＝原5+6、第4周＝原7+8。
- **流程体例**：**9 环节 · 双共读**——静心开场10 → 共读原文1 20 → 第一轮分享10 → 第一轮主题讨论10 → 禅修练习15 → 共读原文2 20 → 第二轮分享10 → 第二轮主题讨论10 → 收尾与回向15（合计 **120 min**）。
- **红线**：**共读原文逐字保留、未改一字**（已程序化核验：主持版/学员版各 4 周，逐字节与源一致）。
- **学员版**：由 8周版**学员版源**合并（保留既有学员版清理规则），并去除周次合并残留的「（原第X周）」子标题、合并重复的禅修练习子节；主持人版保留「（原第X周）」子标题便于主持定位。
- **周标题**：按每周实际主旨另拟简洁周标题（见各系列目录）。
- **不覆盖原版**：修订另立目录，第二版见 `交付成果/第二轮修订版/`，原始第一版见 `交付成果/第一轮初稿/`。
