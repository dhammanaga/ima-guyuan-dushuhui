## 📅 使用方法（每周流程）

1. **开会前**：主持人读当周主持人版（速览＋特别提醒＋时间弹性指南），**学员无需预习**；两版文档打印或电子分发——**学员拿学员版、主持人拿主持人版**。
2. **双版本关系**：两版的**共读原文逐字一致**（主持人版只多出速览／时间弹性指南／特别提醒等主持辅助块）；共读环节大家读到的文字完全相同。
3. **进行中**：按120分钟九环节推进（静心开场10′→共读原文30′→第一轮分享25′→主题讨论35′→禅修练习15′→收尾回向20′）；共读环节轮流朗读★核心段，◈扩展段视时间选读。**共读只读不解释。**
4. **收尾**：一句话收获→下周预告→作业→回向文；作业不检查、不评比。
5. **缺席**：不补分享，缺席者拿当周学员版自学即可。
6. **新人中途加入**：随时欢迎；每讲开头的速览不依赖前几周，主持人用一分钟讲清"只读原文、只谈自己"即可。
7. **核对出处**：想核对某段原文来自哪份材料时，翻《原文全集》按周查找——每块共读文本都标有材料标题、类型与完整 media_id。
8. **材料准备**：学员版人手一份（打印或电子），主持人版主持人自留一份；建议另备**当周要点/对照表的打印或投影**（三不善根×自欺分组表、善的四素质表、六类自欺总表、对治铁三角图等），备计时器与安静场地即可。

## 🗓 给组织者的开课建议

- **固定节奏**：建议同一时段、同一场地，8周连续；每周1次×2小时，按第1—8周的次序走（总说一周 → 六类自欺六周 → 总摄一周）。
- **人数**：6-12人为宜；8人以上时第一轮分享改为"每人一句话"。
- **主持人**：可由1—2位轮值；轮值者提前通读《00_主持人总指南》，开讲前读当周"主持人版"速览与特别提醒即可上场，**不需要阿毗达摩或禅修资历**。
- **首课约定**：第一讲开场花三五分钟说明三条规则——只读原文、只谈自己、作业不检查；并说清"**如实觉察 ≠ 自我否定；我们照的是自己的心，不是别人的心**"，让"不审判、不比较、不贴标签"的氛围从第一课就立起来。
- **课前准备**：当周要点/对照表打印或投影稿一份；计时器；安静场地即可。
- **课后小结**：每讲可由主持人记一句"本周最触动我的话"，四周下来就是一份属于这个班的"共学小记"。
