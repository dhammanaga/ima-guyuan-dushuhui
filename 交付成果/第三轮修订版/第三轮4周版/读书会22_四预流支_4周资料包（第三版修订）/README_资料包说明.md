## 📅 使用方法（每周流程）

1. **开会前**：主持人读当周主持人版（速览＋特别提醒＋时间弹性指南，再扫一眼总指南的"逐周要点一句话"），**学员无需预习**；两版文档打印或电子分发——**学员拿学员版、主持人拿主持人版**。
2. **双版本关系**：两版的**共读原文逐字一致**（主持人版只多出速览／时间弹性指南／特别提醒等主持辅助块）；共读环节大家读到的文字完全相同，主持人的辅助内容不打扰共读。
3. **进行中**：按120分钟九环节推进（静心开场10′→共读原文30′→第一轮分享25′→主题讨论35′→禅修练习15′→收尾回向20′）；共读环节轮流朗读★核心段，◈扩展段视时间选读。**共读只读不解释。**
4. **收尾**：一句话收获→下周预告→作业→回向文；作业不检查、不评比。
5. **缺席**：不补分享，缺席者拿当周学员版自学即可。
6. **新人中途加入**：随时欢迎；每讲开头的速览不依赖前几周，主持人用一分钟讲清"只读原文、只谈自己"即可。
7. **核对出处**：想核对某段原文来自哪份材料时，翻《原文全集》按周查找——每块共读文本都标有材料标题、类型与完整 media_id；延伸阅读的打开方式与此相同。
8. **材料准备**：学员版人手一份（打印或电子），主持人版主持人自留一份；建议另备**当周图表／对照表的打印或投影**（四预流支总表、择师十德对照表、闻法五利益与两组五法表、七种舍断对照表、《一切漏经》七舍断与四道四果关系图、八层因缘链条图等），备计时器与安静场地即可。

## 🗓 给组织者的开课建议

- **固定节奏**：建议同一时段、同一场地，8周连续；每周1次×2小时，按第1—8周的次序走，主线最清楚（总论一周 → 亲近善士两周 → 听闻正法一周 → 如理作意两周 → 法随法行一周 → 总结一周）。
- **人数**：6-12人为宜；8人以上时第一轮分享改为"每人一句话"，让每个人都说得上话。
- **主持人**：可由1—2位轮值；轮值者提前通读《00_主持人总指南》，开讲前读当周"主持人版"的速览与"逐周要点一句话"一段即可上场，**不需要修学或教学资历，也不需要任何"证量"**（本系列不比较、不判定任何人的进度）。
- **首课约定**：第一讲开场花三五分钟说明三条规则——只读原文、只谈自己、作业不检查；并说清"**四预流支是解脱与成佛的共同前行、非高下之分；依法不依人、不盲目崇拜、不评判他人师承**"，让"不考试、不评比、不评判他人师承"的氛围从第一课就立起来。
- **课前准备**：当周图表／对照表打印或投影稿一份；计时器；安静场地即可，无需投影以外的多媒体设备。
- **课后小结**：每讲可由主持人记一句"本周最触动我的话"，四周下来就是一份属于这个班的"共学小记"。
- **收官安排**：第8周为总结与收官周，建议把"收尾与回向"留足15分钟，做四周回顾与"下一程"分享，并落到"从当下可落实的一件小事做起"，让这一路走得完整、走得踏实。
