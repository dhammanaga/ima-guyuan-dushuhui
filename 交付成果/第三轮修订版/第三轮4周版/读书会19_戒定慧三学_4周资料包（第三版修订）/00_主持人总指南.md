## 一、本系列定位：戒定慧三学——修学的完整框架（20系列之19）

- 本系列是整套20个系列读书会中的**第19站**，主题为**戒定慧三学——修学的完整框架**：讲的不是「背下三个名词」，而是**佛陀教导里那副最核心的修行骨架**——戒、定、慧三学如何一环扣一环，**由戒生定、由定发慧**，又怎样统摄八圣道、展开为「七清净·十六观智」的完整地图，最后落到在家人怎么把这条道走在自己的日子里。核心素材为**如来禅修学体系介绍05/07/08/09/11/12/13/17/35/37 等讲**（音声＋课件）、**《清净之道》讲要·说戒品**、**《清净道论·说戒品》**、**《禅修入门与次第-帕奥》**、**《帕奥禅师佛学问答整理》**、**《修学入门》**、**《亲知实见》**等（PDF）。

## 二、你不是老师，是"共学同行者"

- 本读书会的每一讲都可以换新主持人；主持人自己也是共学者，**不需要懂戒定慧、不需要解释法义**——名相极多，讲不清是正常的。
- 你的全部职责：按流程推进、让大家轮流读原文、确保每个人都被听见、时间到了就推进、最后一起回向。
- 有人问"这个词（四遍净戒／止持作持／刹那定／五禅支／名色分别智／七清净／十六观智）什么意思"——标准答案：**"我们跟着原文读，读几周自然就熟了。"**（实在需要，用一句白话点一下，不展开。）
- 有人问"我是不是没有定力／我是不是太愚痴／我现在修到第几级了"——标准答案：**"我们不是来打分的；了解次第，是认识一条路怎么走，不是衡量自己到了哪一级。"**
- 三学系列特别提示：本系列讲「戒的层次、定的深浅、慧的次第、七清净十六观智」等**阶次与境界**，**最容易滑向两个方向**——要么被「我戒守不住、我没有定、我悟性低」压住，生出自我看轻，要么把它听成一场「谁修得深」的暗自比较。主持人的第一功课不是讲解，而是**守定调**——一句护心话贯穿四周：**了解次第是认识一条道路，不是衡量自己到哪一级；进度快慢不制造自卑，也不制造优越。**

## 四、主持人10条守则

① 先到、先静、先安顿自己——主持人的松弛是这个场最稳的缘；② 不讲解、不提供答案——让原文自己说话（名相只点一句白话，不展开）；③ 一次只请一位发言，不打断、不点名施压；④ 涉及"持戒严松、禅定境界、修行阶次"等话题保持柔和，回到"这颗心当时是什么状态""当下这一步是什么"；⑤ 有人情绪起伏，先安顿人、其次才是内容（共情→停顿约30秒→再导回"此刻能安住的是什么"）；⑥ 不确定处说"我们把它记下来，下次请教"，不硬编；⑦ 照录原文照读，不擅自增删改；⑧ 时间到了就推进，用"我们还有大约五分钟"而不是"快点"；⑨ 禅修练习照读引导词即可，不承诺"修了就会得定、开慧"，不比较谁修得好、谁境界高；⑩ 结束一起回向，把功德分享给一切有情。

### 四周逐周要点与主持准备（开讲前各读一段即可上场）

- **W1 三学总说——戒定慧的次第与修学总纲**：本讲给整个系列"立总纲"——修行不是零散技巧，而是一条**有次第的完整道路**：由戒生定、由定发慧；三学又统摄八圣道（正语正业正命＝戒／正精进正念正定＝定／正见正思维＝慧），展开为「七清净·十六观智」的完整地图。四份材料汇成一句：**戒是地基、定是梁柱、慧是屋顶，同一栋房子，不是三栋。** 主持提醒：**开头就营造轻松氛围**——"我们不是来考试的，是一起来认一条路的"；用"地基—梁柱—屋顶"落地，别急着讲名相；「烦恼有三层，对治有三学：违犯性用戒、困扰性用定、随眠性用慧」是最好的收束句。心理安全（重点）：本周涉"戒定慧次第／修行阶次高低"——**了解次第是认识一条道路该怎么走，不是衡量自己到了哪一级；进度的快慢不制造自卑，也不制造优越**；术语先白后文；照录缺口如实说明、不补写。
- **W2 戒学（一）——戒的四个层次与四遍净戒**：本周走进第一学——把"戒＝束缚"的成见换成"戒＝守护"。核心：**止持**（不该做的不做）＋**作持**（该做的去做到）两条腿走路，展开为**四遍净戒**（巴帝摩卡律仪戒／根律仪戒／活命遍净戒／资具依止戒）四个层次；戒的相味现起足处以**惭愧**为根（不是恐惧）；戒的功德链「善戒→无悔→愉悦→喜→轻安→乐→定→如实知见→……→解脱知见」就是"由戒生定、由定生慧"的完整推导。主持提醒：材料②〈说戒品〉时间紧时**只读「止持与作持」「四遍净戒」两小节**；说清"四遍净戒是出家众的四种戒名，在家人可取其**精神**（守好行为、守好六门、正命、省察）"，避免在家人觉得"那是出家的事"。心理安全（重点）：本周涉**持戒严松**——**不比较、不评判、不道德绑架**；戒是自由非束缚，关注**心质非条目数量**；惭愧不是自责而是"不忍伤害"的柔软；材料①③涉"受戒再犯是否罪加一等"以尊者"铁球"比喻破除恐惧。
- **W3 戒学（二）——戒在实修中的作用**：本周往前走一步，问一个更贴身的问题——**戒，在真正的实修里到底起什么作用？** 四段原文讲同一件事的不同侧面：**如理作意**（修行最重要的内因，外因是善知识）、**守护根门**（不取相、不取随相；是培养定力的第一步）、**戒为定基**（修学次第与常见误区）、**三类烦恼**（违犯性用戒、困扰性用定、随眠性用慧）。主持提醒：**"戒先管最外面那一层（身语）"是起点而非终点**；本周只讲"戒在实修中的作用"，不再重复第2周"戒是什么、有哪些"；「彼分断／镇伏断／正断」只在读书会04第8周已详讲处点到为止。心理安全（重点）：本周涉**持戒严松**与"做不安之事后难以静心"——把"持戒"与"自我攻击"分开，**不比较、不评判**；"守不住根门怎么办"回到材料②两步——"可回避的回避，不可回避的护心，先做能做的，不苛求"；"总自责、追悔怎么办"回到材料③——"佛陀教我们犯后清净的方法，改善过来就好"。

## 七、心理安全要点索引（本系列重点；详见《_制作规范_读书19.md》第6节与各周"特别提醒"）

| 周 | 话题 | 要点与主持人动作 |
|:--:|:-----|:-----|
| W1 | 三学次第、"修行阶次高低" | 了解次第易被听成"量自己到第几级"：**了解次第是认识一条道路该怎么走，不是衡量自己到了哪一级；进度的快慢不制造自卑，也不制造优越**；术语先白后文；照录缺口如实说明、不补写。 |
| W2 | **持戒严松、戒的层次** | **重点周**：**不比较、不评判、不道德绑架**；戒是自由非束缚，关注**心质非条目数量**；惭愧不是自卑而是"不忍伤害"；把"四遍净戒"讲成在家人也可学的**精神**，不只是出家众的事。 |
| W3 | **持戒严松、"做不安之事后难以静心"** | **重点周**：把"持戒"与"自我攻击"分开；守不住根门→"可回避的回避，不可回避的护心，先做能做的、不苛求"；自责追悔→"佛陀教我们犯后清净的方法，改善过来就好"；不比较、不评判。 |
| W4 | **定、"我没有境界"、四十业处** | **重点周**：**不比较境界、不追求神通**；一旦有人给自己"打分"或羡慕他人境界，立刻带回「认识道路、不比较境界」；**无禅定经验的主持人亦可主持（反而更平等）**；定是工具不是目的。 |
| W5 | **禅那、八定、五禅支** | **重点周**：同上——**不比较境界、不追求神通**；宁可少读一段，也要接住心理安全；涉入出息念注明"读书会06已讲、本讲取不同段落"。 |
| W6 | **慧、"我太愚痴"、"他悟得深"** | **重点周**：**不比较、不评判**；"知道"与"看清"是两回事，把落点放回"看见"本身即是修；名色分别智及观智细节归 W7，本周只作名词介绍。 |
| W7 | **七清净十六观智、修行阶次高低** | **重点周**：**了解次第是认识一条道路该怎么走，不是衡量自己到了哪一级；快慢不制造自卑或优越**；十六观智名目多，**避免让人觉得被考问或被"录像评分"**；不展开四谛八正道／缘起业力／心所心路细节。 |
| W8 | **修学生涯规划、进度快慢** | **重点周**：**规划不是把自己逼紧，而是让自己在长路上不迷路、不退转；发心与当下的一步法随法行，本身就在道上**；不替任何人规划细节、不比较谁功课多；**避免把规划变成压力**；给"收尾与回向"留足15分钟。 |
| 通用 | —— | 分享以自愿为限；主持人不诊断、不给心理学标签；成员情绪波动时提供呼吸放松／允许静坐或暂离选项；涉较重伤痛时只陪伴、不劝解、不追问。 |

## 十二、常见问题（FAQ）

- **Q：我没有戒定慧的基础，能主持吗？** A：能。本系列主持人只守流程、不讲解法义；名相交给原文与书友的分享。遇到术语，一句白话点一下，不展开。**尤其提醒：无禅定经验的主持人亦可主持 W4／W5（反而更平等）。**
- **Q：四遍净戒、四十业处、五禅支、七清净、十六观智这么多，记不住怎么办？** A：不需要记。知道"戒有四个层次""定就是心一境性""修慧从名色分别智入门""七清净是一条从戒到解脱的路"就够；每周带走一句话即可。
- **Q：W1／W6／W7 会不会让人因"修行阶次"而自卑或优越？** A：本系列反复申明——**了解次第是认识一条道路该怎么走，不是衡量自己到了哪一级；进度的快慢不制造自卑，也不制造优越**；十六观智名目多，务必避免让人觉得被考问或被"录像评分"。
- **Q：W2／W3 讲"持戒"，会不会变成道德优越感或道德绑架？** A：不会。**持戒不是道德优越感**（"戒是约束自己的，不是批判别人的"）；戒关注**心质非条目数量**，**不比较、不评判、不道德绑架**；惭愧不是自卑而是"不忍伤害"；四遍净戒在家人可取其**精神**，不只是出家众的事。
- **Q：W4／W5 讲"禅定境界"，会不会让人攀比、追求神通？** A：不会。本周定调是"**不比较境界、不追求神通**"；一旦发现有人给自己"打分"或羡慕他人境界，立刻带回「认识道路、不比较境界」；定是工具不是目的——"诸比库，应修习定，有定力的比库能如实地了知"。
- **Q：W6 讲慧、W7 讲十六观智，会不会让"愚痴"的人更自卑？** A：不会。本周定调是"**不比较、不评判**"；"知道"和"看清"是两回事，把落点放回"看见本身即是修"；名色分别智及观智细节归 W7，本周只作名词介绍。
- **Q：W8 讲"修学生涯规划"，会不会把人逼紧？** A：不会。本周定调是"**规划不是把自己逼紧，而是让自己在长路上不迷路、不退转；发心与当下的一步法随法行，本身就在道上**"；主持人不替任何人规划细节、不比较谁功课多；**避免把规划变成压力**。
- **Q：W3 会重讲读书会04的戒律生活吗？W7 会重讲四谛八正道、缘起业力吗？** A：都不会。W3 只讲**戒在三学框架中的作用**（与04 取不同段落）；W7 只讲**七清净十六观智总纲**，四谛八正道详见09/10、缘起与业力详见11/12/13、心所心路详见14/15。
- **Q：作业必须完成并汇报吗？** A：不必。作业是给自己看的自查方向，不检查、不收、不评比；下一次开场也不做作业讲评。
- **Q：可以只参加其中几周吗？** A：可以。每周材料自成段落；不过四周连上才能看到"立总纲→讲戒的层次→讲戒的实修作用→讲定的种类→近行定到安止定→慧的种类与次第→七清净与十六观智→落到现实"的完整线索。
- **Q：W1 就出现"四遍净戒""四十业处""五禅支""七清净""十六观智"这些词，要先讲清楚吗？** A：不必。第一周只求"见个面、不怕它"；这些概念在四周里反复出现，会自己长出来。
- **Q：为什么 W2 与 W8、W5 与 W8 会出现同一份文件？** A：**同文件不同段落**，各周只取与本讲主题对应的章节（《帕奥问答.pdf》W2 取〈戒学问答〉、W8 取〈修行规划/自检/长远目标〉；《禅修入门与次第-帕奥.pdf》W5 取〈定学诸篇〉、W8 取〈编者序/依戒进修定慧/法随法行〉），共读时读到的内容并不重复，文档内均已注明。
- **Q：W8 的《介绍17》id 为什么和任务原给的不一样？** A：任务／蓝图原给 id 经完整 id 核验**无对应文件**；W8 已改用知识库中该讲音声的真实 id（见第八节出处一览），并在 W8 文档注明、报告主线程。
- **Q：学员问巴利文怎么读？** A：不必当众纠正读音，事后轻声提示即可；本系列不考发音、不考记名相（"戒定慧""四遍净戒""禅支""观智"等只需混个耳熟），音声转写的同音字（"进行定／净行定""观制""未道帝病"等）**不纠不考**。
