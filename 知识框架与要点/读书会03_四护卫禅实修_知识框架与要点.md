## 一、总知识框架：四护卫禅实修

### 1. 一句话主线

> 佛陀给走上修行之路的人准备了四件「护身之物」——**慈心禅、佛随念、不净随念、死随念**，合称「四护卫禅」，又称「一切业处」（所有佛弟子都应修习）。
> 四者**各对治一种烦恼**：慈心治瞋恨、佛随念治「疑与怯弱」（内心无力·恐惧·怀疑）、不净治贪欲、死随念治放逸。修法只为「对上自己的病」——心无力则忆念佛陀，容易生气则散播慈爱，贪着身体则拆看三十二身分，懈怠放逸则念死策励。
> 落到日用上：**晨修佛念、昼修慈心、暮修不净、夜修死念**——一日四重防护，而一切法门最后都收摄回入出息念。

### 3. 总核心要点

1. **四护卫禅＝慈心禅·佛随念·不净随念·死随念，又称「一切业处」**——所有佛弟子都应修习，是保护佛弟子、保护禅修者的「护身之物」；四者各对治一种烦恼：**佛随念治疑与怯弱、慈心治嗔恨、不净治贪欲、死随念治放逸**。
2. **一切处业处 ≠ 根本业处**：根本业处是培养定力的主业处（如入出息念）；一切处业处＝护卫禅（前行/护卫）。在家人时间有限，不宜学很多业处（别做「狗熊掰棒子」），**以练觉察为主、不强求禅定**。
3. **慈心禅是四护卫之首**：属四梵住之一、取无量有情为所缘、直接对治嗔心。四步次第＝**自己 → 喜爱的尊敬的同性 → 中性的人 → 敌人**；四句祝愿＝愿其无敌意／无内心的痛苦／无身体的痛苦／保有自己的快乐。
4. **只对喜爱的人修慈心，会变成贪爱**——慈心是平等的、要突破界限；只对喜爱的人修，修着修着就变成贪爱。对敌人生不起慈心，可改修悲心（愿其早日解脱一切苦）。**慈心圆满＝对 528 个方向与种类的有情都遍满、都证慈心三禅。**
5. **佛随念＝忆念佛陀十种功德名号**（阿拉汉·正自觉者·明行具足·善逝·世间解·无上士调御丈夫·天人导师·佛陀·世尊），三种忆念方式：**赞叹功德／希望自己拥有／分享佛陀功德（融入功德海）**。
6. **阿拉汉五功德**：远离烦恼·破烦恼贼·断轮回之辐·应受人天供养·无隐恶。**正等正觉**＝应知的已知、应断的已断、应修的已修（觉悟四圣谛）；**明行具足**＝明（三明）＋行（十五种行）＝悲智双全；**善逝**＝善行·善妙处行·正语；**世间解**＝行世间·有情世间·空间世间。
7. **卫塞节＝维萨卡月圆日，菩萨诞生·成佛·入般涅槃三事同日**。佛陀一生：入胎（兜率天以正念正知入母胎）→降生（平稳七步·狮子吼）→出家（四门游观·29 岁大出离）→苦行（极端苦行无意义）→证悟（35 年后维萨卡月圆日）→初转法轮与 45 年弘法→双娑罗树间入般涅槃。**「法随法行」才是对佛陀最高的礼敬。**
8. **不净观＝观察三十二身分**（出自《身至念经》），分六组：发毛爪齿皮／肉筋骨骨髓肾／心肝膜脾肺／肠肠间膜胃中物粪脑／胆汁痰脓血汗脂肪／泪油膏唾涕关节滑液尿。修法＝依次作意与十种善巧；以「五事」（颜色·形状·方位·处所·界限）分辨每一身分；**八类利益**（征服不乐与乐·征服怖畏·能忍冷热饥渴蚊虫恶言·能成四禅四遍·能成就神通）。观察方式＝**把「人」还原成三十二身分、「透视」皮肤观内部不净**——解决贪爱的执取。对在家人是日用工具，**始终以慈心平衡，不净观不是自厌**。
9. **死随念＝正面思维死亡**：死亡是自然法则（只要有生就有死）、凡夫临终三种不善心（贪恋·嗔恨·恐惧）；正确作意＝**我必然会死·命根会断·身体会坏**。**九种利益**含：得「一切诸有不可乐想」、克服对生命的执取、谴责罪恶、不多储藏、熟练无常想、临终无畏无昏迷、来世得善趣。传统修法（◈）=取**同性**尸体观不净，再替换为自身。
10. **一日四重防护：晨修佛念 → 昼修慈心 → 暮修不净 → 夜修死念**。上座前以智慧观察自己：昏沉修所缘多的前行、有气多修慈心、身不适对身体修慈心或四大差别；若一坐下就能安住根本业处，则**前行不必每次都做**。一切法门最后收摄回入出息念。

**知识框架**
- 佛陀对修行者教导四种护卫禅＝慈心禅·佛随念·不净随念·死随念，又名「一切业处」
- 在家人不适合学很多业处（狗熊掰棒子）；在家人的修法建议：以练觉察为主、不强求禅定
- 四法各自的保护：慈心→没有危难（五百比库与树神典故）／佛随念→威德力、免非人干扰／不净观→去除对自他身体的贪爱／死随念→防懈怠、破死惧
- 一切处业处 vs 根本业处
- 四种护卫禅各对治一种烦恼（佛随念→疑与怯弱／慈心→嗔／不净→贪／死随念→放逸）
- 如实、自然、轻松：不抓取、不评判的觉知

**要点**
1. 四护卫禅＝**慈心禅·佛随念·不净随念·死随念**，佛陀称为「一切业处」——**所有佛弟子都应修习**，它保护佛弟子、也保护禅修者。
2. 在家人**不适合学很多业处**（「狗熊掰棒子」：抓一个扔一个）——学多了没有时间；时间不足以修定者，**以练觉察为主**，觉察身心、以对治烦恼为主。
3. 第一护卫·慈心禅：保护＝**没有危难**（五百位比库依《应作慈爱经》对树神散播慈爱，树神反来护持，安居后五百比库皆证阿拉汉）。
4. 第二护卫·佛随念：佛陀无量劫累积功德、威德力大，常修使内心有力量，**免受非人及有毒众生的伤害**。
5. 第三护卫·不净观：观察身体三十二个部分，**去除对自己、对他人身体的贪爱**。
6. 第四护卫·死随念：思维「死亡总是要到来的，谁都逃不过」，**防止懈怠、破除对死亡的恐惧**；死亡前最主要的准备不是赚钱，而是「我有没有善业？我能不能维持善心到临终？」
7. **一切处业处＝护卫禅（前行/护卫）**；**根本业处＝培养定力的主业处**（入出息念等）——大部分时间用根本业处。
8. 身心最好的状态是「平衡」：自自然然——没有抓取、没有控制、没有要求、没有批判（如实、自然、轻松）。

2. **四步次第（必须练习）**：①自己 ②喜爱的、尊敬的人（**必须同性**，初学者对异性易生贪爱）③中性的人（没有喜欢、没有不喜欢；一般五人或十人）④不喜欢的、讨厌的、乃至敌人。
3. **四句祝愿**：愿其 ①无敌意（无危难）②无内心的痛苦 ③无身体的痛苦 ④保有自己的快乐——可择一法持续，也可四种轮用。

### W4　佛随念（二）生平／卫塞节与生活应用

**共读材料**：《2025五月包容寺短期出家修习营12-卫塞节-古源尊者-20250512》（卫塞节与佛陀的一生、法随法行与报答三宝）〔★〕

- 卫塞节：诞生·成道·般涅槃同在维萨卡月圆日
- 入胎·降生·出家·苦行·证悟·初转法轮·弘法 45 年·入般涅槃
- 法随法行才是对佛陀最高的礼敬
- 恐惧慌乱时，用佛随念

**要点**
1. **卫塞节＝维萨卡月的月圆日**：依上座部传统，这一天是菩萨诞生、佛陀成佛、入般涅槃的**同一日**（1950 年世界佛教徒联谊会定为卫塞节，1999 年联合国教科文列为全球性节日）。
2. **入胎**：菩萨从兜率天**以正念正知**入母胎（《稀有未曾有经》）；胎儿四类正知——入·住·出三阶全无（大部分人）／仅入胎有（八十大弟子）／入·住胎有（两上首弟子与独觉佛）／三阶全有（注定成佛的菩萨）。
3. **降生**：菩萨以平稳双足立地、向北迈七步，发狮子吼——「我是世间功德绝顶者/最高者/最胜者，这是最后生，今后已无再生」（如实陈述，非傲慢）。
4. **出家**：29 岁的悉达多太子四门游观，见老人·病人·死人·沙门**生悚惧心**；在罗睺罗出生之日，夜半**大出离**。
5. **苦行的教训**：古印度「主动受苦消业障」的习惯——**佛陀发现极端苦行是错误的、没有意义**。

### W7　死随念

**共读材料**：《231107大佛禅修营第五天早上开示》（死亡是自然规律·凡夫何以怖死·正确作意·九种利益·取尸体替换自身的传统修法）〔★〕

**知识框架**
- 死亡是自然法则：只要有生，就有死
- 凡夫临终三种不善心：贪恋·嗔恨·恐惧
- 正确作意：我必然会死·命根会断·身体会坏
- 九种利益
- 什么时候修：懈怠放逸时
- 传统修法：取同性尸体观不净，再替换为自身

**要点**
1. **开场之问**：我们可以不死吗？我们害怕死吗？——**一定会死又怕死 → 死时必无好心情 → 不善心 → 堕恶趣**；故佛陀教修死随念、先正确认识死亡。
2. **死亡是自然法则**：只要有生，就有死——谁都不能例外（权威·财富·天人·圣者·佛陀皆然）；**死心灭、结生心无间生起**，冰冻/克隆皆无用。
3. **凡夫临终三种不善心**：贪恋（忆念所爱，悲伤生起）·嗔恨（忆念敌对者，「死不瞑目」）·恐惧（想到自己将死）。
4. **正确作意**：构思**我必然会死·命根会断·身体会坏**——忆念的是**自己的死**（非想别人死）。辅助观想：身后有无间追近的杀戮者／头顶悬剑／由兴盛而衰败。
5. **九种利益**（源稿为录音转写，序号有跳缺，按实列项呈现）：①得「一切诸有不可乐想」②克服对生命的执取 ③谴责罪恶 ④不多储藏（不悭吝）⑤熟练无常想（→苦想·无我想易现起）⑥临终无畏、无昏迷 ⑦今生不证阿拉汉、来世得善趣——「有这么多的利益，细的还有更多」。
6. **什么时候修**：**懈怠放逸、不想修法的时候**——用死随念策励自己的精进。
7. **传统修法（◈扩展）**：取**同性**的尸体观不净，再替换为自身（异性尸体易反生贪欲）；可配合不净证**近行定**，或修观禅的不净业处；对死亡生起**悚惧**——「我一定也会跟他一样死掉，不知何时何地死」。

2. **修法要点（十种善巧）**：依次作意·不过急·不过慢·不散乱·超越名称概念·次第不显现而空缺作意·根据安止/《增上心》/《清凉性经》/《觉支善巧经》作意；**作意取相**＝以头发为例的「遍作」阶段（记录颜色）。
3. **以「五事」分辨**每一身分：颜色·形状·方位·处所·界限（自分／异分界限）；**八类利益**（征服不乐与乐·征服怖畏·能忍冷热饥渴蚊虫恶言·成四禅四遍·成神通）。
4. **观察方式**：把「人」还原成三十二身分（**把脸变成骷髅**）；**「透视」皮肤、观见内部不净** → 解决对（他人）贪爱的执取；并作「闭眼回忆·逐部位觉察」训练。
5. **固态组（第二、三组＋脑/粪）**：肉（红，腥臭）·筋（白）·骨·骨髓·肾／心·肝·肋膜／胃中物（如污水池）·粪·脑。
6. **水界组（第五、六组）**：胆汁·痰·脓·血·汗·脂肪·泪·油膏·唾液·涕·关节滑液·尿。
7. **层次**：先在**概念上**把三十二身分过清楚（现在就能做），定力深了才谈得上看细。**对在家人是日用工具**——心烦时收摄散乱、贪爱冒头时对治、照镜生容貌执着时作意；**始终以慈心平衡，不净观不是自厌**。

### 4W4　死随念与四护卫禅综合运用　（＝8W7 + 8W8）

**共读原文1**：《231107大佛禅修营第五天早上开示》——死亡是自然规律·凡夫何以怖死·正确作意·九种利益·取尸体替换自身
**共读原文2**：《四护卫禅明灯论 Caturārakkhadīpanī.pdf》——四重防护时序·偈颂选录；《10_四护卫禅-古源尊者-20250111》——业处分类·依状态选前行·名号选择

**知识框架**
- 死亡是自然法则；凡夫临终三种不善心
- 正确作意：我必然会死·命根会断·身体会坏；九种利益
- 传统修法：取同性尸体观不净，替换为自身
- 四重防护时序：晨修佛念→昼修慈心→暮修不净→夜修死念
- 上座前以智慧观察自己；不必每次都做前行
- 佛随念十种名号的选择；收摄回入出息念

**要点**
1. **死亡是自然法则**：只要有生就有死，谁都不能例外；**死心灭、结生心无间生起**；凡夫临终三种不善心＝**贪恋·嗔恨·恐惧**。
2. **正确作意**：**我必然会死·命根会断·身体会坏**（忆念自己的死）；辅助观想：身后追近的杀戮者／头顶悬剑／由盛而衰。
3. **死随念九种利益**：得「一切诸有不可乐想」·克服对生命的执取·谴责罪恶·不多储藏·熟练无常想·临终无畏无昏迷·来世得善趣——**懈怠放逸、不想修法时修死随念，策励精进**。
4. **传统修法（◈）**：取**同性**尸体观不净、再替换为自身（异性尸体易反生贪欲）；对死亡生起悚惧。
5. **四重防护时序**：**晨修佛念 → 昼修慈心 → 暮修不净 → 夜修死念**；各对治一烦恼（佛随念→疑与怯弱／慈心→嗔／不净→贪／死随念→放逸）。
6. **上座前以智慧观察自己**：昏沉→修所缘多的前行；有气→多修慈心；身不适→对身体修慈心或四大差别；**能直接安住根本业处则前行不必做**。
7. **佛随念十种名号的选择**：想成就什么就多忆念什么（阿拉汉→断烦恼…**跋格瓦（世尊）**→求吉祥·万德庄严）；**修慈心的深一层**——心遍满慈，过去伤害性的不善业即退避。
8. 收摄：一切法门最后回到**入出息念**；八周所学＝「护身之物要天天带在身上，才护得了人」。
