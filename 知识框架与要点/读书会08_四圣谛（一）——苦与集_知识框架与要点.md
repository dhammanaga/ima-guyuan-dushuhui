## 一、总知识框架：四圣谛（一）· 苦与集

### 1. 一句话主线

> 佛陀成道后第一次说法，讲的就是四圣谛——**苦、苦之集、苦之灭、导至苦灭之道**；修行的起步，是「**如实了知**」：如实知苦、如实知苦因。
> 本系列先把「苦」看清（苦谛），再把「苦的因」看清（集谛）——**如实知苦，是为了离苦，不是沉溺苦。**

### 3. 总核心要点

1. **四圣谛是「看问题的最上之理」**：佛陀悟道后第一次说法讲的即是苦集灭道；从概念上逐一认识——苦＝八苦（简言之五取蕴是究竟的苦）、集＝爱欲（渴爱）是苦最显著的助缘、灭＝爱欲的无余灭尽（涅槃）、道＝八圣道分。
2. **苦分两层：世俗谛之苦与究竟谛之苦**。八苦／十一项属概念法（世俗谛），「简而言之，五取蕴即苦」属究竟法（究竟谛）——看到概念上的苦，要知道它在究竟上就是苦。
3. **苦的范围＝十一项＋五取蕴**：生、老、死、愁、悲、苦、忧、恼、怨憎会、爱别离、所求不得；收归一句「五取蕴即苦」。
4. **苦的本质是三相**：五蕴无常→无常故苦→苦故无我（三相连锁句）；并因「两种坏灭」（因缘坏灭＋刹那坏灭）而遍及三界，禅那乐、三界最高处都不出苦的范围。
5. **集谛的核心是「渴爱」**：此爱导致再有、与喜贪俱、处处而喜乐，分为**欲爱／有爱／无有爱**；它是苦生起最显著的助缘（种子湿度喻）。
6. **渴爱有「固定作案地点」**：佛陀以十组（内六处·外六处·识·触·受·想·思·爱·寻·伺）说明爱在何处生起、在何处「建立而住立」——灭苦要回到它生起的地方。
7. **集谛的根是无明**：无明＝对四圣谛无知；无明经「想蕴标记」沉淀为**三颠倒**（想颠倒·心颠倒·见颠倒）。造成今生五取蕴的五种过去因＝**无明·爱·取·行·业**。
8. **轮回的机制是三转轮**：烦恼轮转→业轮转→果报轮转；「果报如此，速行可变」，出路在当下。
9. **四谛是一个整体**：苦应知、集应断（苦与集是「当知／当断」）；灭应证、道应修（属于《四圣谛（二）》，详见读书会09）。
10. **看清苦≠悲观**：如实知苦正是离苦之路；本周作业与讨论都指向「在生活里认出苦、认出它的因」。

### W1　四圣谛总说——如实了知苦集灭道

**共读材料**：《第193讲 应用（摄集41）》；《小问答经讲记04-古源尊者-20251104》（课件）

**知识框架**
- 四圣谛总说：从概念上逐一介绍四谛——苦圣谛（八苦·五取蕴）／集圣谛（爱欲是苦的因）／苦灭圣谛（爱欲的无余灭尽）／道圣谛（八圣道分）
- 苦圣谛：八苦经文与解释、五取蕴总说、十一种五蕴
- 集圣谛：爱欲是苦的因、三种爱、五种因（无明·爱·取·行·业）
- 苦灭圣谛与道圣谛：渴爱的无余离染灭尽、舍弃、解脱、无执；于世间可爱可喜处舍断爱欲／八圣道分＝正见、正思惟、正语、正业、正命、正精进、正念、正定
- 正见＝了知苦·苦因·苦灭·导至苦灭之道的四种智慧；苦灭的次第（无明灭→行灭→…→一切苦灭）

**要点**
1. 四圣谛总说＝从概念上逐一认识四谛：什么是苦（八苦，简言之五取蕴）、什么是苦之集（欲爱·有爱·无有爱）、什么是苦之灭（渴爱的无余灭尽）、什么是导至苦灭之道（八圣道分）。
2. 苦圣谛的经文表述：生·老·死·愁·悲·苦·忧·恼·怨憎会·爱别离·所求不得＋「简而言之，五取蕴即苦」。
3. 生、老、死各依世俗谛（一生首末刹那之间为「老」）与究竟谛（每一名色刹那的生·住·灭）两法观照。
4. 集圣谛：渴爱（此爱导致再有、与喜贪俱、处处喜乐）＝欲爱·有爱·无有爱，是苦最显著的助缘（种子湿度喻）。
5. 无明·爱·取·行·业为五种因；爱欲在诸因中最显著。
6. 苦灭圣谛：渴爱的无余离染灭尽、舍弃、舍遣、解脱、无依住（《小问答经》问答）；于世间可爱可喜处（眼根等）舍断爱欲。道圣谛：圣八支道；正见＝了知苦、苦因、苦灭、导至苦灭之道的智慧。
7. 四圣谛是看问题的最上之理，也是解脱的根本——本系列的总纲。

### W2　苦圣谛（一）——世俗谛之苦的十一项观察

**共读材料**：《正念之道》（帕奥西亚多）〔主〕；辅以《大念处经》讲记、如来禅修学体系05

**知识框架**
- 苦的定位：四圣谛随观下的苦圣谛
- 八苦列举＋生、老、死的定义
- 八苦的世俗谛／究竟谛双层解读；观照生老死的两种方法
- 愁·悲·苦·忧·恼（心的苦受·嗔组）；怨憎会苦与爱别离苦
- 所求不得苦（含禅修中的「求不得」）
- 「简而言之，五取蕴是苦」：十一种五蕴、名色分别智
- 扩展：生为什么是苦——十二种苦与入胎七苦相

**要点**
1. 「苦」＝十一项能在自己生命里逐一对上号的具体经验：生·老·死／愁·悲·苦·忧·恼／怨憎会·爱别离·所求不得。
2. 生·老·死各有定义；概念法（世俗谛）与究竟法（究竟谛）双层观察（观照生老死须两种方法并观）。
3. **愁·悲·忧·恼是「心的苦受」，属嗔（瞋）组**；**「苦」是身门心路过程中与身识相应的苦受**——观照时按心路过程观。
4. 怨憎会＝与不可喜、不可爱、不可意之六境或「意图不利者」相遇；爱别离＝与可喜、可爱、可意者（父母兄弟亲友）分离——都生起与瞋俱的苦受。
5. 所求不得：有生（老病……愁悲苦忧恼）法者起「愿不生」之欲求而不能得；**这些无法藉愿望达成，但可藉有系统地修习八支圣道达成**。
6. 「简而言之，五取蕴即苦」——五取蕴是观智的目标，先观十一种五蕴（详见W3）。
7. 「dukkha（苦）」「Dukkha（巴利语：dukkha）」的词义与「如实知苦是为离苦」。

### W3　苦圣谛（二）——五取蕴即苦与十一类五蕴

**共读材料**：《171讲 摄集·摄一切》（共修版）；《蕴品 Khandhavaggapāḷi》

**知识框架**
- 摄一切之概要：蕴·处·界·谛等分类法是为了显示观智所照的范围
- 五蕴：蕴＝「一堆、一组」；十一个维度
- 五取蕴 vs 五蕴：区别在「可被执取」
- 四圣谛的收摄：众苦归苦圣谛，而根子在五取蕴
- 十二处：从「门与所缘」再分一遍
- 经典证成（蕴品）：执取→忧悲苦恼；不执取→解脱；重担经；无我相经

**要点**
1. 蕴＝积聚义（「一堆、一组」）；色·受·想·行·识五蕴。
2. **十一种维度**：过去·现在·未来／内·外／粗·细／低劣·优胜／远·近——各蕴皆以此十一类遍观。
3. **五取蕴与五蕴之别在「可被执取」三字**——这正是「苦的开关」：会被执取的五蕴即苦。
4. 「简而言之五取蕴即苦」：一切苦收摄于苦圣谛，而苦圣谛的根子落在五取蕴。
5. 十二处／十八界（意处分为七个识界）／四究竟法（心·心所·色·涅槃）与蕴、处、界的对应关系——同一堆现象的多种分法。
6. 蕴品经文证成：凡夫执取五蕴 → 愁悲苦忧恼；不执取 → 心解脱；任「重担」者即五取蕴，放下重担；《无我相经》——五蕴非我、非我所。

### W4　苦圣谛（三）——为何有生命就是苦：三相与两种坏灭

**共读材料**：《蕴品 Khandhavaggapāḷi》（三相经段）；《显正法藏》（帕奥西亚多）

**知识框架**
- 开卷·身病心不病（《那拘罗父经》）
- 三时·三相经：五蕴皆无常·苦·无我
- 三相直说＋三相连锁句（凡无常者→苦；凡苦者→无我）
- 因与果俱三相；坏灭经证（易坏经·灭法经）
- 三相的完整解脱链；如实知五蕴生起灭尽（三昧经）
- 三界皆苦的经文映照（阿罗汉经）；观无常→喜贪灭；十一类遍观与断我慢
- 显正法藏：三相总说；十一种五取蕴皆苦；生灭随观智（因缘生灭／刹那生灭）

**要点**
1. **三相连锁**：五蕴无常 → 无常故苦 → 苦故无我；这是「为何有生命就是苦」的推理链。
2. **两种坏灭**：**因缘坏灭**（缘起层面的因缘生灭）与**刹那坏灭**（每个名色刹那的生灭）——两者把「苦」焊在「生命」上。
3. 三界皆苦：连禅那之乐、连三界最高处（非想非非想处）都出不了苦的范围。
4. 「如实知五蕴的生起与灭尽」→ 厌离 → 离贪 → 解脱（《无常经》第45）。
5. 观照苦谛法、集谛法为无常·苦·无我；三遍知（知遍知·审察遍知·断遍知）。
6. 出路：观无常则喜贪灭；如实知苦，即为离苦之始。

### W5　集圣谛（一）——渴爱：欲爱、有爱、无有爱

**共读材料**：《显正法藏》；《清净之道》（清净道论）

**知识框架**
- 苦集圣谛经文总定义（与喜、贪俱）
- 何谓渴爱：欲爱／有爱／无有爱（定义与展开）
- 何谓五取蕴是苦——「快乐是倒腾出来的」
- 渴爱是苦的因——一切苦皆由渴爱驱动（种子湿度喻）
- 音声展开：空间地狱；贪心升起怎么办（省察食物·子肉经）；临终与轮回警示；日常舍断入手
- 显正法藏 5.2（五种方式·阿沙卡本生）；《清净之道》三种贪爱

**要点**
1. **苦集圣谛**＝「此爱导致再有，与喜、贪俱，于处处而有喜乐」——即欲爱·有爱·无有爱。
2. **欲爱**＝对色·声·香·味·触·法的爱；**有爱**＝(1)与常见俱生的爱（大我／真我／神识）、(2)对色界无色界生命的爱、(3)对禅那的爱；**无有爱**＝与断灭见相关的爱（对「没有再生」的爱）。
3. 渴爱是苦生起**最显著的助缘**（种子湿度喻：业力如种子，爱欲如种子中的湿度——没有爱欲，业力无法产生五蕴）。
4. 「简而言之，五取蕴是苦」——**快乐是倒腾出来的，痛苦才是它的本质**。
5. **贪心升起的当下**有可用的方法：如理作意、省察食物、子肉经等；**日常舍断三层次**＝彼分断·镇伏断·正断断。
6. 临终与轮回的警示（行舍智结生、天界四类人）；无有爱所感的「空间地狱」。
7. 一切苦皆由渴爱驱动——集谛的总纲。

### W6　集圣谛（二）——渴爱生起的十组处所

**共读材料**：《正念之道》（帕奥西亚多）

**知识框架**
- 开篇：把苦·集·灭·道串起来
- 苦集圣谛：十组概述框架
- 苦灭圣谛：同样在这十组相应处灭除渴爱
- 十组逐组机制——「凡世间有喜色、悦色者，其爱即于此处生起而生起，于此处建立而住立」
  - 1 内六处·外六处（果报评价机制）／2 识／3 触／4 受（爱生起的基地）／5 想（标记与颠倒想）／6 思（从标记到行动）／7 爱／8 寻／9 伺
- 苦灭圣谛：依十二处解释爱欲的灭除（稻田蔓生植物喻）

**要点**
1. 苦之集＝**无明与渴爱**，佛陀分为**十组**来解释。
2. **十组**：内六处·外六处·识·触·受·想·思·爱·寻·伺——爱就在这十处**生起**并**「建立而住立」**。
3. 经文核心：「凡世间有喜色、悦色者，其爱即于此处生起而生起，于此处建立而住立。」
4. **爱有「固定作案地点」**：果报评价机制使爱恰在「可喜可爱」处生起；关键是**从「受」到「爱」的那一跳**。
5. **寻、伺让爱「住立」下来**（习惯性的渴爱）——这是爱能反复发生的原因。
6. **灭苦要回到它生起的地方**：灭谛同样在这十组灭渴爱（稻田蔓生植物喻——在根处断除）。

### W7　集圣谛（三）——无明、五种苦因与烦恼轮转

**共读材料**：《〈摄集〉汇总讲义》；《第9讲 摄缘·缘起支4》；《如来禅修学体系05·缘起》

**知识框架**
- 轮回的根：无明与渴爱；什么是无明（两种含义）
- 无明的形成：想蕴标记 → 三颠倒（想颠倒·心颠倒·见颠倒）；狼孩喻；四种想
- 无明让我们「不知有涅槃」
- 五种苦因／过去因（无明·爱·取·行·业）；贪的根源与临死速行业的无明爱取
- 三颠倒与常·乐·我·净；行＝福行·非福行·不动行
- 烦恼轮转→业轮转→果报轮转
- 日常生活中削弱无明、断除颠倒

**要点**
1. **轮回的根是无明与渴爱**；无明＝对四圣谛无知（经教法）／对八处无智（论教法），有「遮蔽」义。
2. **无明如何形成**：想蕴的「标记」过程 → **三颠倒**：想颠倒（稻草人）·心颠倒（魔术师）·见颠倒——层层递进，沉淀成坚固的错看（狼孩喻）。
3. 「虽见究竟法，但不见四圣谛，仍是无明」；无明让我们**不知有涅槃**。
4. **造成今生五取蕴的五种过去因**（集谛）＝无明·爱·取·行·业；其中爱欲最显著。临死速行业的「无明·爱·取」决定结生。
5. 三颠倒与常·乐·我·净（十二种颠倒）；**行**＝福行·非福行·不动行。
6. **三转轮**：烦恼轮转 → 业轮转 → 果报轮转。
7. 出路：「**果报如此，速行可变**」——在日常生活中发现烦恼、削弱无明。

### W8　以四圣谛看问题——苦与集的生活运用与总结

**共读材料**：《第196讲 应用（摄集44）》；《2023六一密集禅修营开示6·五蕴转念法》

**知识框架**
- 定位：四念处是必行之道
- 四圣谛运用：（一）看问题的原则 →（二）集的生起·建立 →（三）灭的舍弃·断除 →（四）用八正道灭除苦
- 拥有导向解脱的「见」（回向的深义）
- 总结：三十七道品总收与氛围营造
- 生活实操：五蕴转念法（五盖源于无明爱取 → 把认知拆开、把常见拆掉）

**要点**
1. **看问题以四圣谛为原则**：先如实知「这是苦」，再找它的「集」——**不以「希望问题赶紧消失」为目的**（那不符合佛陀的教导）。
2. **四圣谛运用四步**：看问题的原则／集的生起与建立／灭的舍弃与断除／用八支圣道灭除苦。
3. 解决问题应循**八支圣道**；培养「拥有导向解脱的见」（正见）——回向的深义。
4. **五蕴转念法**（生活实操四步）：①发生了什么（色）→②我的感受与情绪（受）→③我当时给它贴了什么标记（想）→④我把什么当成了「必然／应该」（常见）——**把认知拆开，把常见拆掉**。
5. 「**无明缘行、无明灭则行灭**」：从「颠倒想」转向「有慧想」。
6. 全系列总结：三十七道品总收，在生活中营造觉悟的氛围；展望灭谛与道谛（**详见读书会09**）。

### 4W1　四圣谛总说与苦圣谛·十一项观察　（＝8W1 + 8W2）

**共读原文1**：《第193讲 应用（摄集41）》——苦谛·集谛；《小问答经讲记04》——苦灭圣谛·道圣谛
**共读原文2**：《大念处经》讲记27——苦圣谛十一项逐项；《正念之道》——十一项互证

**知识框架**
- 四圣谛总说：从概念上逐一认识四谛——苦（八苦·五取蕴）／集（爱欲是苦的因）／灭（爱欲的无余灭尽）／道（八圣道分）
- 苦圣谛：八苦经文＋生老死定义＋世俗谛／究竟谛双层
- 愁·悲·苦·忧·恼（心苦·嗔组）／怨憎会／爱别离／所求不得
- 简而言之五取蕴即苦（十一种五蕴总说）
- 集圣谛引子：爱欲是苦的因（欲爱·有爱·无有爱）
- （延伸）《正念之道》书摘：苦圣谛十一项互证与五取蕴总说

**要点**
1. 四圣谛＝佛陀第一次说法的核心，是「看问题的最上之理」与解脱根本；修行起步是「如实了知」——如实知苦、知苦因、知苦灭、知道。
2. 苦有**世俗谛（十一项／概念法）**与**究竟谛（五取蕴／究竟法）**两层——看到概念苦，须知其究竟即苦。
3. 十一项：生·老·死·愁·悲·苦·忧·恼·怨憎会·爱别离·所求不得；生老死须以两种方法（世俗／究竟）观照。
4. 愁悲忧恼是心的苦受（嗔组）；「苦」是身识相应的苦受。
5. 所求不得无法藉愿望达成，可藉修**八支圣道**达成。
6. 「简而言之，五取蕴即苦」；先总说五取蕴与十一种维度（详见 4W2）。
7. 集谛引子：渴爱（欲爱·有爱·无有爱）是苦最显著的助缘（详见 4W3）。

### 4W2　苦圣谛·五取蕴与三相坏灭　（＝8W3 + 8W4）

**共读原文1**：《171讲 摄集·摄一切》——五蕴·五取蕴·处·界·谛对应体系
**共读原文2**：《蕴品》三相经段（＋《显正法藏》三相与两种坏灭）

**知识框架**
- 五蕴：「一堆、一组」；十一个维度
- 五取蕴 vs 五蕴：「可被执取」是苦的开关
- 四谛收摄：众苦归苦圣谛，根子在五取蕴；十二处／十八界／四究竟法
- 三相：无常 → 苦 → 无我（三相连锁句）
- 两种坏灭：因缘坏灭＋刹那坏灭；三界皆苦
- 经典：执取→忧悲苦恼、不执取→解脱；重担经；无我相经；那拘罗父经（身病心不病）

**要点**
1. 蕴＝积聚义（「一堆、一组」）；五蕴皆以**十一种维度**遍观（过去·现在·未来／内·外／粗·细／低劣·优胜／远·近）。
2. **五取蕴与五蕴之别在「可被执取」**——苦的开关；「简而言之五取蕴即苦」，苦圣谛根子在五取蕴。
3. 十二处／十八界／四究竟法与蕴、处、界的对应——同一堆现象的多种分法。
4. 蕴品证成：执取五蕴→愁悲苦忧恼；不执取→心解脱；五取蕴即「重担」，放下重担。
5. **为何有生命就是苦**：无常→苦→无我（三相连锁）。
6. **两种坏灭**把苦焊在生命上：因缘坏灭＋刹那坏灭；三界皆苦。
7. 出路：如实知五蕴生起灭尽 → 厌离 → 离贪 → 解脱；观无常则喜贪灭。

### 4W3　集圣谛·渴爱与十组生起处所　（＝8W5 + 8W6）

**共读原文1**：《194讲（共修版）》——渴爱三种定义与苦因
**共读原文2**：《195讲（共修版）》十组框架 ＋《194讲（共修版）》十组逐组机制

**知识框架**
- 苦集圣谛经文（与喜贪俱）
- 渴爱三种：欲爱·有爱·无有爱（定义与展开）
- 五取蕴是苦——「快乐是倒腾出来的」；渴爱是苦的因（种子湿度喻）

- 十组逐组：内六处·外六处→识→触→受→想→思→爱→寻→伺
- 稻田蔓生植物喻：在根处断

**要点**
1. **渴爱**＝「此爱导致再有，与喜、贪俱，于处处而有喜乐」；分**欲爱·有爱·无有爱**。
2. **欲爱**＝对六境的爱；**有爱**＝常见俱生之爱／对色无色界生命之爱／对禅那之爱；**无有爱**＝与断灭见相关的爱。
3. 渴爱是苦生起**最显著的助缘**（种子湿度喻）；「快乐是倒腾出来的，痛苦才是它的本质」。
4. 苦之集＝**无明与渴爱**，佛陀分**十组**解释：内六处·外六处·识·触·受·想·思·爱·寻·伺。
5. 爱在「喜色、悦色」处生起并**「建立而住立」**；关键是**从「受」到「爱」的那一跳**，寻·伺使之住立。
6. **灭苦要回到生起的地方**：灭谛同样在此十组灭渴爱（稻田蔓生植物喻——在根处断）。
7. 日常入手：如理作意、省察食物；舍断三层次＝彼分断·镇伏断·正断断。
