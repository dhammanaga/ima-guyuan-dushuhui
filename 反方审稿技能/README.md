# kb-adversarial-review · 反方审稿技能（ima Copilot 版）

**裁判库已写死**：`@古源尊者开示及上座部佛教资料`。不用每次指定，也不许换别的库。

以该库为唯一裁判依据，对文档做反方审查：拆主张 → 强制取证 → 四角色挑错 → 出带引文的缺陷表。

**它最大的不同**：市面上的「魔鬼代言人」工具都拿模型自己的知识当判据，对上座部教理/律学这类术语密集的内容会双向出错（冤枉正确原文 + 放过真正的错）。本技能把裁判权交给固定知识库——**凡判定必引原文，找不到就写「无据」，禁止用常识替代**。

## 一、导入（两条路径，任选一）

入口：ima 客户端 → **Skills 管理** → **添加 Skill**
平台支持格式：**ZIP 或 MD**，单文件 ≤ 10MB。
MD 需含 YAML 格式的名称与描述（本技能 SKILL.md 开头已带）。

### 路径 A：上传 ZIP（推荐，含参考细则）

1. 选 `kb-adversarial-review.zip`
2. 上传 → 等安全检测 → 在「自定义」分类中确认可见

### 路径 B：上传单个 MD（最快，功能不减）

1. 选 `kb-adversarial-review/SKILL.md`
2. 上传即可

> SKILL.md 本身是**自足**的，全部铁律、流程、报告格式、裁判库都在里面。
> ZIP 里多出的 `references/` 只是加深精度用的细则，缺了也能跑，只是角色问句没那么细。

### 导入后验证

1. 先挂载知识库：在对话框 @古源尊者开示及上座部佛教资料
2. 输入：`反方审稿《文档名》`

若它先问「审哪篇、给谁看」，就说明已生效——**它不该再问用哪个库**，问了就是还在用旧版。

## 二、怎么用

最省事的一句：

> 反方审稿《某篇讲义》

带读者与重点：

> 反方审稿《某篇讲义》，读者是初学者，重点看教理有没有被曲解

前置条件只有一个：`@古源尊者开示及上座部佛教资料` 已挂载。技能自己会先确认，没挂载会提示你先挂。

### 输出会是什么

| 区块 | 内容 |
|:--|:--|
| 开头四行 | 范围 / 裁判依据（固定为该库）/ 四态统计 / 总判定 |
| 一、必改清单 | P0 + P1，每条带文档说法、原文引证、**出处与层级**、问题类型 |
| 二、逐节取证表 | 每条主张一个标签：✅吻合 ⚠️曲解 ❌矛盾 ❓无据 |
| 三、结构问题 | 次第倒置、论点论据错配、层级混乱 |
| 四、读者风险 | 会被误读成什么、建议补一句什么 |
| 五、待裁定 | 反方内部有分歧的，摆出来给你判，不强行统一 |
| 六、库外提示 | 模型凭自身知识的怀疑，**明标非裁判依据** |
| 七、P3 建议 | 纯风格，**非错误**，不影响判定 |
| 八、可信度自评 | 覆盖率 / 引证率 / 未解决项 |

判定三档：**READY** / **NEEDS WORK** / **NOT READY**。
另有一种例外：**INCONCLUSIVE**——库里本来就没有对应材料，反方无权判对错，会写明缺哪类资料让你先补库。

## 三、库内材料层级（这是升级的重点）

本库混有四类材料，效力不同。**取错层，必误判。**

| 层级 | 材料 | 用法 |
|:--|:--|:--|
| **L1 原典** | 上座部经、律、论原文 | 教理事实的最终依据 |
| **L2 注疏** | 义注、复注、疏钞、概要类 | L1 未直说时使用，须注明「此依注疏」 |
| **L3 整理** | 教材、讲义、整理稿、科判表 | 只作辅助定位，**不作判定依据** |
| **L4 开示** | 古源尊者开示记录 | 见下 |

**核心规则：判据层级由「文档在陈述什么」决定，不由材料高低决定。**

| 文档在陈述什么 | 判据用哪层 |
|:--|:--|
| 尊者开示的内容（「尊者说……」「依开示……」） | **L4**，原典字面不能用来否定它 |
| 教理事实（「此戒的开缘是……」） | **L1**，L2 补 |
| 把开示当经文引（「经中说……」实为开示语） | 判 ⚠️ 曲解；错标到具体经名 → **P0** |
| L4 与 L1 字面有张力 | **不判文档错**，进「待裁定」，交尊者裁定 |

> 这一层是本技能最容易被忽略、也最容易误判的地方。库里既有开示又有原典，最常见的错判就是拿原典字面去否定开示的表述，或把开示语当作经文引用。

## 四、行为边界（这是设计，不是限制）

1. **不改正文**。只出报告。你要它改，得单独说「按报告改第 1、2 条」。
2. **不为凑数造缺陷**。文档没问题就说 READY。
3. **不虚构引文**。引文必须逐字能在库里搜到。
4. **不越库**。取证只在 `@古源尊者开示及上座部佛教资料` 内，不联网、不借别的库。
5. **一次一篇**。超过 8 节会分批，每批停下来让你看方向。

---

## 五、要换库或换领域怎么办

**本技能已锁定裁判库与领域，正常使用不需要改。** 若确实要用于别的场景，必须**同时**改两处，只改一处即为故障：

1. SKILL.md 第零节的库名
2. SKILL.md 第 3.1 节的领域问句

| 领域 | 问句方向 |
|:--|:--|
| 法律 / 合规 | 要件是否齐备、适用条件、例外与旧法冲突 |
| 医学 | 适应症禁忌、证据等级、剂量与人群差异 |
| 学术论文 | 文献是否支撑结论、方法可复现性、前人工作 |
| 产品 / 方案 | 前提假设、成本边界、失败路径 |

`references/roles.md` 里有每个角色的完整问句清单，照格式替换即可。
