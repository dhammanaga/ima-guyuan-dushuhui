# 严重度判例与边界情形

用于统一尺度。同一处问题，不同人判出不同级别，是审稿报告最容易被推翻的地方。

## 一、P0 致命

判准：**结论性错误**，或**与原文明确矛盾**，或**会把读者带向相反理解**。

| 判例 | 为什么是 P0 |
|:--|:--|
| 把戒条的「开」写成「遮」 | 直接反了，读者据此行事会出错 |
| 把某部经/论的归属搞错 | 归属错会连带整个判教框架错 |
| 原文说「不得」，文档写「应当」 | 明确矛盾，且具操作性后果 |
| 把否定句读成肯定句 | 语义反转 |
| 引文内容与所标出处完全无关（伪造引文） | 论据全体失效，且属学术不端 |
| 把尊者开示的话标成某经原文（错到具体经名） | 归属错置，读者会据此以为有经文依据 |

## 二、P1 重大

判准：**曲解**、**关键论据无据**、**结构错配导致论点不成立**。

| 判例 | 为什么是 P1 而非 P0 |
|:--|:--|
| 原文有「若…时」的限定，文档去掉限定写成通例 | 意思被推宽，但方向未反 |
| 关键论据在库中查不到 | 结论失去支撑，但结论本身未必错 |
| 引文掐掉后半句，后半句恰好收窄范围 | 属断章取义 |
| 把开示语当经文引述，但未错标到具体经名 | 归属含糊，方向未反 |
| 用 L3 教材/讲义单独支撑教理判定 | 判据层级不足 |
| 章节顺序颠倒，导致论证链断裂 | 结构性问题，影响成立性 |
| 术语前后不一致，使某段论述指向不明 | 影响可读与可判 |

## 三、P2 次要

判准：**内容无误，但标注或表述不精确**。

| 判例 |
|:--|
| 引文页码/卷次标错，但内容确实在该书 |
| 同一概念两种译名混用，但上下文可辨 |
| 举例不够贴切，但论点仍成立 |
| 数字写法不统一（三 vs 3） |

## 四、P3 建议（非错误）

- 句子太长、层次太密
- 可以补一个例子更好懂
- 语气可以更平和

**P3 必须单列，标题写明「非错误，仅供参考」，不进缺陷表，不影响判定。**

## 五、三个易混边界

### 1. 「无据」到什么程度算 P0，什么程度算 P1？

- 关键论据无据，且**结论完全依赖它** → P1（若该结论本身与库中其他原文相冲突，则升 P0）
- 次要论据、旁证无据 → P2
- 大量细节均无据，全文像是凭印象写成 → **整篇 NOT READY**，并建议重写而非逐条修

### 2. 「原文没直说，但可合理推得」怎么判？

标 ⚠️ 曲解，附两段引文（前提句 + 被推句），并在「差在哪里」写明：
「原文只到 X，文档推到了 Y，中间缺 Z 这一步。」

**不许**因「推论合理」就判 ✅ 吻合。吻合只留给原文明确支持的情形。

### 3. 知识库本身有内部矛盾怎么办？

单独列「知识库内部冲突」区，列出冲突的两处原文与出处，**不判定文档对错**，交人裁定。此时文档若与其中一处一致，标 ✅（并注明「依 A 处」）。

## 六、判定汇总规则

| 情况 | 总判定 |
|:--|:--|
| 有任意 P0 | NOT READY |
| 无 P0，有 P1 | NEEDS WORK |
| 仅有 P2 / P3 | READY（可附「顺手可修项」） |
| 全文大面积无据（>40% 主张） | NOT READY，建议重写 |
| 知识库覆盖不足（某主题库里本来就没材料） | 判定降为 INCONCLUSIVE，说明缺哪类材料 |

## 七、报告可信度自评（写在报告末尾）

- 主张覆盖率：已核查 N 条 / 全文估计 M 条
- 引证率：有引文的判定数 / 全部判定数（应接近 100%）
- 未解决项：待裁定 X 条、库外提示 Y 条、知识库缺口 Z 处

这三行是为了让读报告的人知道**这份报告本身有多可信**，不是装饰。
