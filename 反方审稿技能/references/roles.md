# 四角色问句细则

供 SKILL.md 第 3 步加深精度用。每个角色**独立过一遍**，不要合并。

---

## 一、领域反方（默认：上座部教理 / 律学）

### 1.0 先定层级（裁判库固定为 @古源尊者开示及上座部佛教资料）

开审前先判：**这段文档在陈述什么**？层级取错，后面全错。

| 文档在陈述 | 判据层级 | 犯规判法 |
|:--|:--|:--|
| 尊者开示的内容 | L4 开示记录 | 拿原典字面否定开示表述 → **不许判错**，进待裁定 |
| 教理事实 | L1 原典，L2 注疏补 | 拿 L3 教材/讲义单独定案 → 判据无效 |
| 把开示说成经文（「经中说……」） | — | ⚠️ 曲解；错标到具体经名 → P0 |
| 把注疏说成原典 | — | ⚠️ 曲解；影响结论 → P1 |
| 把原典说成尊者开示 | — | ⚠️ 曲解（归属错置） |

### 1.1 定义类

1. 这个术语在知识库里被定义过吗？文档用的定义，与库中定义是同一个意思吗？
2. 有没有「同名异义」？同一个词，文档在一处用 A 义、另一处用 B 义？
3. 有没有「异名同义」？同一概念出现两种译法，文档有没有说明？
4. 有没有把**上位概念**当**下位概念**用（或反之）？例如把通途法门等同于某一宗派的判法。

### 1.2 开遮持犯类（律学重点）

1. 文档说的「犯」，是**根本、方便、还是次第**层面的犯？
2. 开缘的条件，文档列全了吗？有没有把「某条件下的开」写成「一律开」？
3. 有没有把**制戒因缘**（当时针对的具体情形）当成**普遍规则**？
4. 有没有把**注疏的解释**当成**原典原文**？有没有把**尊者开示**当**经文**引用？
5. 轻重、可悔不可悔的分别，与库中一致吗？

### 1.3 次第与判教类

1. 文档的论述顺序，与知识库呈现的次第一致吗？
2. 有没有把**方便说**当**究竟说**，或反过来？
3. 有没有把**某一时期、某一对机**的说法，推广成**通例**？
4. 宗派立场不同导致的判法差异，文档有没有说明「此依某宗」？

### 1.4 常见的六种典型错误（见到就重点查）

| 错误类型 | 表现 | 取证时的查法 |
|:--|:--|:--|
| 以偏概全 | 原文在特定条件下说 X，文档写成普遍说 X | 找原文的限定语（「若有…」「除…」「于…时」） |
| 时代错置 | 把后出注疏的观点安到早期原典 | 查该说法在库中最早出现的文本 |
| 张冠李戴 | 引文内容对，但出处标错 | 直接核对该书该篇是否有此句 |
| 层级错置 | 把开示当经文引、把注疏当原典 | 核对引文所标出处与实际文本层级（L1–L4） |
| 断章取义 | 引半句，另半句恰好相反 | 查引文前后各一句 |
| 概念滑动 | 开头定义 A，论证中悄悄换成 A′ | 逐段核对同一术语的用法 |
| 结论越界 | 论据只支持弱结论，文档下强结论 | 看结论里的情态词：一定／必然／皆／唯 |

## 二、论据反方

### 2.1 存在性

1. 这条论据**在库里真的存在**吗？还是文档自己生成的？
2. 存在的话，是原文、注疏、还是二手转述？文档标的是哪一种？
3. 出处（书名 / 篇名 / 章节 / 编号）与内容对得上吗？

### 2.2 忠实性

1. 引文有没有被掐头去尾？前后各一句是什么？
2. 原文的语气（肯定 / 假设 / 引述他人观点 / 反问）有没有被改掉？
3. 原文是在**陈述**某个观点，还是在**破斥**某个观点？文档有没有搞反？
4. 译文与原文：文档用的是哪一译本？与其他译本差异处，有没有影响结论？

### 2.3 推理合法性（四种跳跃）

| 跳跃 | 长什么样 | 怎么抓 |
|:--|:--|:--|
| 相关 → 因果 | 「A 出现后 B 也出现，故 A 导致 B」 | 原文是否只说「同时」 |
| 个案 → 通例 | 一则因缘故事被推成普遍规则 | 原文有无「是名…」「从此制」等限定 |
| 多数 → 全部 | 「多部经这样说」→「一律如此」 | 是否漏掉了反例文本 |
| 可能 → 必然 | 原文「或可」被写成「必定」 | 核对情态词 |

### 2.4 承载力

1. 这个论据，最多能撑到哪一步结论？
2. 文档的结论，是不是比论据允许的更进一步？
3. 若去掉这条论据，结论还站得住吗？站不住 → 它是关键论据，无据即 P1

## 三、结构反方

1. **次第倒置**：先讲果后讲因、先讲究竟后讲方便、先讲判教后讲教义——与库中编排相反
2. **论点论据错配**：标题说 A，内容讲 B；或某节的论据其实支撑的是另一节的论点
3. **层级混乱**：同一级标题下混入了不同层级的内容（应在下一级展开的，被提到同级）
4. **重复**：同一论点反复出现，且两处说法不一致（这比重复本身更严重）
5. **断裂**：上节提出的问题，下节没有承接；或结论凭空出现，前文没有铺垫
6. **头重脚轻**：次要内容占了大半篇幅，核心论点只有一两句
7. **缺失**：要支撑总标题，明显缺了某一块（对照知识库同类文本的常规结构）

## 四、读者反方

1. 目标读者是谁？他们对这个领域的**默认认知**是什么？
2. 哪一句会被误读？误读成什么？为什么会误读（歧义词、省略、语序）？
3. 哪些隐含前提没有交代，导致读者无法自己验证？
4. 术语首次出现有没有界定？没界定就直接用 → 缺陷
5. 「作者懂、读者不懂」的省略：数字、时间、人名、地名、典故、公案
6. 有没有**过度依赖上下文**的表述？单独看某一节会得出相反理解
7. 举例是否恰当？例子会不会反而让读者形成更粗的理解？

---

## 五、交叉质证规则

1. **合并**：同一处位置、同一问题的多个指出，合并为一条，记「命中角色数」
2. **加权**：四角色中 ≥3 个命中 → 置信度最高，直接进必改清单
3. **冲突**：两个角色判定相反 → 进「待裁定」，双方理由各写一句，**不许调和**
4. **降噪**：「我觉得应该展开」「可以更好」这类，全部进 P3，不占缺陷表
5. **复核**：合并后回头再看一眼原始引文，确认合并没有造成意思走样
