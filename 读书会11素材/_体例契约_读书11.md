## 二、材料信息行格式（四要素，字段名不得改）

```
### 原文材料1：〈文件标题〉★
- **文件类型**：pdf / word / 音声
- **知识库出处**：古源尊者开示及上座部佛教资料
- **media_id**：<完整 id 原样整串复制，严禁拆分/拼接/重排>
- **打开方式**：ima 知识库搜索「<标题关键词>」
> ⚠️ 主持人操作：<如何切分照录段落／何处跳读>
```
- 照录用 `>` 引用块或直接成段，**逐字照录，不得改写、不得虚构**；遇转写残缺保留 `[generated, not original text]` 原样。
- **音声**材料标题后加「（依据录音转写整理，已校对明显同音错字）」，并保留时间码 `[00:00:00.000]`。
- ★＝核心必读；◈＝扩展可选。

## 四、硬约束速查（5 条）

1. 照录不虚构：原文逐字照录，不改写、不臆补。
2. media_id 整串复制；新出现的 id 先 `grep -F` 禁用清单（命中即按段落级核验或换版本）。
3. 字数：主持人版 ≥ 30000 字符；其中照录 ≥ 12000 字符（以 python `len()` 计，非字节）。
4. 流程时长 120 分钟不得改动（静心10／共读30／分享25／讨论35／练习15／收尾20）。
5. 同一文件多次编辑必须**串行**，禁止并发 file_edit。
