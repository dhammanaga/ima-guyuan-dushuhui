# 有为法

什么是有为法？《增支部·有为相经》中说："诸比库，有这三种有为的有为相。哪三种呢？知生，知灭，知住之变易。"什么是有为法的有为相呢？生、住、灭。换言之，具有生、住、灭这三种特相的法就是有为法。

《中部义注》中说：""有为"即以诸缘会合而作，此是五蕴的同义语。"在此，诸缘指什么呢？就阿毗达摩而言，诸缘指十二缘起、二十四缘，也就是有为法生起、维持和灭去的因缘。"以诸缘会合而作"是从我们整个生命流——名色相续流来看的，名色相续流中的每一个名色，都是因缘和合而生、因缘离散而灭的。而二十四缘要解释的是，这些名色生起时各需要什么样的因缘，以及这些因缘如何产生作用。"以诸缘会合而作"的有为法指的是五蕴、名色，不是外在、五蕴身之外的物质世界，也不是对其他世间的诠释。

# 无为法

佛陀在《相应部·无为经》中说："什么是无为（asaṅkhatā）？诸比库，贪的灭尽，嗔的灭尽，痴的灭尽，诸比库，这称为无为。"《相应部复注》中说：""无为"即没有造作的因缘，因此称为'无作'（akatā）。"人们总是以有为的思维去想象无为，把无为法描绘为一种虚无缥缈，或者高深莫测的状态。不管说的多玄妙，能描述的都是有为法。无为法也称为"无作"，即贪嗔痴的灭尽。贪、嗔、痴是三个造业的因，当贪灭、嗔灭、痴灭时造业的因就不存在，就不会有造作、不会造业，这称为"无作"。当贪嗔痴的灭尽时，涅槃在阿拉汉的心中彻底显现。

涅槃是无为法，经由道智而被证得，是种姓心、道心、果心的所缘。很多人把涅槃想象为不可体验、不可经验、不可言说的；不可言说是对的，但它不是不可经验的，然而只有成为圣者才能真正体验到涅槃。一位证得缘摄受智的禅修者在观察未来生时，也必须观察到烦恼灭尽、五蕴无余灭尽——一般涅槃。涅槃的本质是贪嗔痴的灭尽。我们在理解涅槃的时候，不要被出世间、种姓、道心、果心等名相吓到，好像是要进入另外一个跟自己不相关的世界和空间，变成不存在了。举例而言，阿拉汉在有余涅槃的时候，就是贪嗔痴灭尽的状态。

# 究竟法及其自相与共相

究竟法是已分析到最终属性的真实存在的法，包括色法、心法、心所法、涅槃法。究竟法不再是一个组合，它不可再分，依自性而存在。自性的巴利语是 sabhāva，自性相的巴利语是 sabhāva-lakkhaṇa，特指究竟法的自性相。

Sabhāva 所指的自性跟梵语 Prakṛti 的自性不是同一个概念。梵语 Prakṛti，婆罗门教的数论派指它为世界最初的根本因，是一种处于未显状态的原初物质，人事物皆由它演化而来，且最后回归于它。所谓的"本初佛"可能也是从它演变而来的。

巴利语 sabhāva 所指的自性是什么呢？究竟法的自性包括自相与共相。自相（salakkhaṇa）是指任何一个刹那生灭的究竟法，在住时都会表现出自己的特相，例如地大的特相是硬、粗、重、软、滑、轻，嫉心所的特相是嫉羡他人的成就。每一个不可再分的究竟法其特性都不一样，都是独特的，由此我们才能分别诸法。共相（sāmañña-lakkhaṇa）是指一切有为法的共有特相——无常、苦、无我。

有一点需要厘清的是，佛法所说的不可再分的究竟法跟科学上分析物质直到不可再分的微粒并不相同，原则上不能把两者相提并论……（原文此处以"科学细分物质至夸克"与"佛法破除组合密集、作用密集、相续密集、所缘密集"对照展开，详见原文，此处不逐字重录以免与后文重复。）

从阿毗达摩的角度来看，色聚由色法组成。色法包括四大及其二十四种所造色，它们是地、水、火、风、颜色、香、味、食素，加上声音、男根、女根、命根、心色、五种净色（眼净色、耳净色、鼻净色、舌净色、身净色），以及其他十种非完成色，共有二十八种色法。这些都是不可再分的究竟法。

名聚由一个心识与若干心所组成。以贪心为例，我们可以把贪心这个名聚比作一个香菇豆干包……贪心这个名聚里面有什么呢？有一个心识，还有若干个心所——触、受、想、思等通一切心心所以及贪、痴、掉举、无惭、无愧等不善心所，它们每一种都有自己独有的自相，都是不可再分的究竟法。

然而，不管是哪一种究竟法，也不管是它们的自相还是共相，它们都有一个共同的特点：可以被体验……以修习身念处为例，身体的触觉是什么？就是对地、火、风三种触所缘的觉受，硬、软是地大的特相，支持、推动是风大的特相，冷、热是火大的特相，这些都是对究竟法的体验。

总而言之，佛法不是形而上学的，佛法不是虚无缥缈的，佛法也不是一种哲学的假设、思辨，一切诸法都是可以经验的。我们要去体验它、觉知它、观察它，看到它的自相和共相（涅槃不具共相），看到生命的真相。

# 有所缘的法与无所缘的法

其他几个相关的概念比较简单。"有所缘的法"指的是名法；"无所缘的法"指的是色法与无为界——涅槃，色法和涅槃都可以成为名法的所缘，但唯有种姓心以及出世间道心、果心能取涅槃为所缘。

# 二、缘起法与发趣法

佛法研究的核心内容是：心和目标的关系。目标无外乎颜色、声、香、味、触、法六外处。这些除了概念指的都是究竟法……根本而言，佛法关注的是蕴、处、界、根、谛、缘，而非外在千变万化的世界。所以，虽然阿毗达摩对研究宇宙的万事万物具有指导意义，但它的主要内容是关于五蕴、十二处、十八界、二十二根、四圣谛、十二缘起支和二十四缘。

缘（paccaya）可分为两种，即：缘起法与发趣法（二十四缘）。缘起法主要指十二支缘起；发趣法则依诸缘的特有支助力而说。它们之间的差别在哪里呢？

- 十二处：内六处——眼根、耳根、鼻根、舌根、身根、意根；外六处——色、声、香、味、触、法
- 十八界：六识——眼识界、耳识界、鼻识界、舌识界、身识界、意识界；六根——眼界、耳界、鼻界、舌界、身界、意界；六尘——色界、声界、香界、味界、触界、法界

对缘起法最概括的描述是"此有故彼有，此生故彼生；此无故彼无，此灭故彼灭"。通俗地说，即因为某一法存在，另一法就生起；因为某一法不存在，另一法就灭去——纯粹只是前者引发后者。以"无明缘行"为例，因为"无明"存在，"行"生起、存在，这是对"无明缘行"这一真实存在之现象的描述。

发趣法是什么呢？它对此作更进一步的细化。举例而言，"无明缘行"——缘于某一法而另一法生起，它们之间存在一种力量，这称为"缘力"。也就是说，"缘法"潜藏着一种特别的力量，而这种力量可以使"缘所生法"生起、存续，对此过程的描述属于发趣法研究的内容。

另外，缘起主要阐释三世轮回、三轮转（果报轮转、业轮转、烦恼轮转）、三时二十行相（三时以及过去五因和现在五果、现在五因和未来五果这二十行相）等，是解释生命的轮转与解脱的体系。

发趣法则着重于从结生到死亡的这一期生命流上看所有名色生起的缘和缘力。当然，一期生命相续流从结生到死亡，还牵涉到过去的缘，例如异刹那业缘、自然亲依止缘、无间缘、等无间缘，但是发趣法的主要研究对象落在当下这一生，从结生到死亡，所有名色生起背后的缘和缘力。所有可能的生命从结生到死亡心生起，这两者之间的整个名色相续流细分下来只是八十九种心、五十二种心所，再加上二十八种色法。这些名和色是怎么生起的，依靠什么样的力量而生起，这些力量是由哪一些缘法提供的，这是发趣法要解释的内容。

# 缘法、缘所生法与缘力

在二十四缘发趣法中，"缘法""缘所生法""缘力"是三个很重要的概念。简言之，"缘法"指实际的因；"缘所生法"指实际的果：只要前者住立，后者必定生起。"缘力"有三种作用，即产生（janaka）、支持（upatthambhaka）与维持（anupālana），借由它们所特有的力用而令因法与果法相关联。具体来看：

一. 缘法（paccaya-dhamma）：指果法所依赖的因法，若没有它，该果法就不存在。
- 缘法包括了阿毗达摩所涉及的一切法——心法、心所法、色法、涅槃和概念。

二. 缘所生法（paccayuppanna-dhamma）：指由因法所造成的果法。依赖众缘而生起的诸法，它们借由缘法所提供的支助而生起及存续。缘所生法只能是心法、心所法和色法，或者说名色，它不会是涅槃和概念。涅槃不是因缘和合而生的；概念是假合、是施设，不是真实的。换言之，心、心所和色法既可以作为缘法，也可以作为缘所生法，而涅槃和概念只能作为缘法。

三. 缘力（paccaya-satti）：指具有产生或完成的力量者。如前所述，缘力有三种作用，即产生、支持或维持。"产生"指的是缘法缘助缘所生法生起，例如无间缘、依处前生缘、异刹那业缘；"支持"指的是缘法缘助缘所生法逐渐发展、成长，例如后生缘；"维持"指的是缘法缘助缘缘所生法继续存在，例如色命根缘。

犹如辣椒的辣是它本身所固有的，并不能独立于它之外而存在；又如糖的甜是它本身所固有的，不能独立于它之外而存在；同样地，缘力是缘法所固有的，不能独立于缘法而存在。以因缘为例，缘力是作为六因之一的贪所固有的，它不能独立于贪之外而存在。在此，缘法是贪，贪的缘力也是贪。因此，不能认为缘力与具有该力量的缘法是各自独立存在的。不过，亦应谨记，一种缘法可以具有许多种缘力，例如作为因缘缘法的无痴，也是增上缘、俱生缘、相互缘、依止缘、果报缘、根缘、道缘、相应缘、不相应缘、有缘与不离去缘的缘法。

二十四缘有能力作为一种力量去完成缘的作用，它诠释了缘法如何以其特定的方式作为缘所生法的缘来发挥产生、支持或维持的作用。或者说，缘力显示了缘法与缘所生法如何彼此关联。

总而言之，缘力隐藏在缘法中，好比苦瓜的苦性潜藏在苦瓜中；或者说缘力是缘法本身所特有的一种力量，它能够产生、支持或维持缘所生法的生起或存续，这样的力量称为缘力。

历代论师，不管是阿耨楼陀尊者还是雷迪西亚多都对二十四缘进行了再分。然而，二十四缘即使在细分为五十四缘之后，我们依然会发现还有很多的力没有归纳进去，这些最后都被归为自然亲依止缘；也就是说，二十四缘或者五十四缘所不能够包括的其他一切缘力，都归在自然亲依止缘下面。所以，自然亲依止缘是二十四缘里涵盖内容最为广泛的。

如果没有老师的讲解，我们可能会觉得二十四缘极为复杂、让人头疼。实际上并非如此。我们念诵广释的时候可能已经发现，有许多缘很类似，例如无间缘和等无间缘，俱生缘和相互缘，有缘和不离去缘，无有缘和离去缘，它们看起来几乎没有什么差别。我们一一学习后会逐步把它们分组，分成六组或九组。把二十四缘分组后就不复杂了，只是涉及的内容比较多而已……只要我们循序渐进地学习，二十四缘并不难。

学习二十四缘最大的价值在哪里呢？学习后我们会明白，在日常生活中，我们这个五蕴身内有各种名色生起来，这些名色是依于什么缘生起的，这些缘有哪些力量，怎么去回避可能导致不善的缘故所生法生起的那些缘，怎么观察到缘力在我们身心里面的运作，然后去调整它。这就是我们学习二十四缘的价值所在。如果只是把它背下来，当作一组名相，那就可惜了。

我们将按照二十四缘的次第进行学习，期间再逐步学习把各种缘分组和串起来分析。

# 五、我们该如何做？

落到日常修习上，（冰山上层）既然外面的表现是生老死愁悲苦忧恼，受不善寻的反应模式所决定。不善寻的行为反应模式是因为有执取，执取是因为有爱，爱是因为有受，受是因为有触，触食因为你寻找生命的四食，寻找生命的四食是因为有无明。

# 二、什么是缘起

## （一）缘起三要素（十二缘起）

（导图：无明→缘法；无明通过诸缘涉及十七种→缘力；→对诸行（福行、非福行、不动行）→缘生法。）

无论是十二缘起支还是二十四缘，缘起都有三要素：缘法、缘力和缘所生法。以十二缘起"无明缘行"为例，在"无明缘行，即因为无明这种缘，而有行的结果生起"这句话中：

无明是因，即缘法；行是果，即缘生法。这个因导致果生起，在这里涉及二十四缘中的十七种缘。无明有十七种力量导致相关的诸行生起、维持或支持它。对因法，我们称之为缘法；对果法，我们称之为缘生法。

无明：归为三要素中的缘法，也就是原因、支持条件等因法；
诸行：归为三要素中的缘生法，也就是在那些条件的支持下所产生的结果，也可以说是果法；
诸缘：经教法中并没有提及缘力，论教法提到每一种缘法都有特定的缘力，也就是缘法是通过缘力作用的。

## （二）什么是缘起

什么是缘起？缘起即是缘的法，即缘法。缘法指果法所依赖的因法，若没有它，该果法就不存在。

因为无明——因法，而行——果法会生起来。这个行所依赖的是无明。如果没有无明，行不会生起。

举个简单的例子，你今天生气了。生气是一种非福行……生气是因为无明……行是因为有这个无明才生起来的。这非常重要，它涉及到佛法的一个根本思想。世间人总是从结果上去追求、从结果上去判断、从结果上去期待，以及对结果有恐惧，而佛陀教导所有的结果都是从原因开始的，着重点要放在因上。核心点是因，强调一切都要从缘起上来看。

## （三）缘起的特相、作用、现起

"缘起"是以老死等诸法的缘为特相，有与苦结合的作用，邪道（轮回）是它的现状。

1. 缘起的特相（本质）："缘起"是以老死等诸法的缘为特相。比如"无明缘行"，十二缘起支从行一直到老死，都是从结果的角度来讲。对于行，它的因是无明。"无明缘行"是因为无明这个因存在，才有行生起。从因的角度上看，有无明，行就会生起。缘起从因的角度上看结果。从无明到生都可以作为因法，行一直到老死都可以作为果法。

## （四）缘起&缘生的差别

缘法就是缘起。缘生法就是结果。缘起和缘生的差别在哪儿？《清净之道》中解释："缘起"者，即缘法（paccayadhamma，因缘条件）。"缘生法"是由于那些缘而生起之法。

缘起是对老、死等法的缘，即会生起缘生法的缘。从"无明一直到生"作为缘起的因法（缘法），会导致从"行一直到老死"的果法（缘所生法）生起。前面的因法针对于后面的果法来讲，称为缘起或缘法。缘生（paṭicca+samuppanna），是由于那些缘而生起之法——果。当知老死等为"缘生法"。

# 三、缘的性质和作用

## （一）缘起的性质

依《清净之道》，缘起的性质有四种，即如性（tathatā）、不违如性（avitathatā）、不他性（anaññathatā）和此缘性（idappaccayatā）。

1. 如性 tathatā：如性是指此[缘起]由于以这些不多不少的缘而有那些法的生起。tathatā 意为如此、如实、事实、真实。注疏解释，通过那些缘果能够生起，只要通过那些完整无缺的缘其（果）就能生起；而且，借由（除此之外的）其他[缘]，是不具有因果匹配性的。故说"不多不少"。如同因为眼、颜色、光和作意，而有眼识的[生起]。阿毗达摩中眼识的生起需要四种条件：眼净色，对象的颜色，光，和作意。条件具足，就可以生起眼识。这四个条件是不多不少的。

2. 不违如性 avitathatā：由于在[诸缘]结合之时，即使是瞬间，源于此而生之诸法的不生起是不存在的。只要我看向这个摄像机，而且周围有光，就一定会生起眼识……只要这些缘这么聚合，就不会违背现实、背离事实，就一定产生这样的事实，是不可避免的必然性。

3. 不他性 anaññathatā：由于不能以某一种法的缘而生起另一种法，故有不他性。无明缘行：无明这种缘法导向的就是行的生起。无明不会直接作用使触、六处、名色生起。识只会导致名色生起，名色只会导致六处生起，六处只会导致触生起……因和果具有对应性，不会是矛盾的。

4. 此缘性 idappaccayatā：由于上述这些老、死等的缘，或者由于缘的聚合。无明导致行生起……生缘老死等，缘法导致缘所生法生起，就是这样的缘性。不是眼净色、照相机的颜色、你的作意、灯光，我给你凑一下，让你生起一个眼识，而是只要因缘具足眼识就会生起，这就是此缘性。这样的发生没有一个"我"在里面指使。此缘性的核心就是要破一个"我"，其核心是"无我"，没有一个"我"在聚合。

# 二十四缘的缘起三要素说明

眼识要生起一定要有四个要素，现在选其中一个要素。眼睛要看得见就需要眼净色（眼处）。眼处是眼识生起的缘法。眼识依止眼净色（眼处）才能生起，眼处对眼识生起有依止缘的缘力。眼处是缘法，眼识是缘生法，眼处通过依止缘的缘力支持眼识生起。

这就到了一个很微观的状态。眼识是一个心识刹那……缘力不作为观智的所缘，佛弟子只能去感受缘力，这是佛陀的智慧范畴。但在观智的状态，你知道有这么多缘，是可以感知和标记这些缘的作用的，但看不清楚它。

二十四缘的三要素：缘法、缘所生法和缘力。缘法和缘力之间的关系是什么呢？举个简单的例子，辣椒具有辣的特性，辣就是辣椒的缘力。辣椒这个缘法有一种缘力就是辣，你吃它就会导致舌头火辣辣的（缘所生法）。缘力是蕴藏在缘法里本有的一种属性、特性。辣椒、舌净色、水分等相关因缘聚合的时候，辣性发生作用就会导致辣舌的缘所生法生起来。

缘法、缘所生法和缘力符合缘起的四种性：如性、不违如性、不他性和此缘性。从宏观的角度来说，这是一切世间运作的基本规律。

无论是外在的物质，还是内在的精神都是因缘所生法，有此因就有果。

那么这对我们有什么价值呢？我们的生活、工作、学习、身体、修行都有如性、不违如性、不他性、此缘性的规律。比如出家人想导向涅槃，想证得道智果智。要获得这个缘所生法，就要依着戒定慧规律，找到导致道智生起的缘法，以及通过什么样的缘力才能导向它。解决一切事情都是用这样的方法。

学习缘起的核心点就是一切都要从因出发。懂得去观察因，懂得去分析因，懂得去运用因。在结果出现的时候，接受这个结果，分析导致结果的因。对于修行人来讲，就是在因上努力，让结果朝向与趣向涅槃之道相符的方向，而非相反的行道。作为一个修行人如果能把握佛陀的因缘的方法就能够把握好生命。祝福大家生活能越来越好，祝福所有修行者都能早日证悟涅槃！
