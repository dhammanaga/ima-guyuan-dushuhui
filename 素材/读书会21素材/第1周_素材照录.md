# 善的四种核心素质

# 无病的 (Aroga)

内心没有苦患、烦恼的侵扰，如同身体无病般健康、清净，远离内心的“病痛”。

# ◆ 无罪的 (Anavajja)

行为与心念清净无染，没有过失和愧疚，或对罪恶的彻底断除，身口意行皆清净。

# ◆ 乐果报的 (Sampattisampada)

善的行为种下善业的种子，时机成熟便会收获幸福的果实，体现因果法则的自然运作。

善的本质带来智慧与善巧，不仅是道德的，更是智慧的，能让人明辨是非，行事恰当。

# “善巧收割”的隐喻

阐明了对“善”的理解：

1) 效用与潜力

如吉祥草正确使用时的物质价值，布施、持戒等善法实为道业发展的利器。

2) 无知之险

若无智慧，这些善行可能沦为表演或染污。例如：出于傲慢、执着或求赞的布施，实已掺杂不善(akusala)。

由此得出根本教理洞见:善法的真实性取决于正见(sammā-diṭṭhi)的存在与无痴。决定其伦理本质的，非行为本身，而是背后的动机、清明与智慧。

# 佛教中的不善

## 佛教中“不善”的哲学观

在佛教中，“不善”（akusala）一词——通常译为“不净”“不善巧”或“有染污”——其意义远超道德过失或伦理失败。它代表一种根植于三不善根（贪、嗔、痴）的心识染污状态，这些烦恼扭曲认知、毒害意志，并延续轮回（生死与苦）。

# 三不善根

# 一切不善法的根基在于三根本烦恼：

# (1) 贪 (lobha)

对物、人、见解或经验的强迫性占有欲

实例如：贪婪、感官欲求、傲慢驱动的野心、身份认同的执取

# (2) 嗔 (dosa)

对逆境的排斥、毁坏或疏离冲动

实例如：愤怒、怨恨、残忍、偏狭、义愤

# (3) 痴 (moha)

无明的根本：不解四圣谛、无常、无我或业力法则

实例如：困惑、疑、自欺、邪见。《阿毗达摩》中，这三根生起十二不善心，各伴随特定染污心所。

实例如：贪根心总与慢、邪见或执取相应；嗔根心必含愤怒与忧受；痴根心则与疑、掉举俱生。

# 三不善根

# 一切不善法的根基在于三根本烦恼：

# (1) 贪 (lobha)

对物、人、见解或经验的强迫性占有欲

实例如：贪婪、感官欲求、傲慢驱动的野心、身份认同的执取

# (2) 嗔 (dosa)

对逆境的排斥、毁坏或疏离冲动

实例如：愤怒、怨恨、残忍、偏狭、义愤

# (3) 痴 (moha)

无明的根本：不解四圣谛、无常、无我或业力法则

实例如：困惑、疑、自欺、邪见。《阿毗达摩》中，这三根生起十二不善心，各伴随特定染污心所。

实例如：贪根心总与慢、邪见或执取相应；嗔根心必含愤怒与忧受；痴根心则与疑、掉举俱生。

# 不善的特质

◆ 1) 无明主导

◆ 2) 动机出于自私而非利他或法随法行

◆ 3) 导致心扰动、追悔，与善心的宁静相反

◆ 4) 破坏定力，令觉知支离破碎

◆ 5) 障碍观智生起，因其遮蔽无常、苦、无我

四、近因 (Padaṭṭhāna)，它直接依靠的近缘。
