# 止观堂读书会 · 资料仓库

> 依据「古源尊者开示及上座部佛教资料」整理的一套**系列共读（读书会）资料包**。
> 共 **25 个独立主题**，每个主题含 **4 周版与 8 周版**；每周 1 次、每次 2 小时（六环节 120 分钟）；分 **主持人版 / 学员版**。主持人无需专业背景，照本即可带读。

---

## 一、目录结构

| 目录 | 内容 |
|---|---|
| `交付成果/` | 各轮**成品资料包**（第一轮初稿 → 第二轮修订 → 第三轮修订 → 第4轮朗读优化） |
| `素材/` | 各系列**制作素材**（`读书会04素材` … `读书会25素材`：素材照录、制作蓝图、规范、脚本） |
| `文档/` | **项目文档**：`总览/`、`需求与方案/`、`规范与手册/`、`执行与修订记录/`、`运行与守护/` |
| `脚本/` | 制作与校订**流水线脚本**（`_*.py`、`_thirdround_titles.json`、`watchdog_template.sh`） |
| `原始文档/` | 原始资料 |
| `审核工作区/` | 审核过程工作区 |

> 完整的读书会一览见 `文档/总览/`。
