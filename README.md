## 一、这个仓库是什么

基于 ima.copilot 知识库 **「古源尊者开示及上座部佛教资料」**（kb_id：`gUS_F0u-c-s03vZz9iozILn4CNDWZ1X3ireb8fXHIRc=`），把古源尊者的真实开示，逐句照录整理为**可直接开班使用的读书会共读资料包**。

- **规模**：**25 个系列 × 8 周 = 200 个教学周**，每个系列产出「双版本 × 8 周 ＋ 汇总 4 份」= **20 份文档**，累计约 **500 份 Markdown 文档** ＋ 各系列 zip 包。
- **纪律**：所有共读原文**逐字照录**知识库真实内容，禁止改写、缩写、虚构；每份引用均标注真实 `media_id` 与打开方式。
- **质量门槛**：程序化终检**硬性 0 失败**（双版本齐全、共读原文逐字一致、无临时链接、无禁用命中）。

## 五、如何取用（阅读路径建议）

1. **要使用某个系列** → 打开 `交付成果/读书会NN_…_8周资料包/`，主持人读 `00_主持人总指南.md` ＋ 对应周 `_主持人版.md`；学员用 `_学员版.md`。

4. **要开工新系列** → 读《读书会资料包制作规范总纲》＋《启动提示词 v2.0》＋《任务需求文档》最新版 ＋《守护协议》。
5. **要理解某类文件** → 见本文第三节。

## 六、命名与时间戳规范

- **对外交付文件名**：`文件名_YYYYMMDD_HHMM_vX.Y.扩展名`（北京时间；首次 v1.0，内容小改 v1.1，结构性更新 v2.0）；zip 同规则。
- **文档头部**：`> 📅 **最近更新**：YYYY-MM-DD HH:MM　|　更新内容摘要`；文末维护"更新记录"表；资料包整体维护 CHANGELOG。
- **文件名禁用半角 `/`**（会误建子目录），一律用全角 `／`。
- **沙箱时区为 UTC**，展示与文件名一律换算为北京时间为准（`TZ='Asia/Shanghai' date`）。
