## 二、适用范围与产物位置

1. **产物目录**：每个资料包内固定建 `Word版/`，docx 与 md **同名同数**（除跳过项）。
2. **命名**：`第N周_{周标题}_主持人版.docx`／`_学员版.docx`；`00_主持人总指南.docx`；`原文全集.docx`；附表按 md 原名。
3. **打包**：在资料包根目录生成 `{资料包名}_Word版_YYYYMMDD_HHMM_vX.Y.zip`，zip 内层目录为 `Word版/`。
4. **版本号**：与当轮 md 同版本（如 `v1.0`、`v3.9`）；时间戳取生成时刻（北京时间，`TZ=Asia/Shanghai`）。

> ⚠️ 取源纪律：重出 Word 时**必须从最新轮次的 md 取源**（当前最新轮次＝`交付成果/第八轮去禅修引导/…（第8版）`），不得拿旧轮次（第5/6/7版）md 转 Word；转换前先确认目标目录是否为最新轮次。

## 四、版式基准（页面与正文）

```
纸张：A4 纵向 21.0 × 29.7 cm
边距：上 2.00 / 下 2.00 / 左 2.00 / 右 2.00 cm
Normal 样式：西文 等线（DengXian），中文 eastAsia 宋体，10.5 pt
段落：单倍行距（不设 line_spacing），无首行缩进，段前段后不设
分节：单节（全篇 1 节），不分栏、不加封面页、不生成目录
```

实现要点（python-docx）：

```python
sec.page_width, sec.page_height = Cm(21), Cm(29.7)
for m in ("left_margin", "right_margin", "top_margin", "bottom_margin"):
    setattr(sec, m, Cm(2))
st = doc.styles["Normal"]; st.font.name = "等线"; st.font.size = Pt(10.5)
st.element.rPr.rFonts.set(qn("w:eastAsia"), "宋体")
```

## 六、标题层级映射（md → docx）

| md 标记 | docx 呈现 | 备注 |
|---|---|---|
| 文档**首个** `# 第N周：…（主持人版）` | 18 pt 加粗居中主题色 | **去掉**「（主持人版）」「（学员版）」后缀；`# ` 前缀不显示 |
| 其余 `# …`（多出现在共读材料内部小节） | 15 pt 加粗主题色左对齐，段前 10 pt | 实测读书会13 共读节内 18 处 |
| `## …`（环节标题，如 `📋 本周信息卡`） | 13 pt 加粗主题色 | 保留 emoji 与全角括号 |
| `### …`（如 `原文材料①…`、`练习一`、`收尾一`） | 11.5 pt 加粗主题色 | — |
| `#### …` 及更深 | 11.5 pt 加粗主题色 | 与三级同号 |
| 无 `#` 的加粗行 `**…**` | 10.5 pt 正文加粗 | 段内 `**` 分段处理，其余部分不加粗 |

要点：标题一律**不用** Word 内置 Heading 1/2/3 样式，而是普通段落 + 手动字号/加粗/颜色（保证目录、导航行为一致且不引入额外样式）。

## 七、页眉与页脚

**页眉**（居中，8 pt，主题色）：

```
读书会NN · 第N周 · {轮次版本}（4周版） · 主持人版
读书会NN · 第N周 · {轮次版本}（4周版） · 学员版
读书会NN · 第N周 · {轮次版本}（8周版） · 主持人版
读书会NN · 主持人总指南 · {轮次版本}（4周版）
```

- `{轮次版本}` 随产物轮次填写，如「第三版修订」「朗读优化版」。
- 实测样例：`读书会05 · 第1周 · 朗读优化版（4周版） · 主持人版`；`读书会13 · 第1周 · 朗读优化版（4周版） · 主持人版`。
- 分隔符统一半角空格＋`·`＋半角空格。

**页脚**：居中插入 `PAGE` 域（`w:fldChar begin` + `w:instrText PAGE` + `w:fldChar end`），只到页码数字；不加「第…页」「共…页」文字，**不插 NUMPAGES 域**。

```python
f1 = OxmlElement("w:fldChar"); f1.set(qn("w:fldCharType"), "begin")
it = OxmlElement("w:instrText"); it.set(qn("xml:space"), "preserve"); it.text = "PAGE"
f2 = OxmlElement("w:fldChar"); f2.set(qn("w:fldCharType"), "end")
r._r.append(f1); r._r.append(it); r._r.append(f2)
```

> 已知例外：读书会19 第2–4 周等少数 docx 为另一套旧精细版（页脚仅写「第  页」、无 PAGE 域），属历史遗留，重出时按本规则覆盖（见 §13）。

## 八、Markdown → Word 元素映射（逐项实现要点）

### 8.1 引用块 `> …`
- 连续的 `>` 行**逐行**转成独立段落（**不合并成一段**）。
- 每段：左缩进 0.3 cm；左侧竖线 `w:pBdr/w:left`（`w:val="single"`、`w:sz="18"`、`w:space="4"`、`w:color=` 主题色）；段落底纹 `w:shd w:fill="F2F5FA"`。
- 纯 `>` 空行跳过，不产生空段。
- 块内 `**加粗**` 照常处理。

### 8.2 表格
- 识别 `|` 开头且下一行为 `|---|:--:|---|` 分隔行的块。
- **引用块内嵌表格必须单独识别**：md 中存在 `> | 环节 | 标准时长 | … |` 形式（如「⏱ 时间弹性指南」表整张写在引用块内）。解析时先剥掉行首 `>` 再判表格，转为**普通表格**（不套引用框底纹）；不得把 `> |` 行当引用正文逐行输出（否则 docx 里残留 `| 环节 | 标准时长 | … |` 与 `|:-----|:----:|` 分隔行）。实测：第四轮读书会05 第1周主持人版 docx 有 4 张表（含此表），说明现行流程已按此处理。
- 丢弃分隔行；表头＝第一行。
- `Table Grid` 样式；所有单元格 9 pt；表头白字＋主题色底纹；第 2、4、6… 数据行底纹 `F2F5FA`（隔行浅底）。
- 单元格内 `**加粗**` 保留加粗。

### 8.3 列表
- `- ` / `* ` → `List Bullet` 样式段落，去掉前缀。
- `1. ` / `2. ` → `List Number` 样式段落，**去掉原编号**（避免「1. 1.」双编号）。
- 列表项内 `**加粗**` 照常处理。

### 8.4 内联标记
| md | docx |
|---|---|
| `**文字**` | 加粗 run |
| `` `文字` `` | 去掉反引号，保留文字（不设等宽字体） |
| `<br>`（表格内换行） | 转空格 |
| 全角标点 | 原样保留（不得转半角） |

### 8.5 时间戳行
`<div align="right">📅 最近更新：…</div>` → 右对齐、8 pt、灰色 `#888888`，仅保留 div 内文字。

### 8.6 丢弃项
- `---`、`***` 分隔线：整行丢弃，不产生段落、不产生空行。
- HTML 注释 `<!--EXT_READ-->`／`<!--/EXT_READ-->`：丢弃。
- 空行：不产生段落（Word 段落间距由样式控制，不靠空行排版）。

### 8.7 图片
- 现行为**不嵌入**：md 中的 `<img>`／`![]()` 一律不转图，`word/media/` 为空（第四轮全量实测 media=0）。
- 课件原图通过资料包内 `课件原图/` 目录随包提供，投屏时另开图片；`🖼 课件原图（源 PDF 渲染·供投屏）` 节保留文字说明即可。

## 十、维护约定（何时必须重出 Word）

1. **默认不随 md 更新**：`CHANGELOG` 中已多处登记「Word／zip 按维护约定默认不随 md 更新」——即 md 内容修订（错字、术语、周次、环节调整）时，**不自动重出 Word**，只交付 md。
2. **必须重出的三种情形**：
   - 用户／尊者明确指示「重出 Word」或「出一版 Word」；
   - 进入新一轮交付（如「第四轮朗读优化版」需整轮含 md+Word+zip）；
   - 结构性变更使既有 Word 无法使用（环节增删导致页码/表格错位、配色换版）。
3. **重出时的口径**：取源＝最新轮次 md（§2 取源纪律）；样式＝本规则；完成后同批交付 `Word版/` ＋ Word 包 zip，并在 CHANGELOG 登记「重出 Word：轮次/版本/份数」。
4. **一致性自检**：重出后 md 与 docx 的周标题、环节标题、表格数量应逐一对齐（见 §11）。
