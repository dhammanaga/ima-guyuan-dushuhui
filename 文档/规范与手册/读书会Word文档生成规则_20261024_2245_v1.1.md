## 一、字体方案（避免缺字提示的关键）

| 用途 | 字体 |
|---|---|
| 正文中文 | 宋体（SimSun） |
| 正文西文/数字 | Times New Roman |
| 标题（首行、各级） | 微软雅黑（Microsoft YaHei） |
| 列表符号 | Symbol / Courier（Word 内建，系统自带） |

生成后必须做「主题字体清理」：把 `word/theme/theme1.xml` 的 majorFont 改为微软雅黑、minorFont 改为 Times New Roman＋宋体，并删除 `<a:font script="…" typeface="…"/>` 其他语言字体条目。成品 docx 内出现的字体名应只有：`宋体`、`Times New Roman`、`微软雅黑`、`Symbol`、`Courier`——出现「等线／DengXian」即为未清理。

## 二、版式基准

```
纸张 A4 21.0 × 29.7 cm；页边距 上下 2.0 cm／左右 2.2 cm
页眉距边界 1.2 cm；页脚距边界 1.2 cm
Normal：西文 Times New Roman ＋ 中文 宋体，10.5 pt，行距 1.4，段后 5 pt
正文：两端对齐，无首行缩进
分节：单节，无封面页、无目录
```

## 五、页眉页脚

页眉（居中 8.5pt 主题色，下细线）：

```
读书会NN · 第N周 · {轮次版本}（4周版|8周版） · 主持人版|学员版
读书会NN · 主持人总指南 · {轮次版本}（4周版|8周版）
```

页脚：居中 `PAGE` 域，前后加全角破折号，呈「— 3 —」；不设 NUMPAGES，不写「第 页」。

## 六、Markdown → Word 映射

1. **标题**：首个 `#` → 20pt 居中（去版本后缀）；其余 `#`→16、`##`→13.5、`###`/`####`→11.5，全部加粗主题色（不用内置 Heading 样式）。
2. **引用块 `>`**：逐行独立成段；左缩进 0.45cm、右 0.25cm；左侧竖线 `w:sz=30`（3.75pt）主题色；底纹 `#EEF3F9`；纯 `>` 行与 HTML 注释跳过。
3. **表格**：识别 `|…|` ＋ 分隔行 `|:--:|`；**引用块内嵌表格**（`> | … |`）须先剥 `>` 再转普通表格；`Table Grid`；按内容估算列宽（固定布局）；表头主题色底白字 10pt、跨页重复；数据行 9.5pt、首列加粗、隔行 `#EEF2F8`；表格后留半行空段。
4. **代码块 ` ``` `（知识地图）**：剥掉 `│ ├ └ ─ ┄ ┈` 与行首「·」；按前缀字符数 `//4` 定层级 0–4；顶层 10.5pt 加粗 `#1A1A1A`，子级 10pt `#333333`；左缩进 `0.35 + 0.55×层级` cm；行距 1.3；空行丢弃。
5. **列表**：`- `→`List Bullet`、`1. `→`List Number`（去原编号），左缩进 0.95cm、悬挂 −0.45cm。
6. **时间戳**：`<div align="right">…</div>` → 右对齐 8pt `#888888`，段后 6pt。
7. **丢弃**：`---`、`***`、`___`、HTML 注释 `<!--EXT_READ-->`、空行。
8. **图片**：不嵌入（`word/media` 为空）；课件原图随包另存「课件原图/」或 `素材图_*.png`。

## 九、维护约定

- **默认不随 md 更新**：md 修订不自动重出 Word。
- **必须重出**：①明确指令重出；②进入新一轮交付；③结构性变更（环节增删、换配色）。
- 取源：只认**最新轮次** md（当前＝第八轮（第8版）`精修4周版/`、`精修8周版/`）。
- 重出后新版本号、新时间戳另存，不覆盖旧 zip。
