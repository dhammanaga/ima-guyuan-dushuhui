## 一、任务定义与目标

把古源尊者的真实开示，整理为**可直接开班使用的读书会共读资料包**：每个系列固定 **8 周**，每周 **120 分钟**，约 10 人。产出 **双版本（主持人版＋学员版）× 8 周 ＋ 汇总 4 份 ＝ 20 份文档** ＋ 1 个 zip。

**三条不可动摇的底线**：
1. **照录不虚构**——共读原文逐字取自知识库真实内容，禁止改写、缩写、"润色"、拼接、编造；
2. **双版本共读原文逐字一致**——由脚本构造性保证，不靠人工核对；
3. **程序化终检硬性 0 失败**——不达标不交付。

## 四、内容标准

### 4.1 六条校对原则
① 确定主题 → ② 检索确定完整主题结构并拆分到 N 周 → ③ 按小主题收集组织内容 → ④ N 周完整覆盖全部内容框架 → ⑤ 每周内容完全符合当周主题 → ⑥ 校对各周内容无重复。

### 4.2 查重规则（v2.3 段落级口径，当前有效）
- **不同系列或同系列不同周，可以引用同一文件（同一 media_id），但不可引用相同段落或相同内容。**
- 选材前对照既有系列素材照录确认段落不重复；同文件共用须在**照录与周文档两处**注明「与读书会XX第X周同文件不同段落（本讲取〈章节名/时间码〉，彼讲取〈章节名/时间码〉）」。
- 既有《禁用清单》降为**参考工具**（非硬禁用）；清单只取**真实已用**（各 `读书会XX素材/第X周_素材照录.md` ＋ `交付成果/读书会XX_*资料包/**/*.md`），**排除**设计稿/确定稿/第四批等预留来源，防候选 id「自命中」。
- **并行开工前**各线推送 `_拟用id_读书会NN.txt` 互查，防同文件同章节撞段。
- 收尾必做**全库段落对撞**（脚本比对 md5），确保**内部跨周=0、跨系列=0**。

### 4.3 格式标准（与慈心禅读书会一致）
- 见第五节"双版本规范"与 `_体例契约_读书NN.md`。
- 长文档编辑：对 80KB+ 文档多处插入时，**用 python 脚本整文件读入/插入/写回**（`file_edit` 易触发尾部重复），写入后校验章节计数与行数。

## 五、双版本规范

### 5.1 主持人版章节骨架（顺序固定，详见各系列 `骨架样板.md`）
```
<div align="right">📅 最近更新：YYYY-MM-DD HH:MM　|　初版制作（v1.0）</div>

# 第X周：<周标题>（主持人版）

> ⭐ 本讲主持人速览（四列表：环节｜标准时长｜时间不够怎么办｜时间富余怎么办 ＋ 主持人 10 条守则精简版）
---
> **读书会NN：<系列名> · 第X周**（主持人导语 2–3 句）
> 本周主题：<一句话>
## 📋 本周信息卡（时长120min｜核心问题｜共读原文提要｜本周作业）
## ⏱ 时间弹性指南（本讲通用）
---
## 🧘 静心开场（10 min）
## 📖 共读原文（30 min）  ← 材料①★核心＋信息行＋⚠️主持人操作行＋逐字照录（材料②③同构）
## 💬 第一轮分享（25 min）
## 🎯 主题讨论（35 min）
## 🧘 禅修练习（15 min）
## 📚 扩展内容包（时间富余时使用）
## 🔚 收尾与回向（20 min）
## 📌 本讲主持人特别提醒（3–6 条；含心理安全指引）
---
<!--EXT_READ--> ## 📖 延伸阅读（表格｜材料｜出处｜media_id｜说明） <!--/EXT_READ-->
<!--W_LEAD--> （主持人开场提示语 1–3 句） <!--/W_LEAD-->
```
- 120 分钟时长**不得改动**：10/30/25/35/15/20。
- 主持人版 **≥30,000 字符**（用 `python3 -c "print(len(open('文件').read()))"` 核，**禁 `wc -c`**）；每周共读原文照录 **≥12,000 字符**。
- ⭐速览／⏱弹性／📌特别提醒三块须以**整行 `---`** 结尾（勿用 `> ---`）。
- 共读原文材料块在**主持人版用 `### 材料`（三级）**、在**素材照录用 `## 材料`（二级）**；两者不可混（见第十四节陷阱）。

### 5.2 共读原文材料信息行格式（每材料必含）
```
**材料①** ★核心：《<文件标题>》
- 文件类型：pdf/word/音声
- 知识库出处：古源尊者开示及上座部佛教资料
- media_id：`<完整id，原样整串复制>`
- 打开方式：ima知识库搜索「<标题关键词>」

⚠️ 主持人操作：<如何切分照录段落/跳读指示>
```

### 5.3 学员版
- **不由子代理写**；由 `_mk_student.py <主持人版.md>` 零 LLM 派生。
- 自动：删⭐速览/⏱弹性/📌特别提醒/⚠️主持人操作行；`W_LEAD` 转纯文本、`EXT_READ` 挪文末；换标题与引导标签。
- 终检额外核：学员版含「本周信息卡」与「读书会NN」导语行。

### 5.4 定界标记（脚本依赖，缺一返工）

| 标记 | 数量 | 位置 | 学员版行为 |
|---|---|---|---|
| `<!--W_LEAD-->…<!--/W_LEAD-->` | 1 对 | 文件末尾 | 还原为纯文本行 |
| `<!--EXT_READ-->…<!--/EXT_READ-->` | 1 对 | 特别提醒块之后 | 挪到文末 |
| ⭐速览／⏱弹性／📌特别提醒块 | 各 1 | 固定节 | 整块删除（须整行 `---` 结尾） |

> 必须为**英文半角**标记；防全角 `<！--` 致脚本失配（终检核 `s.count('<！--')==0`）。

## 七、素材照录规范

1. **media_id 纪律**：必须从检索/蓝图结果**原样整串复制**，严禁手工拆分/拼接/重排（曾因多一字符致整篇报废）。新 id 先以**完整串** `grep -F` 禁用清单，再写入。
2. **五要素**：标题／文件类型／知识库出处／media_id／打开方式。
3. **音声转写**：加「（依据录音转写整理，已校对明显同音错字）」，**保留时间码** `[00:00:00.000]`；正文括注（ ）内为整理注记，朗读时跳过。
4. **缺口如实注明**：fetch 返回 `[generated, not original text]` 照常使用**并保留标注**；PDF 图形页缺口、知识库缺档段**如实注明，禁止虚构补齐**。
5. **不放置临时链接**：一律用"知识库出处＋media_id＋打开方式"；扫 `https?://` 清零（页眉页脚 http 链接会触发终检硬失败）。
6. **材料块标题**：照录文件统一 `## 材料①…`（供 `_gen_yuanwenNN.py` 以 `^## 材料` 切分）。
7. **取段边界**：开工即给每周明确"取材时间码/章节边界"，防越界照录与跨周撞段。

## 八、子代理派发规范

- **每代理 1 周**，产出「素材照录＋主持人版」2 份；学员版留脚本。分批派发（每批 ≤4）。
- **模型分级**：主持人版写作＝**heavy**；素材调研/汇总聚合/终检修复＝**light**；学员版/原文全集/终检/打包/推送＝**脚本零 LLM**。
- **任务书 ≤500 字**，只写本周差异（周标题、素材表、锚点、特殊要求）；共同规则让代理读《骨架样板》《_体例契约》《_制作规范》。
- **报告 6 字段 ≤300 字**：文件路径／字数／media_id 数／标注情况／自检结果／异常。禁止过程叙述。
- **直接写盘**；每完成 1 周**即推 GitHub**防丢失。
- **自检前置**：产出后先程序化自检（字符数硬线／禁用 grep／定界标记／无全角）全部通过才报完成。
- 若派发被拦截（T2'）→ 先 `ls` 核盘：未执行→改**单发**或 light 诊断；已执行未回传（T3）→ 按现有产物收尾，勿盲目重派。

## 九、程序化终检标准（交付门槛）

`_qa_check.py <资料包目录>` **硬性校验**：
1. 双版本齐全（缺学员版 → 失败）；
2. 禁用清单命中（传 `--banned`/`QA_BANNED` 时）；
3. 无临时链接（`https?://`）；
4. **双版本「共读原文」实质原文行逐字一致**。

通过 `_pipelineNN.py` 一键执行：学员版生成 → 原文全集 → 终检 → 打包 → 推送。**退出码非 0 一律逐条修复后重跑，不得带病交付。**

> ⚠️ **终检必核**「共读原文**实质原文行=0**」计数：为 0 说明共读原文节被切空、比对为**真空假通过**（见第十四节）。

## 十一、多机协作与断点恢复

### 11.1 多机协作约定
1. **分工**：每系列归属一"线"（机），见《任务需求文档》第四节/第八节；本机禁动他线 `读书会XX素材/`、`交付成果/读书会XX_*/` 及推送文件。
2. **共享文件错峰更新**：《任务需求文档》为多机共享——更新前**先 GET 远端最新版合并再 PUT**（Contents API 整文件覆盖，直接推会抹掉他人进度）；进度行各机只改自己的。
3. **并行开工前**各线推 `_拟用id_读书会NN.txt` 互查。
4. **中断记录**：各机恢复动作各自记入《中断日志》，注明机别。

### 11.2 唤醒自检 SOP（每次新会话必做）
1. **查盘**：`ls /sandbox/workspace/新型读书会.大佛寺/第二轮/` 是否含《任务需求文档》；缺失→从 GitHub 恢复（见 11.4）。
2. **读状态**：读《任务需求文档》最新版 → 第四节进度表定位断点。
3. **查中断**：看《中断日志》最近一条 → 判断类型。
4. **核现场**：对应 `读书会XX素材/` 与《_制作蓝图》是否存在；蓝图在→按蓝图续做。
5. **续跑**：遵守高频持久化纪律（11.3）。
6. **记中断**：向《中断日志》追加记录。

### 11.3 高频持久化纪律（防丢失主防线）
每完成 1 份文档／1 周／1 系列 → **立即落盘并推 GitHub**（+ 系列完成时 zip＋更新任务文档＋更新记忆）。GitHub 是**唯一可信持久层**（沙箱容器会被平台回收）。

### 11.4 恢复工具与网络注意
- `python3 _restore_workspace.py`（zipball 一键恢复）。
- **git 协议在沙箱不可达**（clone 报错），一律走 **Contents API / zipball**。
- zipball 截断率高：先 `unzip -t` 校验；不通过改走 **git trees API（`/git/trees/{sha}?recursive=1`）＋ blobs API（`/git/blobs/{sha}`）并行下载**（多线程＋重试）。
- **中断类型学**：T1 容器回收／T2 策略拦截／T2' 派发额度拦截／T3 orphan（插话致结果丢失）／T4 超时网络／T5 token 不足。T3/T5 一律**先 ls 核盘**再决定是否重派。

## 十二、Token 优化八条（08 起必执行）

1. **骨架样板替代全文样板**（≤4KB，替代 80KB）。
2. **任务书只写本周差异**（≤500 字）。
3. **机械步骤一键流水线**（`_pipelineNN.py` 合并学员版/原文全集/终检/打包/推送）。
4. **素材调研下沉**（主线程仅 2–3 次 search；细粒度素材由周代理自选）。
5. **子代理报告定额**（6 字段 ≤300 字）。
6. **轻重模型分层**（heavy 写作／light 机械／脚本零 LLM）。
7. **单系列单会话**（系列间不续聊，系列内少插话防 orphan）。
8. **跨系列复用沉淀**（规范/脚本/流水线/样板模板化，每系列只改系列号）。

## 十三、已知陷阱与规避（历系列教训汇总）

| # | 陷阱 | 规避 |
|---|---|---|
| 1 | 主持人版材料块误写 `## 材料`（二级）→ 共读原文节被 `^## ` 切空、**终检真空假通过** | 主持人版用 `### 材料`；终检必核「实质原文行=0」 |
| 2 | 定界标记误写全角 `<！--` → 脚本失配、学员版残留标记 | 用英文半角；终检核 `count('<！--')==0` |
| 3 | 速览/弹性/提醒块以 `> ---` 结尾 → `_mk_student` 过度删除（丢信息卡/弹性指南） | 三块以**整行 `---`** 结尾 |
| 4 | 课件页眉页脚 http 链接 → 终检链接项硬失败 | 照录前扫 `https?://` 清零 |
| 5 | 子代理自填的"北京时间"头部时间戳偏差 | 终检用 `TZ='Asia/Shanghai' date` 校正 |
| 6 | 文件名含半角 `/` → 误建子目录 | 一律改全角 `／`；远端错误嵌套用 `_del_gh.py` 清理后按正确路径重推 |
| 7 | 按 `^## ` 聚合时材料块脱离共读原文节 | 照录 `## 材料`、主持版 `### 材料`，不可混用 |
| 8 | 多周并行各自照录同一部经 → 跨周重复 | 开工即给"取段边界"；收尾做全库 md5 对撞（内部=0、跨系列=0） |
| 9 | 禁用清单含设计稿预留 id → 候选"自命中"假阳性 | 清单只取**真实已用**，剔除设计稿/确定稿/第四批 |
| 10 | 子代理 T2'/T3 返回空 → 盲目重派 | 先 `ls` 核盘；已落盘则主线程补足收尾 |
| 11 | `file_edit` 改 80KB+ 文档致尾部内容重复 | 改用 python 脚本整文件读入/插入/写回，并校验章节计数 |
| 12 | 交付文件名含半角括号等特殊字符在 API 下异常 | 全角括号可用；路径需 urlencode；中文文件用 UTF-8 |
