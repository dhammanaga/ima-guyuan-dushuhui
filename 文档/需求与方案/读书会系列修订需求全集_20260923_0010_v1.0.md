## 一、总流程（每个系列按序执行）

1. 拉取源资料（脚本落盘，不读入上下文）
2. 结构改造（4 周版改制 / 同步 8 周版）
3. 时长锁定（单讲 120 分钟）
4. 录音转写**存疑核对表**
5. 依知识库**校对**（逐处订正，非替换）
6. **专名校对**（经名/地名/人名回知识库定名）
7. **学员版清理**（8 类，见第五节）
8. **课件原图**插入
9. **Word** 生成与打包
10. 程序化**终检**
11. 打包 → 推送 GitHub → 交付下载链接
12. 全程登记《更新日志_CHANGELOG.md》

## 二、4 周版改制与多版本同步

- **改制方式**：8 周版按**连续两周合并** → 4 周版
  - 第1周 = 原第1周 ＋ 原第2周
  - 第2周 = 原第3周 ＋ 原第4周
  - 第3周 = 原第5周 ＋ 原第6周
  - 第4周 = 原第7周 ＋ 原第8周
- **流程体例**：9 环节双共读
  静心开场 → 共读原文1 → 第一轮分享 → 第一轮主题讨论 → 禅修练习 → 共读原文2 → 第二轮分享 → 第二轮主题讨论 → 收尾与回向
- **共读原文逐字保留**；学员版去除"主持人操作"行；周次合并残留的「（原第X周）」一律删除。
- **多版本同步规则（重要）**：同一任务的**内容/格式类修订须同时应用到 8 周版与 4 周版**；**排除「8周合并4周」的合并操作本身**（周次合并、「（原第X周）」标注、两轮分享/讨论、时长重排等）。
- **周标题**：按每周实际主旨另拟**简洁周标题**（例：禅修入门与正确坐姿／安般念修法与数息对治／禅相培育与五盖对治／经行日常正念与修学规划）；改名后须全局替换正文与文件名，并修复跨文档"下一份文档"链接顺序。

## 六、原文红线与「校对 ≠ 替换」

- **共读/照录原文一字不改**（以源为准）。
- 引用录音转写须**逐句标注时间戳**。
- 自撰文字涉及禅修技法/法义，须有知识库出处，无据者标存疑。
- **「校对」定义**：依源文档**逐处订正**原整理稿，**保留其原有形态与结构**（如"段落整理稿"体例），**不得整段替换/重写**。修订时「校对」与「替换」必须区分。
- **存疑标记规范**：三个红点 🔴🔴🔴；句级写作 `🔴🔴🔴【存疑·未改】……【存疑·未改·止】🔴🔴🔴`，整块首尾包夹，文档顶部加图例。
  - 学员版：去标记、**留文字**；
  - 主持人版：保留标记与元信息；
  - 经确认原文无误处：**"存疑"字样与标记一并去掉**。
