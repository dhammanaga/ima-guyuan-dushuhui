## 一、结论摘要（先说结果）

| 问题 | 核查结果 |
|---|---|
| 禁用清单是"整篇（media_id）级"还是"段落级"？ | **是 media_id 级——整篇文章进列表，不含任何段落信息**。尊者担忧属实 |
| 是否"只引用一段就把整篇禁掉"？ | **是，机制更严重**：不仅"引用即整篇禁"，还混入大量**从未引用**的候选/预留 id |

| 全仓任何文档都找不到的"幽灵 id" | **26 个** |
| 真正发生的"跨系列段落级重复" | **12 段**，集中在 07↔08（10 段），另有 01↔15、01↔05 各 1 段 |

**一句话**：清单"越用越少"不是因为它忠实记录了已用段落，而是因为它把**候选、预留、设计稿占位 id 一并当成"已用"**钉死了。真正需要处理的段落重复很少。

## 四、结论

1. **禁用清单确为"整篇（media_id）级"，非段落级**——与尊者判断一致。
2. 清单膨胀的**真正主因不是"引用一段即整篇禁"，而是把候选/预留 id 当作"已用"写入**：573 个中 223 个无材料记录，142 个纯属预留。→ 这才是"后面可引用材料越来越少"的机制。
3. **真正需要处理的段落级重复很少**：跨系列仅 12 段（07↔08 占 10 段）。
4. 实作中"同文件跨章节/跨周"本就普遍——说明改革为段落级**不会造成返工负担**，只是把已有事实登记到位。

**规则**：
1. 同一 media_id **允许复用**，只需避开"已被引用的章节/段落"；
2. 新引用落稿后，**回写**该 media_id 的"已用章节"；
3. 复用时在照录/周文档注明"与读书会XX第X周同文件不同段落（本讲取〈章节〉，彼讲取〈章节〉）"；
